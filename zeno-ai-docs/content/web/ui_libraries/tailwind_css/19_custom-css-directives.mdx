## 핵심 먼저 보기

- 일반 CSS와 Tailwind를 함께 사용할 수 있습니다.
- 변형과 결합할 새 유틸리티는 `@utility`로 등록합니다.
- `@apply`는 모든 컴포넌트 추상화를 대체하는 도구가 아닙니다.

## 레이어와 사용자 스타일

`@layer base`는 HTML 기본값, `components`는 공통 구성요소의 스타일에 사용합니다. 사용자 스타일을 레이어 밖에 두면 일반 선언의 레이어 우선순위가 달라질 수 있습니다. Tailwind 유틸리티가 무조건 이긴다고 가정하지 않습니다.

## 유틸리티 등록

```css
@utility content-auto {
  content-visibility: auto;
}
```

이 유틸리티는 `hover:content-auto` 같은 변형과 결합할 수 있습니다. 복잡한 기능형 유틸리티는 값 해석 규칙까지 필요하므로 단순한 반복 값을 해결하는 데 과하게 도입하지 않습니다.

## apply와 reference

```css
@layer components {
  .notice {
    @apply rounded-lg bg-blue-50 p-4;
  }
}
```

`@apply`는 알려진 유틸리티의 선언을 현재 규칙에 넣습니다. 긴 클래스 문자열을 모두 CSS 클래스로 옮기기보다 무엇을 공통화하는지 먼저 정합니다. 별도로 처리되는 CSS 모듈·Vue·Svelte 스타일에서 테마나 사용자 유틸리티 정보가 필요하면 `@reference`를 사용합니다. 참조는 그 CSS를 다시 출력하는 import와 다릅니다.
