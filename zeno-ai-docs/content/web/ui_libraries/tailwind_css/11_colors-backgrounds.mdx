## 핵심 먼저 보기

- `text-*`·`bg-*`·`border-*`는 같은 색 토큰을 다른 속성에 적용합니다.
- 색 불투명도와 요소 전체 opacity는 다릅니다.
- 상태를 색 하나로만 구분하지 않습니다.

## 색 이름과 투명도

`bg-blue-600`은 배경, `text-blue-600`은 글자, `border-blue-600`은 테두리입니다. 팔레트 번호는 명도 단계이며 같은 번호가 항상 같은 대비를 보장하지는 않습니다. `bg-black/50`은 배경색만, `opacity-50`은 자식까지 합성된 요소 전체를 반투명하게 만듭니다.

```html
<div class="bg-blue-600/10 p-4 text-blue-800">
  처리 중
</div>
```

## 그라디언트와 이미지

v4의 `bg-linear-to-r from-blue-600 to-cyan-400`은 오른쪽 방향 선형 그라디언트입니다. 중간 색은 `via-*`로 추가합니다. 배경 이미지는 `bg-[url(/images/cover.jpg)]`처럼 선언하고 `bg-cover bg-center`로 크기·위치를 정합니다.

의미 있는 이미지는 배경보다 alt를 제공할 수 있는 img 요소가 적절합니다. 배경 위 글자는 실제 이미지와 겹친 결과로 대비를 확인합니다.

## 테마 색

브랜드 색은 `@theme`의 `--color-brand-*`로 등록해 일관되게 사용합니다. 다크 모드에서는 밝기 번호를 단순히 반전하기보다 배경·본문·테두리 역할별로 선택합니다.
