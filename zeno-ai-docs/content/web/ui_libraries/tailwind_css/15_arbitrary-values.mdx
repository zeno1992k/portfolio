## 핵심 먼저 보기

- 표준 토큰으로 표현하기 어려운 값에 대괄호를 씁니다.
- 임의 값도 완성된 클래스 문자열로 소스에 보여야 합니다.
- 재사용되는 값은 테마나 컴포넌트로 올립니다.

## 값과 속성

`w-[22rem]`은 특정 너비, `grid-cols-[1fr_2fr]`는 특정 열 비율입니다. 클래스 안 공백은 필요한 곳에서 `_`로 표현합니다. `[text-wrap:balance]`처럼 임의 속성을 직접 적는 문법도 있습니다.

```html
<div class="w-[22rem] max-w-full [text-wrap:balance]">
  필요한 값만 직접 지정합니다.
</div>
```

`text-[length:var(--label-size)]`처럼 타입 힌트는 같은 접두사의 글자 크기·색 해석이 모호할 때 구분을 돕습니다. v4의 `bg-(--surface)`는 CSS 변수 참조의 축약 문법입니다.

## 임의 변형

`[&>p]:mt-2`는 현재 요소의 직계 p 자식에 위 여백을 줍니다. 여기서 `&`는 현재 선택자입니다. 외부 콘텐츠처럼 자식마다 클래스를 넣기 어려울 때 유용하지만, 앱 전체에 긴 선택자 문자열을 반복하면 유지보수가 어려워집니다.

## 동적 값

실행 중 받은 너비는 인라인 스타일의 CSS 변수에 넣고 `w-[var(--card-width)]`라는 완성된 클래스를 사용합니다. `w-[${width}px]`처럼 런타임 문자열을 만들어도 빌드가 실제 클래스를 알 수는 없습니다. 임의 URL·선택자를 외부 입력 그대로 받아 적용하지 않습니다.
