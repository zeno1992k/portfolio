## 핵심 먼저 보기

- 모양뿐 아니라 의미·동작이 반복되면 컴포넌트로 묶습니다.
- 조건별 완성 클래스 문자열을 유지합니다.
- 클래스를 합치는 것과 충돌을 해결하는 것은 다른 일입니다.

## 추상화의 경계

버튼마다 padding을 복사하기보다 버튼 컴포넌트에서 크기·색·비활성 상태를 관리할 수 있습니다. 모든 div를 추상화하거나 서로 다른 동작을 하나의 거대한 옵션 컴포넌트에 넣지는 않습니다. 반복의 의미가 안정됐을 때 묶습니다.

```js
const sizes = {
  small: 'px-2 py-1 text-sm',
  medium: 'px-4 py-2 text-base',
}
// 공통 클래스 + 선택한 sizes 값을 사용한다.
```

## 클래스 조합 도구

조건에 따라 문자열을 합치는 도구는 `p-2`와 `p-4`의 CSS 충돌까지 자동 판단하지 않을 수 있습니다. 클래스 병합 도구를 쓰면 해당 도구의 Tailwind 버전·커스텀 유틸리티 지원도 확인합니다. Tailwind 핵심 패키지에 모든 조합·충돌 해결 기능이 내장된 것은 아닙니다.

## 읽기 좋은 나열

레이아웃 → 크기·간격 → 글자 → 색·효과 → 상태처럼 팀 기준으로 정렬하면 찾기 쉽습니다. 정렬 순서는 가독성을 위한 것이며 CSS 우선순위를 바꾸지 않습니다. 외부 Markdown이나 제3자 위젯처럼 마크업을 통제하기 어려운 곳에는 일반 CSS가 더 간단할 수 있습니다.
