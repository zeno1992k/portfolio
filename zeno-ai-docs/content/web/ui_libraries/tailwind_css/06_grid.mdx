## 핵심 먼저 보기

- Grid는 행과 열을 함께 맞추는 배치입니다.
- `grid-cols-3`은 동일 비율의 세 열을 만듭니다.
- 자식의 콘텐츠 크기와 열의 최소 크기도 확인합니다.

## 열과 영역

`grid`로 켜고 `grid-cols-*`·`grid-rows-*`로 트랙을 정합니다. `col-span-2`는 두 열, `row-span-2`는 두 행을 차지합니다. `gap-*`은 트랙 사이 간격이며 바깥 여백은 아닙니다.

```html
<div class="grid grid-cols-1 gap-4 md:grid-cols-3">
  <article class="md:col-span-2">주요 내용</article>
  <aside>부가 내용</aside>
</div>
```

## 자동 배치와 정렬

자식은 기본 배치 규칙에 따라 빈 칸을 채웁니다. `grid-flow-col`은 열 방향 자동 배치에 사용합니다. `justify-items-*`는 셀 안 가로 정렬, `items-*`는 셀 안 세로 정렬입니다. Flex의 주축 정렬과 같은 뜻으로 섞어 읽지 않습니다.

## 필요한 만큼 늘어나는 열

`grid-cols-[repeat(auto-fit,minmax(14rem,1fr))]`은 최소 폭을 지키며 가능한 열 수를 채웁니다. 컨테이너가 그 최소 폭보다 작을 수도 있으면 최소값도 유연하게 설계해야 합니다. `grid-cols-subgrid`는 부모 트랙을 공유할 때 사용하며 부모에 Grid 트랙이 있어야 합니다.
