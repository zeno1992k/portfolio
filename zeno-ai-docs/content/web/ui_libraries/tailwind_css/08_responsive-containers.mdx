## 핵심 먼저 보기

- 접두사 없는 클래스가 기본이며 `md:`는 md 이상입니다.
- 브레이크포인트 이름은 특정 기기 이름이 아닙니다.
- 재사용 카드의 배치는 화면보다 부모 폭이 더 적절한 기준일 수 있습니다.

## 모바일 우선

기본 테마에서 `sm`은 40rem, `md`는 48rem, `lg`는 64rem, `xl`은 80rem, `2xl`은 96rem입니다. `sm:`을 휴대폰 전용으로 읽지 않습니다. 조건은 아래에서 위로 추가되며 큰 화면에도 유지됩니다.

```html
<div class="grid grid-cols-1 gap-4 md:grid-cols-2">
  <article>첫 카드</article>
  <article>둘째 카드</article>
</div>
```

## 특정 범위만 적용

`md:max-lg:flex`는 md 이상 lg 미만에서만 적용합니다. 임의 조건 `min-[50rem]:*`·`max-[70rem]:*`도 쓸 수 있습니다. 테마 브레이크포인트를 추가할 때는 정렬이 예측되도록 단위를 통일합니다.

## 부모 폭을 기준으로

부모의 `@container`는 쿼리 컨테이너를 만들고, 자식의 `@md:`는 그 컨테이너 폭을 봅니다. 뷰포트의 `md:`와 별개 척도이며 기본 `@md`는 28rem입니다. 이름이 같아도 같은 숫자가 아닙니다.

```html
<section class="@container">
  <div class="flex flex-col @md:flex-row">내용</div>
</section>
```
