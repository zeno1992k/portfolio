## 핵심 먼저 보기

- `@theme`는 토큰과 연결된 유틸리티를 만듭니다.
- 일반 CSS 변수만 필요하면 `:root`를 사용합니다.
- 반복되는 값은 이름을 붙이고 일회성 값은 과하게 토큰화하지 않습니다.

## 토큰이 클래스가 되는 과정

```css
@import "tailwindcss";
@theme {
  --color-brand-600: #2563eb;
  --font-display: "Inter", sans-serif;
  --breakpoint-3xl: 120rem;
}
```

이 색은 `bg-brand-600`·`text-brand-600`·`border-brand-600`처럼 사용합니다. `--font-*`는 글꼴, `--breakpoint-*`는 반응형 조건, `--spacing`은 숫자형 간격 계산에 연결됩니다. 이름 공간이 기능을 정합니다.

## 일반 변수와 inline

`:root`의 `--surface` 같은 일반 변수는 CSS 값으로 쓰이지만 그 자체가 모든 Tailwind 유틸리티를 만들지는 않습니다. 다른 변수에 토큰을 연결하면 `@theme inline`으로 유틸리티가 그 참조 값을 직접 사용하게 할 수 있습니다. 변수의 정의·상속 위치가 다르면 결과도 확인해야 합니다.

```css
@theme inline {
  --color-surface: var(--surface);
}
```

## 기본값 변경

같은 토큰 이름을 다시 정의하면 해당 기준을 바꿉니다. `--color-*: initial`은 기본 색 이름 공간을 비우므로 기존 `bg-blue-*` 등을 계속 쓰는지 먼저 확인합니다. 기본값 전체를 초기화하는 작업은 토큰 하나 추가하는 작업과 영향 범위가 다릅니다.
