## 핵심 먼저 보기

- v3 설정 파일을 그대로 두었다고 v4가 자동으로 읽지는 않습니다.
- 빌드 도구 변경과 화면 기본값 변경을 따로 확인합니다.
- 자동 변환 뒤에도 실제 화면과 지원 브라우저를 검증합니다.

## 설정과 도구

| 이전 안내 | v4에서 확인할 것 |
|---|---|
| `@tailwind` 세 디렉티브 | `@import "tailwindcss";` |
| PostCSS의 `tailwindcss` 플러그인 | `@tailwindcss/postcss` |
| `tailwind.config.js` 자동 감지 | CSS 중심 설정 또는 `@config` |
| `bg-gradient-to-r` | `bg-linear-to-r` |

JavaScript 설정 호환 기능에는 제한이 있으므로 `safelist` 등 모든 기존 옵션이 그대로 작동한다고 가정하지 않습니다. 클래스 강제 우선 적용은 `p-4!`, CSS 변수 축약은 `bg-(--surface)`처럼 v4 문법을 확인합니다.

## 화면에서 달라지는 값

그림자·라운드·ring 등 일부 스케일과 기본값이 달라졌습니다. 테두리 색도 명시하는 편이 안전합니다. v4는 hover 가능한 장치 조건 안에서 hover 변형을 사용하므로 터치 장치에서의 기대도 점검합니다.

## 지원 환경

v4는 현대적인 CSS 기능을 사용합니다. 구형 브라우저가 요구되면 공식 호환성 기준과 실제 대상 환경을 대조하고 버전 선택을 판단합니다. 업그레이드 도구는 출발점을 돕지만 모든 사용자 CSS·외부 플러그인·화면 상태를 대신 검증하지 않습니다.
