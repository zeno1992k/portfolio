## 핵심 먼저 보기

- `md:hover:bg-blue-700`은 조건과 실제 스타일을 나눠 읽습니다.
- HTML에서 클래스 이름을 뒤에 적었다고 항상 이기지 않습니다.
- 반응형·상태 조건마다 충돌하는 속성을 하나로 정리합니다.

## 클래스 읽는 순서

`md:`는 화면 폭 조건, `hover:`는 마우스 상태, `bg-blue-700`은 배경색입니다. `-mt-2`는 음수 위 여백이고 `bg-black/50`의 `/50`은 해당 색의 불투명도입니다. 모든 속성에 음수·투명도 문법이 적용되는 것은 아닙니다.

```html
<button class="bg-blue-600 p-3 md:hover:bg-blue-700">
  저장
</button>
```

## 충돌하는 클래스

`p-2 p-4`를 함께 적어도 HTML 나열 순서가 최종 우선순위를 정하지 않습니다. 생성된 CSS의 순서·레이어·선택자 우선순위·조건이 결정합니다. 조건부 UI에서는 둘 중 하나만 남기는 방식으로 조합합니다.

v4의 강제 우선 적용 문법은 `p-4!`처럼 끝에 `!`를 붙입니다. 프로젝트 전체의 우선순위 문제를 이것으로 덮지 않습니다.

## display와 숨김

`hidden`은 `display: none`, `invisible`은 공간을 남기는 숨김, `sr-only`는 화면에서 숨기면서 보조 기술에 읽힐 수 있게 하는 패턴입니다. 문서를 비밀로 만드는 접근 제어는 아닙니다. `hidden md:block`은 작은 화면에서 숨겼다가 md 이상에서 보입니다.
