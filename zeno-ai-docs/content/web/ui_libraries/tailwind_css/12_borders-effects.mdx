## 핵심 먼저 보기

- 테두리의 두께·색·스타일을 따로 읽습니다.
- ring·outline·shadow는 서로 다른 표현입니다.
- 효과가 정보·대비·포커스 표시를 가리지 않게 합니다.

## 경계와 포커스

`border border-slate-300 rounded-lg`는 테두리와 둥근 모서리를 만듭니다. v4에서 기본 border 색을 임의로 가정하지 말고 필요한 색을 명시합니다. `divide-y`는 자식 사이 구분선에 사용합니다.

```html
<button class="rounded-lg border border-slate-300 p-3
  focus-visible:outline-2 focus-visible:outline-blue-600">
  확인
</button>
```

`outline`은 레이아웃 공간을 차지하지 않는 외곽선, `ring`은 그림자 기반의 고리 효과입니다. outline을 없앨 때는 키보드 포커스를 볼 수 있는 대안을 반드시 제공합니다.

## 그림자·필터

`shadow-sm`은 상자 그림자이고 `drop-shadow-*`는 투명한 이미지 실루엣 등 필터 결과에 따라 그림자를 만듭니다. `blur-*`는 요소 자체를, `backdrop-blur-*`는 뒤쪽 배경을 흐립니다. backdrop 효과는 배경이 비쳐야 알아보기 쉽습니다.

## 합성과 마스크

`mix-blend-*`는 뒤쪽 내용과의 색 합성에, `bg-blend-*`는 한 요소의 배경 레이어 합성에 쓰입니다. 마스크는 요소의 보이는 범위를 조절합니다. 이런 효과는 영역·픽셀 수가 크면 비용이 커질 수 있으므로 장식 목적과 읽기 성능을 함께 판단합니다.
