## 핵심 먼저 보기

- 기본 `dark:`는 시스템의 색 구성 선호에 반응합니다.
- 수동 선택은 dark 변형의 조건과 실제 저장·적용 로직을 함께 정합니다.
- 밝은 화면과 어두운 화면 모두에서 대비를 확인합니다.

## 두 색상 구성

```html
<article class="bg-white p-4 text-slate-900
  dark:bg-slate-900 dark:text-slate-100">
  안내
</article>
```

테두리·placeholder·아이콘·포커스 표시도 함께 바꿉니다. 배경만 어둡게 하고 글자색을 그대로 두면 읽을 수 없을 수 있습니다.

## 수동 토글 조건

```css
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));
```

이 설정의 `dark:`는 상위 `.dark` 클래스에 반응합니다. data 속성을 조건으로 삼을 수도 있습니다. 클래스나 속성을 언제 적용할지는 JavaScript가 담당합니다.

## 시스템·밝게·어둡게

수동 선택값을 저장하고, 시스템 선택일 때만 `prefers-color-scheme`을 따릅니다. 첫 화면이 반대 테마로 잠깐 보이지 않게 초기 적용 시점도 정합니다. 폼 컨트롤의 기본 테마에는 CSS `color-scheme`을 함께 검토합니다. `dark:` 클래스만으로 저장·토글·초기화가 구현되지는 않습니다.
