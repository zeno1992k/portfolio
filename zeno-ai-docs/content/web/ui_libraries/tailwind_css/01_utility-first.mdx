## 핵심 먼저 보기

- Tailwind는 작은 CSS 클래스를 조합해 화면을 표현하는 도구입니다.
- 작성한 클래스에서 필요한 CSS를 빌드하며 별도의 UI 동작을 만들지 않습니다.
- 이 과목은 v4 문법을 기준으로 읽습니다.

## 클래스가 하는 일

`p-4`는 안쪽 여백, `rounded-lg`는 모서리, `font-semibold`는 글자 두께를 정합니다. 같은 클래스를 여러 요소에서 재사용합니다. 이름을 외우기보다 CSS 속성과 연결해 읽으면 됩니다.

```html
<div class="rounded-lg bg-white p-4 shadow-sm">
  <h2 class="text-lg font-semibold">공지</h2>
  <p class="mt-2 text-sm text-slate-600">새 소식</p>
</div>
```

## 일반 CSS·인라인 스타일과의 차이

유틸리티는 상태·반응형 조건과 디자인 토큰을 함께 사용합니다. 인라인 스타일은 실행 중 계산한 값을 전달하기 편합니다. 복잡한 선택자나 외부 라이브러리 조정에는 일반 CSS를 함께 써도 됩니다.

Tailwind는 CSS 지식을 대신하지 않습니다. `flex`의 축이나 `position`의 기준은 CSS 규칙 그대로입니다. 메뉴 열기·폼 제출 같은 동작은 HTML과 JavaScript의 역할입니다.

## Preflight가 바꾸는 기본값

Tailwind의 기본 가져오기에는 Preflight가 포함됩니다. 여백·테두리·제목·목록 등의 브라우저 기본 스타일을 정돈하므로 제목이 자동으로 크거나 목록에 점이 찍힌다고 가정하지 않습니다. 필요한 모양은 클래스로 지정합니다.
