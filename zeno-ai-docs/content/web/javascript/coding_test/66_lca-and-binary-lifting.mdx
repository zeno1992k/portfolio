## LCA

LCA(Lowest Common Ancestor, 최소 공통 조상)는 루트가 정해진 트리에서 **두 정점의 공통 조상 가운데 가장 깊은 정점**입니다. 정점은 자기 자신도 조상으로 칩니다. `u`가 `v`의 조상이면 `LCA(u, v)`는 `u`입니다.

다음 트리(루트 0)를 예로 듭니다. 이 문서의 모든 예에서 같은 트리를 씁니다.

```text
간선: 0-1, 0-2, 1-3, 1-4, 2-5, 4-6, 4-7
깊이: 0은 0, 1·2는 1, 3·4·5는 2, 6·7은 3

LCA(6, 7) = 4    두 정점의 부모가 같다
LCA(3, 6) = 1    3과 6의 공통 조상은 1, 0이고 1이 더 깊다
LCA(6, 5) = 0    왼쪽 가지와 오른쪽 가지의 공통 조상은 루트뿐이다
LCA(4, 6) = 4    4가 6의 조상이다
```

- 두 정점 사이의 경로는 항상 LCA를 지납니다. 경로가 유일하다는 트리의 성질(43편)에서 나오며, 이 때문에 LCA로 거리와 경로 정보를 구할 수 있습니다.
- 루트를 바꾸면 LCA가 바뀝니다. 입력이 루트 없는 트리이면 먼저 루트를 정합니다(44편).

가장 단순한 풀이는 깊이를 맞춘 뒤 함께 올리는 것입니다. 부모와 깊이는 루트에서 BFS로 구합니다(44편).

```js
function rootTree(n, adj, root) {
  const parent = new Int32Array(n).fill(-1)   // -1: 아직 미방문
  const depth = new Int32Array(n)
  const queue = [root]
  parent[root] = root                    // 루트의 부모는 자기 자신
  for (let h = 0; h < queue.length; h++) {
    const v = queue[h]
    for (const w of adj[v]) {
      if (parent[w] !== -1) continue
      parent[w] = v; depth[w] = depth[v] + 1
      queue.push(w)
    }
  }
  return { parent, depth }
}
```

```js
function lcaNaive(parent, depth, u, v) {
  while (depth[u] > depth[v]) u = parent[u]   // 깊은 쪽을 올린다
  while (depth[v] > depth[u]) v = parent[v]
  while (u !== v) { u = parent[u]; v = parent[v] }
  return u
}
```

- 시간은 질의당 O(깊이)입니다. 정점이 일렬로 이어진 트리(체인)에서는 깊이가 N - 1이라 O(N)입니다.
- 질의가 Q개이면 O(N × Q)입니다. N, Q가 10^5이면 10^10이라 시간 초과입니다. 아래 Binary Lifting이 질의를 O(log N)으로 줄입니다.
- 재귀 DFS 대신 BFS로 부모와 깊이를 구했습니다. 체인 같은 깊은 트리에서 JavaScript의 호출 스택이 넘치지 않게 하기 위해서입니다(자세히는 86편).

| 방법 | 준비 | 질의 |
|------|------|------|
| 단순 올리기 | O(N) | O(N) |
| Binary Lifting | O(N log N) | O(log N) |
| Euler Tour + Sparse Table(67편) | O(N log N) | O(1) |
| Heavy-Light Decomposition(67편) | O(N) | O(log N) |

**문제의 단서:** "두 정점의 가장 가까운 공통 조상", "두 노드 사이의 거리", "경로 위의 최대·최소 간선", 정점과 질의가 10^5 이상입니다.

## Binary Lifting

Binary Lifting은 **각 정점에서 위로 `2^j`칸 올라간 조상을 `j`별로 미리 저장해 두고, 이동 거리를 이진수로 쪼개 점프하는** 기법입니다. 100칸을 올라가야 하면 64 + 32 + 4칸으로 세 번 점프합니다.

`up[j][v]`를 `v`의 `2^j`번째 조상으로 정의합니다. `2^j`칸은 `2^(j-1)`칸을 두 번 올라간 것이므로 점화식은 다음과 같습니다.

- `up[0][v] = parent[v]`
- `up[j][v] = up[j-1][ up[j-1][v] ]`

```js
function buildUp(parent) {
  const n = parent.length
  const LOG = 32 - Math.clz32(n)         // 2^LOG > n
  const up = [parent]
  for (let j = 1; j < LOG; j++) {
    const prev = up[j - 1], cur = new Int32Array(n)
    for (let v = 0; v < n; v++) cur[v] = prev[prev[v]]
    up.push(cur)
  }
  return up
}
```

위 트리에서 표입니다. 루트 0의 부모는 자기 자신이라, 루트를 넘어서 올라가는 칸은 모두 0이 됩니다.

| 정점 v | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|--------|---|---|---|---|---|---|---|---|
| up[0] (1칸) | 0 | 0 | 0 | 1 | 1 | 2 | 4 | 4 |
| up[1] (2칸) | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 1 |
| up[2] (4칸) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

- 표 크기는 `LOG × N`이고 `LOG`는 약 `log2 N`입니다. N이 10^5이면 17층이라 170만 칸입니다. `Int32Array` 17개면 메모리 7MB 정도입니다(자세히는 14편).
- `LOG = 32 - Math.clz32(n)`이면 `2^LOG > n`이라 깊이 차(최대 `n - 1`)를 모두 이진수로 표현할 수 있습니다.
- 표는 층(`j`)을 바깥 반복으로 채웁니다. 한 층을 만들 때 아래층 전체가 이미 필요하기 때문입니다. 정점을 바깥 반복으로 하면 아직 안 채운 칸을 읽습니다.
- 준비는 O(N log N)입니다.

임의의 정점을 `k`칸 올리는 함수는 `k`의 이진수에서 켜진 비트마다 점프합니다.

```js
function jump(up, v, k) {                // v에서 k칸 위의 조상
  for (let j = 0; k > 0; j++, k >>= 1) {
    if (k & 1) v = up[j][v]
  }
  return v
}
```

LCA는 두 단계입니다.

1. **깊이 맞추기:** 더 깊은 정점을 깊이 차만큼 `jump`로 올립니다. 이때 두 정점이 같아지면 그 정점이 LCA입니다.
2. **함께 올리기:** 큰 점프부터 시도하며, 두 정점의 `2^j`번째 조상이 **서로 다르면** 둘 다 점프합니다. 같으면 LCA를 넘었거나 LCA일 수 있으므로 점프하지 않습니다. 끝나면 두 정점은 LCA의 바로 아래 자식이고, 답은 부모입니다.

```js
function lca(up, depth, u, v) {
  if (depth[u] < depth[v]) [u, v] = [v, u]
  u = jump(up, u, depth[u] - depth[v])   // 1단계
  if (u === v) return u
  for (let j = up.length - 1; j >= 0; j--) {   // 2단계
    if (up[j][u] !== up[j][v]) {
      u = up[j][u]
      v = up[j][v]
    }
  }
  return up[0][u]                        // 바로 아래 자식의 부모
}
```

`lca(6, 5)`를 추적합니다. 깊이는 6이 3, 5가 2입니다.

| 단계 | u | v | 동작 |
|------|---|---|------|
| 시작 | 6 | 5 | 깊이 차 1 |
| 깊이 맞추기 | 4 | 5 | `up[0][6] = 4` |
| j = 3, 2, 1 | 4 | 5 | `up[j][4]`와 `up[j][5]`가 모두 0이라 점프 없음 |
| j = 0 | 1 | 2 | `up[0][4] = 1`, `up[0][5] = 2`가 달라서 점프 |
| 끝 | 1 | 2 | `up[0][1] = 0`을 반환 |

- 2단계의 점프 조건은 "두 조상이 다르다"입니다. 같은 조상까지 올라가면 LCA를 넘길 수 있어서, 항상 **다른 동안만** 올라가서 LCA 바로 아래에서 멈춥니다.
- `lca(3, 6)`은 깊이를 맞추면 `u`가 4, `v`가 3이고 `j = 0`에서 `up[0][4] = up[0][3] = 1`로 같아서 점프하지 않고 `up[0][4] = 1`을 반환합니다.
- 질의는 O(log N)입니다. 준비 O(N log N) 뒤 질의 Q개는 O((N + Q) log N)입니다.
- `u`가 `v`의 조상인 경우는 1단계에서 `u === v`가 되어 바로 반환됩니다.
- 진입·진출 시각(tin, tout)으로 "`u`가 `v`의 조상인가"를 O(1)에 판정해, 2단계를 "`u`가 `v`의 조상이 아닌 동안 올라가기"로 바꾸는 방식도 있습니다(67편의 Euler Tour).

백준식 입력(정점 번호는 1부터, 질의마다 `u v`) 전체 틀입니다.

```js
const fs = require('fs')
const data = fs.readFileSync(0, 'utf8').split(/\s+/)
let p = 0
const n = Number(data[p++])
const adj = Array.from({ length: n }, () => [])
for (let i = 1; i < n; i++) {
  const a = Number(data[p++]) - 1, b = Number(data[p++]) - 1
  adj[a].push(b)
  adj[b].push(a)
}
const { parent, depth } = rootTree(n, adj, 0)
const up = buildUp(parent)
```

```js
const out = []
for (let m = Number(data[p++]); m > 0; m--) {
  const u = Number(data[p++]) - 1, v = Number(data[p++]) - 1
  out.push(lca(up, depth, u, v) + 1)    // 출력은 다시 1부터
}
console.log(out.join('\n'))
```

**흔한 실수:**

- 루트의 부모를 `-1`로 두는 것입니다. 루트를 넘는 점프에서 `up[j][-1]`이 `undefined`가 됩니다. 루트의 부모를 자기 자신(또는 1부터 번호를 쓸 때 0번 정점)으로 두면 루트를 넘어도 안전합니다.
- `LOG`를 17처럼 고정했다가 N이 더 커지는 것입니다. `n`에서 계산하거나 `n`의 최댓값으로 정합니다.
- 깊이를 맞춘 뒤 `u === v` 검사를 빼먹는 것입니다. 검사가 없으면 2단계가 조상 관계의 두 정점에서 `up[0][u]`를 반환해 한 칸 위를 답으로 냅니다.
- 2단계의 반복을 `j`가 작은 쪽부터 돌리는 것입니다. 큰 점프부터 해야 이진수 분해가 맞습니다.
- 재귀 DFS로 부모와 깊이를 구하다가 체인형 트리에서 `RangeError`가 나는 것입니다.

## LCA를 이용한 거리 계산

두 정점 사이의 거리(간선 수)는 **각 정점의 깊이에서 LCA의 깊이를 두 번 뺀 값**입니다.

```js
function dist(up, depth, u, v) {
  const l = lca(up, depth, u, v)
  return depth[u] + depth[v] - 2 * depth[l]
}
// dist(6, 5) = 3 + 2 - 2 * 0 = 5  (6-4-1-0-2-5)
```

- `u`에서 LCA까지가 `depth[u] - depth[l]`, `v`에서 LCA까지가 `depth[v] - depth[l]`이고 둘의 합입니다. 경로가 LCA를 지나는 성질을 이용한 식입니다.
- 거리 질의가 Q개이면 O((N + Q) log N)입니다. 질의마다 BFS를 돌리는 O(N × Q)보다 훨씬 빠릅니다.
- 같은 정점이면 `l`이 자기 자신이라 0이고, 부모와 자식이면 1입니다.
- 이 식으로 "두 정점 사이에 정점이 몇 개인가"는 `dist + 1`, "경로 위에 정점 `x`가 있는가"는 `dist(u, x) + dist(x, v) === dist(u, v)`로 판정합니다.

**문제의 단서:** "두 노드 사이의 거리를 Q번 묻는다", 트리가 고정이고 질의가 많습니다. 트리 전체의 지름(44편)은 LCA 없이 BFS 두 번으로 구하므로 구분합니다.

**흔한 실수:** `2 * depth[l]`에서 2배를 빼먹거나, `depth[u] + depth[v] - depth[l]`처럼 한 번만 빼는 것입니다. 위 트리의 `dist(6, 5)`로 확인합니다(5가 나와야 합니다).

## Weighted LCA

간선에 가중치가 있는 트리에서도 LCA는 간선 수만 따지는 깊이로 구합니다. 가중치는 **경로의 합과 경로 위의 최댓값**(또는 최솟값)을 구할 때 더합니다.

**경로의 합(가중 거리):** 루트에서 각 정점까지의 가중치 합 `wdist`를 BFS에서 함께 기록합니다. 거리 식의 깊이를 `wdist`로 바꾸면 됩니다.

```js
for (const [w, c] of adj[v]) {     // adj[v] = [[이웃, 가중치]]
  if (parent[w] !== -1) continue
  parent[w] = v; depth[w] = depth[v] + 1
  cost[w] = c                  // w와 부모를 잇는 간선의 가중치
  wdist[w] = wdist[v] + c      // 루트에서 w까지의 합
  queue.push(w)
}
// 가중 거리: wdist[u] + wdist[v] - 2 * wdist[lca(u, v)]
```

- `wdist`는 `Float64Array`로 둡니다. 정점 10^5개, 가중치 10^9이면 합이 최대 10^14로 안전 정수(약 9×10^15) 안입니다. 이를 넘을 수 있으면 `BigInt`를 씁니다(자세히는 02편).
- 가중치가 음수여도 이 식은 맞습니다. 경로가 유일하고 루트를 거쳐 상쇄되기 때문입니다.

**경로의 최댓값(최솟값):** Binary Lifting 표에 "`2^j`칸 올라가는 동안 지나는 간선의 최댓값" `mx[j][v]`를 함께 둡니다. `mx[0][v]`는 `v`와 부모를 잇는 간선의 가중치입니다.

```js
const mx = [cost]       // cost[v]: v와 부모를 잇는 간선
for (let j = 1; j < up.length; j++) {
  const prev = mx[j - 1], cur = new Float64Array(n)
  for (let v = 0; v < n; v++) {
    cur[v] = Math.max(prev[v], prev[up[j - 1][v]])
  }
  mx.push(cur)
}
```

`u`에서 조상 `anc`까지 올라가며 최댓값을 모으는 함수를 만들고, 경로의 최댓값은 `u`와 `v` 양쪽을 LCA까지 올려 합칩니다.

```js
function climbMax(up, mx, depth, u, anc) {
  let best = -Infinity, diff = depth[u] - depth[anc]
  for (let j = 0; diff > 0; j++, diff >>= 1) {
    if (diff & 1) {
      best = Math.max(best, mx[j][u])    // 이번 점프에서 지나는 간선들
      u = up[j][u]
    }
  }
  return best
}
// 경로의 최댓값 = Math.max(climbMax(u, l), climbMax(v, l))
```

- `l`은 `lca(up, depth, u, v)`입니다. `u === l`이면 `climbMax`가 `-Infinity`를 돌려주므로, 둘 중 한쪽이 비어도 `Math.max`가 맞게 동작합니다. `u === v`인 빈 경로의 답은 `-Infinity`이므로 문제의 약속에 맞게 처리합니다.
- 최솟값이면 `Math.min`과 `Infinity`로 바꿉니다. 합을 같은 방식으로 `sum[j][v]`에 담으면 경로 합도 구해지지만, 합은 `wdist`로 O(1)에 구하는 쪽이 간단합니다.
- 표에서 루트의 자기 부모 칸에 쌓인 값은 루트를 넘는 점프에만 쓰이므로 질의 결과에 섞이지 않습니다. `climbMax`는 깊이 차 이상 올라가지 않기 때문입니다.
- 준비는 O(N log N), 질의는 O(log N)입니다.
- 정점 쪽에 가중치가 있는 문제(정점 값의 경로 최댓값)는 `mx[0][v]`를 `v` 자신의 값으로 두고, LCA의 값을 한 번 더 포함시킵니다.

**문제의 단서:** "두 정점 사이 경로에서 가장 큰(작은) 간선 가중치", "두 정점 사이 경로의 가중치 합"을 질의로 묻습니다. 간선이 바뀌는 문제는 이 방식이 아니라 HLD(67편)와 Segment Tree가 필요합니다.

## K번째 조상 찾기

`v`의 K번째 조상은 `v`에서 부모 방향으로 `K`칸 올라간 정점입니다. 위에서 만든 `jump`가 그대로 답이지만, **`K`가 깊이보다 크면 조상이 없다**는 경계를 처리해야 합니다.

```js
function kthAncestor(up, depth, v, k) {
  if (k > depth[v]) return -1            // 루트를 넘는다: 조상 없음
  return jump(up, v, k)
}
// kthAncestor(6, 2) = 1   (6 → 4 → 1)
// kthAncestor(6, 3) = 0   (루트)
// kthAncestor(6, 4) = -1  (깊이 3보다 큼)
```

- 루트의 부모를 자기 자신으로 뒀기 때문에, 깊이 검사를 빼면 `K`가 커도 에러 없이 루트를 반환합니다. 반드시 `k > depth[v]`를 먼저 검사합니다.
- 질의당 O(log N)입니다. `K`의 이진수에서 켜진 비트만 점프합니다.
- 질의가 모두 미리 주어지면 DFS 중에 현재 경로(루트에서 현재 정점까지)를 배열 `path`로 들고 있다가 `path[depth[v] - k]`를 읽는 O(1) 방식도 있습니다. 표가 필요 없어 메모리가 적습니다.

**두 정점 사이 경로의 K번째 정점** (`u`를 0번째로 센다)도 LCA와 `jump`의 조합입니다. 경로는 `u`에서 LCA까지 올라가는 구간(`d1`칸)과 LCA에서 `v`까지 내려가는 구간(`d2`칸)으로 이뤄집니다.

```js
function kthOnPath(up, depth, u, v, k) {
  const l = lca(up, depth, u, v)
  const d1 = depth[u] - depth[l]         // u에서 LCA까지 칸 수
  const d2 = depth[v] - depth[l]         // LCA에서 v까지 칸 수
  if (k > d1 + d2) return -1             // 경로보다 멀다
  if (k <= d1) return jump(up, u, k)     // 올라가는 구간 안
  return jump(up, v, d1 + d2 - k)        // 내려가는 구간은 v에서 거꾸로
}
// kthOnPath(6, 5, 3) = 0,  kthOnPath(6, 5, 4) = 2
```

- 경로 `6-4-1-0-2-5`에서 `d1 = 3`, `d2 = 2`이므로, `k = 3`은 `jump(6, 3) = 0`이고 `k = 4`는 `v`에서 `5 - 4 = 1`칸 올라간 정점 `2`입니다.
- 내려가는 구간은 아래에서 위로만 점프할 수 있으므로, `v`에서 올라가는 거리 `d1 + d2 - k`로 바꿔 계산합니다.

**문제의 단서:** "x에서 부모 방향으로 k번 이동한 정점", "경로 위의 k번째 정점", 질의가 많고 트리가 고정입니다.

## 핵심 정리

- LCA는 두 정점의 공통 조상 중 가장 깊은 정점이며(자기 자신 포함), 단순히 올리는 풀이는 질의당 O(깊이)로 체인형 트리에서 O(N)입니다.
- Binary Lifting은 `up[j][v] = up[j-1][up[j-1][v]]`로 `2^j`번째 조상 표를 O(N log N)에 만들고, 질의를 O(log N)에 처리합니다. 루트의 부모는 자기 자신으로 둡니다.
- LCA는 깊이를 맞춘 뒤, 큰 점프부터 두 조상이 다른 동안만 함께 올라가 LCA 바로 아래에서 멈추고 부모를 반환합니다.
- 거리는 `depth[u] + depth[v] - 2 * depth[lca]`이고, 가중치 거리는 루트부터의 합 `wdist`로 같은 식에 적용합니다. 경로의 최댓값은 `mx[j][v]` 표를 함께 만들어 양쪽을 LCA까지 올려 합칩니다.
- K번째 조상은 `k`의 이진수 비트로 점프하되 `k > depth[v]`이면 -1을 돌려주고, 경로의 K번째 정점은 LCA를 기준으로 올라가는 쪽과 내려가는 쪽을 나눠 처리합니다.
