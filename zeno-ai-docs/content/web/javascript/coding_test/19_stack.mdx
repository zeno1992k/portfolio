## Stack 개념

스택(stack)은 마지막에 넣은 원소를 가장 먼저 꺼내는 후입선출(LIFO, Last In First Out) 자료구조입니다. 접시를 쌓고 맨 위부터 집는 것과 같습니다. 넣고 빼는 쪽이 한쪽 끝뿐이고, 그 끝을 top이라고 합니다.

| 연산 | 동작 | 배열로 구현 |
|------|------|-------------|
| push | top에 원소를 넣음 | `s.push(x)` |
| pop | top 원소를 꺼내 반환하고 제거 | `s.pop()` |
| peek | top 원소를 제거하지 않고 봄 | `s[s.length - 1]` |
| isEmpty | 비었는지 확인 | `s.length === 0` |
| size | 원소 수 | `s.length` |

- JavaScript에는 스택 클래스가 없어서 배열을 스택으로 씁니다. 배열의 끝이 top입니다.
- `push`와 `pop`은 배열 끝에서만 일어나므로 한 번에 O(1)입니다. 배열 크기가 늘어날 때의 복사 비용을 평균내면 한 번에 O(1)입니다(분할 상환, 자세히는 14편).
- 스택이 필요하다는 문제의 단서는 다음과 같습니다.

| 단서 | 예 |
|------|----|
| 짝을 맞추는 것 | 괄호, 태그 |
| 가장 최근 것을 먼저 처리 | 직전 입력 취소, 직전 값과 비교 |
| 안쪽부터 풀어야 하는 중첩 | 괄호 안의 식, 반복 압축 |
| 되돌아가는 탐색 | DFS, 백트래킹 |

- 스택에 넣는 값은 원소 자체일 수도 있고, 인덱스일 수도 있습니다. 위치 정보가 필요하면(자세히는 32편) 인덱스를 넣습니다.

## push와 pop

`push`는 배열 끝에 값을 추가하고 새 길이를 반환합니다. `pop`은 마지막 값을 제거해 반환합니다. 배열이 비어 있으면 에러 없이 `undefined`를 반환합니다.

```js
const s = []
s.push(10)  // 1 (새 길이)
s.push(20)  // 2
s.pop()     // 20
s.pop()     // 10
s.pop()     // undefined (빈 스택, 에러 아님)
```

- top을 보려면 `s[s.length - 1]`을 씁니다. ES2022의 `s.at(-1)`도 같습니다. `at`이 없는 환경에서는 앞의 식을 씁니다.
- `s[-1]`은 마지막 원소가 아니라 `-1`이라는 이름의 프로퍼티를 읽어서 `undefined`입니다.
- 빈 스택에서 `pop`이나 peek를 하면 `undefined`가 나오고 에러가 없어서 조용히 틀립니다. 꺼내기 전에 `s.length > 0`을 확인합니다.
- `if (s.pop())`처럼 꺼낸 값을 조건으로 쓰면 값이 `0`이나 `''`일 때 거짓으로 처리됩니다. 비어 있는지는 길이로 확인합니다.
- `shift`와 `unshift`로도 스택을 만들 수 있지만 매번 배열 전체가 밀려서 느립니다(자세히는 14편, 20편). 스택은 끝에서만 다룹니다.
- 값 여러 개를 한 번에 넣을 때 `s.push(...arr)`는 `arr`가 매우 크면 호출 인수 한계로 RangeError가 납니다(자세히는 86편).

작은 입력의 추적입니다.

| 연산 | 스택(왼쪽이 바닥) | 반환 |
|------|-------------------|------|
| push 1 | `[1]` | 1 |
| push 2 | `[1, 2]` | 2 |
| pop | `[1]` | 2 |
| push 3 | `[1, 3]` | 2 |
| pop | `[1]` | 3 |

## 괄호 검사

괄호 검사는 여는 괄호와 닫는 괄호가 올바르게 짝지어졌는지 판정하는 문제입니다. 가장 안쪽의 닫는 괄호는 가장 최근에 열린 괄호와 짝이어야 하므로 스택이 맞습니다.

1. 여는 괄호를 만나면 `push`합니다.
2. 닫는 괄호를 만나면 `pop`한 값이 같은 종류의 여는 괄호인지 확인합니다.
3. 끝까지 읽은 뒤 스택이 비어 있어야 올바른 문자열입니다.

```js
function isValid(str) {
  const pair = { ')': '(', ']': '[', '}': '{' }
  const stack = []
  for (const ch of str) {
    if (ch === '(' || ch === '[' || ch === '{') {
      stack.push(ch)
    } else if (pair[ch]) {
      if (stack.pop() !== pair[ch]) return false
    }
  }
  return stack.length === 0
}
```

| 입력 | 결과 | 이유 |
|------|------|------|
| `{[()]}` | true | 안쪽부터 모두 짝이 맞음 |
| `([)]` | false | `)`가 왔을 때 top이 `[`라서 불일치 |
| `())(` | false | 두 번째 `)`에서 스택이 비어 `pop`이 `undefined` |
| `((())` | false | 끝에 `(`가 하나 남음 |

- 실패하는 경우는 세 가지입니다. 닫는 괄호를 만났는데 스택이 비어 있음, 종류가 맞지 않음, 끝까지 읽었는데 스택에 남음.
- 위 코드에서 빈 스택의 `pop()`이 `undefined`를 주고 `undefined !== '('`가 `true`라서 첫 번째 경우가 두 번째 경우와 같은 분기로 처리됩니다.
- 괄호가 한 종류뿐이면 스택 대신 깊이를 세는 정수 하나로 충분합니다. 여는 괄호에 1을 더하고 닫는 괄호에 1을 빼며, 중간에 음수가 되면 실패, 끝에 0이 아니면 실패입니다. 공간이 O(1)입니다.
- 괄호가 아닌 문자가 섞여 있으면 무시합니다. 위 코드는 그 문자를 건너뜁니다.
- 시간은 문자열 길이 N에 대해 O(N)이고 스택의 최대 크기는 O(N)입니다.
- 짝이 맞는 구간의 길이나 괄호의 깊이를 묻는 문제도 같은 구조에서 시작합니다. 스택에 괄호 대신 인덱스를 넣으면 구간 길이를 구할 수 있습니다.

**흔한 실수:** 끝에 스택이 비었는지 확인하지 않는 것입니다. `((()`처럼 닫히지 않은 여는 괄호는 읽는 도중에는 실패하지 않습니다.

## 문자열 Stack

문자열을 한 글자씩 읽으며 스택에 쌓고, 직전 글자와의 관계로 지우는 문제에 스택을 씁니다. 결과는 스택에 남은 글자를 `join('')`으로 이어 얻습니다.

인접한 같은 글자를 계속 제거하는 문제입니다.

```js
function removeAdjacent(s) {
  const st = []
  for (const ch of s) {
    if (st[st.length - 1] === ch) st.pop()
    else st.push(ch)
  }
  return st.join('')
}
removeAdjacent('abbaca') // 'ca'
removeAdjacent('aaa')    // 'a'
```

`abbaca`를 추적하면 `a`, `ab`, `a`(b 제거), 빈 문자열(a 제거), `c`, `ca`입니다. 지운 뒤에 새로 인접하게 된 글자도 스택의 top 비교로 자연스럽게 처리됩니다.

- 비어 있는 스택의 top은 `undefined`라서 어떤 글자와도 같지 않습니다. 첫 글자는 항상 `push`됩니다.
- `aaa`는 첫 `a`가 들어가고, 둘째 `a`가 같아서 빠지고, 셋째 `a`가 들어가 `a`가 남습니다. 연속해서 둘씩 짝지어 지웁니다.
- 백스페이스 문자(`#`)가 들어 있는 입력을 편집한 결과를 구하는 문제도 스택입니다.

```js
function typed(s) {
  const st = []
  for (const ch of s) {
    if (ch === '#') st.pop() // 빈 스택이면 아무 일도 없음
    else st.push(ch)
  }
  return st.join('')
}
typed('ab#c') // 'ac'
```

- 문자열을 `+=`로 직접 고치면 매번 새 문자열이 만들어집니다. 배열에 쌓고 마지막에 한 번 `join`합니다(자세히는 06편).
- 안쪽부터 풀어야 하는 반복 압축(예: 숫자 뒤 괄호 안 문자열을 그 횟수만큼 반복)도 여는 괄호를 만났을 때 지금까지의 결과를 스택에 저장하고, 닫는 괄호에서 꺼내 이어 붙입니다. 구조는 괄호 검사와 같습니다.
- 시간은 O(N)입니다. 각 글자가 최대 한 번 들어가고 한 번 나옵니다.

**흔한 실수:** 지운 뒤 다시 인접하게 된 글자를 놓치는 것입니다. `abba`를 앞에서부터 한 번 훑어 `bb`만 지우면 `aa`가 남습니다. 스택은 지운 뒤의 top을 바로 비교해서 이 문제가 없습니다.

## DFS Stack

DFS(깊이 우선 탐색)는 갈 수 있는 곳까지 파고들고 막히면 되돌아오는 탐색입니다. 되돌아올 곳을 기억해야 하므로 스택이 필요하고, 재귀는 호출 스택이 그 역할을 합니다. 직접 만든 스택을 쓰면 재귀 깊이 한계 없이 같은 탐색을 합니다(자세히는 22편, 36편).

```js
function dfs(graph, start) {
  const visited = Array(graph.length).fill(false)
  const order = [], stack = [start]
  while (stack.length > 0) {
    const v = stack.pop()
    if (visited[v]) continue // 이미 방문했으면 건너뜀
    visited[v] = true
    order.push(v)
    for (let i = graph[v].length - 1; i >= 0; i--) {
      stack.push(graph[v][i])
    }
  }
  return order
}
dfs([[1, 2], [3], [3], []], 0) // [0, 1, 3, 2]
```

- 꺼낼 때(`pop`) 방문을 확인하는 이유는 같은 노드가 여러 번 스택에 들어갈 수 있어서입니다. 위 입력에서 노드 3은 1과 2에서 두 번 들어갑니다.
- 이웃을 역순으로 넣는 이유는 먼저 꺼낼 이웃(번호가 작은 쪽)이 맨 위에 오게 하기 위해서입니다. 이렇게 하면 방문 순서가 재귀 DFS와 같습니다. 순서가 중요하지 않으면 정방향으로 넣어도 됩니다.
- 시간은 노드 수 V와 간선 수 E에 대해 O(V + E)이고, 스택에는 최대 E개가 들어갑니다.
- 스택에 `[노드, 이웃 위치]` 같은 쌍을 넣어 이웃을 하나씩 진행하면 노드 도착·종료 시점이 필요한 문제(방문 순서, 사이클)도 반복문으로 옮길 수 있습니다(자세히는 36편).
- 격자 DFS도 같은 구조에서 `(r, c)`를 스택에 넣고 이웃은 방향 배열로 만듭니다(자세히는 17편).

**흔한 실수:** 스택에 넣을 때 방문 표시를 하고 꺼낼 때 또 확인하지 않는 방식을 섞는 것입니다. 한쪽 규칙으로 통일합니다. 위 코드는 꺼낼 때만 확인합니다.

## 후위 표기식

수식의 쓰는 방식은 연산자의 위치에 따라 세 가지입니다.

| 표기 | 연산자 위치 | 예 (3 + 4를 곱하기 2) |
|------|-------------|------------------------|
| 중위(infix) | 피연산자 사이 | `(3 + 4) * 2` |
| 전위(prefix) | 피연산자 앞 | `* + 3 4 2` |
| 후위(postfix) | 피연산자 뒤 | `3 4 + 2 *` |

후위 표기식(역폴란드 표기법)은 연산자가 두 피연산자 뒤에 오기 때문에 괄호와 우선순위가 필요 없고, 앞에서부터 읽으며 스택 하나로 계산됩니다.

1. 숫자를 만나면 `push`합니다.
2. 연산자를 만나면 두 개를 `pop`해서 계산하고 결과를 `push`합니다.
3. 끝나면 스택에 남은 하나가 결과입니다.

```js
const calc = {
  '+': (a, b) => a + b,
  '-': (a, b) => a - b,
  '*': (a, b) => a * b,
  '/': (a, b) => Math.trunc(a / b),
}
```

```js
function evalPostfix(tokens) {
  const st = []
  for (const t of tokens) {
    if (calc[t]) {
      const b = st.pop(), a = st.pop() // 먼저 꺼낸 것이 b
      st.push(calc[t](a, b))
    } else st.push(Number(t))
  }
  return st.pop()
}
```

`evalPostfix('5 1 2 + 4 * + 3 -'.split(' '))`을 추적합니다.

| 토큰 | 스택 |
|------|------|
| 5, 1, 2 | `[5, 1, 2]` |
| + | `[5, 3]` |
| 4 | `[5, 3, 4]` |
| * | `[5, 12]` |
| + | `[17]` |
| 3 | `[17, 3]` |
| - | `[14]` |

- 먼저 꺼낸 값이 오른쪽 피연산자(`b`)입니다. 순서를 바꾸면 뺄셈과 나눗셈이 틀립니다.
- 정수 나눗셈은 문제에 맞춥니다. 0 방향으로 버리는 `Math.trunc(a / b)`는 `-7 / 2`가 `-3`이고, 내림인 `Math.floor`는 `-4`입니다(자세히는 02편).
- 토큰을 공백으로 나눠 주지 않고 한 글자씩 주는 문제에서는 여러 자리 숫자를 직접 이어 붙여야 합니다.
- 시간은 토큰 수 N에 대해 O(N)입니다.

## 중위 표기식을 후위로 변환

사람이 쓰는 중위식을 후위식으로 바꾸는 방법은 연산자를 스택에 쌓아 두고 우선순위로 내보내는 것입니다. 피연산자는 읽는 즉시 출력하고, 연산자는 스택에 보관합니다.

1. 피연산자는 바로 출력합니다.
2. 연산자는 스택의 top이 우선순위가 같거나 높은 연산자인 동안 그것을 꺼내 출력한 뒤 `push`합니다.
3. `(`는 그냥 `push`합니다. `)`를 만나면 `(`가 나올 때까지 꺼내 출력하고 `(`는 버립니다.
4. 끝나면 스택에 남은 연산자를 모두 꺼내 출력합니다.

```js
const prec = { '(': 0, '+': 1, '-': 1, '*': 2, '/': 2 }
function pushOp(ch, ops, out) {
  // top의 우선순위가 같거나 높으면 먼저 꺼내 출력
  const top = () => ops[ops.length - 1]
  while (ops.length && prec[top()] >= prec[ch]) {
    out.push(ops.pop())
  }
  ops.push(ch)
}
```

```js
function toPostfix(expr) {
  const out = [], ops = []
  const top = () => ops[ops.length - 1]
  for (const ch of expr) {
    if (ch === '(') ops.push(ch)
    else if (ch === ')') {
      while (top() !== '(') out.push(ops.pop())
      ops.pop() // '(' 버리기
    } else if (prec[ch] !== undefined) pushOp(ch, ops, out)
    else out.push(ch) // 피연산자
  }
  while (ops.length) out.push(ops.pop())
  return out.join('')
}
```

| 중위 | 후위 |
|------|------|
| `A+B*C` | `ABC*+` |
| `(A+B)*C` | `AB+C*` |
| `A-B-C` | `AB-C-` |
| `A*(B+C)/D` | `ABC+*D/` |

- 우선순위가 같을 때 꺼내는 이유는 왼쪽부터 계산하는 규칙(왼쪽 결합) 때문입니다. `A-B-C`가 `(A-B)-C`이므로 `AB-C-`입니다.
- 거듭제곱(`^`)처럼 오른쪽 결합인 연산자는 우선순위가 같을 때 꺼내지 않고 쌓습니다. `2^3^2`는 `2^(3^2)`입니다.
- `(`는 스택에서 가장 낮은 우선순위(0)로 둡니다. 그래야 `(` 위의 연산자가 `(` 아래로 내려가 꺼내지는 일이 없습니다.
- 입력의 피연산자가 한 글자(변수)나 한 자리 숫자인 것으로 가정한 코드입니다. 여러 자리 숫자는 읽는 단계에서 토큰으로 먼저 나눕니다.
- 시간은 O(N)입니다. 각 문자가 최대 한 번 들어가고 한 번 나옵니다.

## 최솟값 스택

최솟값 스택(Min Stack)은 `push`, `pop`, `peek`에 더해 현재 스택의 최솟값을 O(1)에 돌려주는 스택입니다. 일반 스택에서 최솟값을 구하면 모든 원소를 훑어야 해서 O(N)입니다.

각 원소를 넣을 때 그 시점까지의 최솟값을 함께 저장합니다.

```js
class MinStack {
  constructor() { this.s = [] }
  push(x) {
    const top = this.s[this.s.length - 1]
    const m = top ? Math.min(x, top[1]) : x
    this.s.push([x, m]) // [값, 그때까지의 최솟값]
  }
  pop() { return this.s.pop()[0] }
  top() { return this.s[this.s.length - 1][0] }
  min() { return this.s[this.s.length - 1][1] }
}
```

값 `4, 2, 6`을 차례로 넣으면 `[[4, 4], [2, 2], [6, 2]]`입니다. `pop`을 두 번 하면 `[[4, 4]]`가 되어 `min()`은 `4`입니다.

- 원소 아래에는 자기보다 먼저 들어간 원소들의 최솟값이 이미 적혀 있습니다. 위의 원소가 나가면 최솟값이 자동으로 이전 값으로 복원됩니다.
- 모든 연산이 O(1)이고 공간은 원소 수의 두 배입니다.
- 공간을 아끼려면 최솟값만 별도 스택에 쌓되, 새 값이 현재 최솟값보다 작거나 같을 때만 넣습니다. 같을 때도 넣어야 합니다. 같은 값이 둘 있는 상태에서 하나가 나갔을 때 최솟값이 사라지는 것을 막기 위해서입니다.
- 같은 원리로 최댓값이나 합, 개수 같은 누적 정보를 원소와 함께 저장하는 스택을 만들 수 있습니다.
- 큐에서 같은 일을 하려면 더 정교한 구조가 필요합니다(자세히는 32편).

## 되돌리기 기록

되돌리기(Undo)는 작업을 수행한 순서의 반대로 하나씩 취소하는 기능이고, 마지막 작업부터 취소하므로 스택이 맞습니다. 작업을 수행할 때마다 기록을 스택에 쌓고, 취소할 때 `pop`해 그 작업을 거꾸로 합니다. 다시 실행(Redo)은 취소한 기록을 담는 두 번째 스택을 씁니다.

```js
const text = [], undoStack = [], redoStack = []
function type(ch) {
  text.push(ch); undoStack.push(ch)
  redoStack.length = 0 // 새 작업이 생기면 redo는 무효
}
function undo() {
  if (undoStack.length === 0) return
  const ch = undoStack.pop()
  text.pop(); redoStack.push(ch)
}
function redo() {
  if (redoStack.length === 0) return
  const ch = redoStack.pop()
  text.push(ch); undoStack.push(ch)
}
```

`a`, `b`, `c`를 입력하고 `undo`를 두 번 하면 `a`이고, `redo` 한 번이면 `ab`입니다. 그 상태에서 `x`를 입력하면 `abx`가 되고 `redo`는 더 이상 되살릴 것이 없습니다.

- 기록 방식은 두 가지입니다. 작업의 역연산만 저장하는 방식은 공간이 작지만 역연산을 정의해야 합니다. 작업 직전의 전체 상태를 저장하는 방식은 단순하지만 상태가 크면 공간을 많이 씁니다.
- 새 작업을 하면 `redoStack`을 비웁니다. 되돌리기 이후의 새 작업은 이전의 되살릴 미래와 이어지지 않습니다.
- 브라우저의 뒤로 가기·앞으로 가기도 같은 구조입니다. 시뮬레이션에서 "직전 명령 취소"가 나오면 명령 기록을 스택에 쌓아 두면 됩니다(자세히는 18편).
- 각 연산은 O(1)입니다.

**흔한 실수:** 객체나 배열 상태를 스택에 그대로 `push`하는 것입니다. 이후에 그 객체를 수정하면 스택에 저장된 기록도 같이 바뀝니다. 복사해서 저장합니다(자세히는 01편).

## 핵심 정리

- 스택은 후입선출이고 JavaScript에서는 배열의 `push`, `pop`으로 구현하며 두 연산은 O(1)입니다. 빈 스택의 `pop`은 `undefined`를 줄 뿐 에러가 아닙니다.
- 괄호 검사는 여는 괄호를 쌓고 닫는 괄호에서 top과 짝을 확인하며, 끝에 스택이 비어 있어야 합니다.
- 문자열 스택은 직전 글자와 비교해 지우고 마지막에 `join('')`으로 결과를 얻습니다.
- 반복 DFS는 꺼낼 때 방문을 확인하고, 이웃을 역순으로 넣으면 재귀 DFS와 같은 순서가 됩니다.
- 후위식은 숫자를 쌓고 연산자에서 두 개를 꺼내 계산하며, 먼저 꺼낸 값이 오른쪽 피연산자입니다. 중위에서 후위로의 변환은 연산자 스택과 우선순위를 씁니다.
- 최솟값 스택은 값과 그 시점의 최솟값을 함께 저장하고, 되돌리기는 기록 스택과 되살리기 스택 두 개로 만듭니다.
