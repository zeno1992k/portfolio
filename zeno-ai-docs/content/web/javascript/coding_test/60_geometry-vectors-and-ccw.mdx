## 좌표

2차원 기하 문제의 입력은 점의 좌표 `(x, y)` 목록입니다. 이 문서는 점을 길이 2의 배열 `[x, y]`로 표현합니다. 문제에서 점이 많으면 객체 `{ x, y }`보다 배열이 만들고 읽기 쉽습니다.

```js
const a = [0, 0]
const b = [4, 3]
const [bx, by] = b // 구조 분해로 꺼냄
```

- 이 문서의 기하 코드는 x축이 오른쪽, y축이 위쪽인 수학 좌표계를 가정합니다. 반시계 방향은 이 좌표계에서 정의됩니다.
- 격자 문제(17편)의 `(행, 열)`은 행이 아래로 늘어나서 y축이 아래를 향하는 화면 좌표계입니다. 같은 식을 쓰면 "반시계"와 "시계"가 뒤바뀝니다. 부호를 그대로 쓰되 의미를 문제 좌표계에 맞춰 해석합니다.
- 입력이 정수인지 실수인지 먼저 확인합니다. 정수이면 이 문서의 모든 판정을 정수 연산으로 끝낼 수 있습니다(아래 "정수 좌표 유지와 실수 오차").
- 좌표 범위가 곧 오차 범위입니다. 좌표 절댓값이 3 × 10^7 이하이면 외적이 안전한 정수 범위에 들어가고, 그보다 크면 BigInt가 필요합니다(자세히는 02편).

**흔한 실수:** 입력의 순서가 `x y`인지 `행 열`인지 확인하지 않고 바꿔 읽는 것입니다.

## 두 점 거리

두 점 `(x1, y1)`, `(x2, y2)` 사이의 유클리드 거리는 `√((x1 − x2)² + (y1 − y2)²)`입니다.

```js
const dx = x1 - x2, dy = y1 - y2
const d = Math.hypot(dx, dy)          // 5
const d2 = dx * dx + dy * dy          // 25 (제곱 거리)
Math.hypot(3, 4)                      // 5
```

- `Math.hypot`은 인수의 제곱합의 제곱근을 구합니다. 제곱이 넘치는 아주 큰 값에서도 `Math.sqrt(dx * dx + dy * dy)`보다 안전합니다.
- 거리를 비교하기만 하면 제곱근을 취하지 않고 제곱 거리를 비교합니다. 정수만으로 정확하고, 제곱근이 만드는 오차가 없습니다.

```js
// 점 p가 원(중심 c, 반지름 r) 안에 있는가
const inside = (p, c, r) =>
  (p[0] - c[0]) ** 2 + (p[1] - c[1]) ** 2 <= r * r
```

- 반지름이 정수이면 `r * r`도 정수라서 `<=` 비교가 정확합니다. `Math.sqrt`의 결과와 `r`을 비교하면 `5.000000000000001 <= 5` 같은 문제가 생길 수 있습니다.
- 출력할 때 소수점 자릿수는 `toFixed`로 맞춥니다(자세히는 02편). 작은 음수를 `toFixed(2)`하면 `'-0.00'`이 나오는 것에 주의합니다.

**문제의 단서:** "가장 가까운 두 점", "원 안에 들어가는 점의 수", "반지름 R 이내". N이 큰 입력에서 가장 가까운 쌍을 구하는 문제는 모든 쌍을 보는 O(N²)로는 풀 수 없고 별도 알고리즘이 필요합니다.

## Manhattan Distance

맨해튼 거리(Manhattan distance)는 두 점 사이를 가로·세로로만 이동했을 때의 거리 `|x1 − x2| + |y1 − y2|`입니다.

```js
const manhattan = (p, q) =>
  Math.abs(p[0] - q[0]) + Math.abs(p[1] - q[1])
manhattan([0, 0], [3, -4]) // 7
```

- 격자에서 상하좌우로만 움직이는 문제(17편, 38편)의 최소 이동 거리입니다. 장애물이 없으면 BFS 없이 이 값이 답입니다.
- 모든 값이 정수이면 결과도 정수이고, 제곱근도 오차도 없습니다.
- 맨해튼 거리 1을 가진 점들의 모양은 원이 아니라 마름모(대각선이 축에 놓인 정사각형)입니다. 이 성질 때문에 아래 "45도 회전 변환"이 쓰입니다.

**문제의 단서:** "상하좌우로만 이동", "택시 거리", 두 점의 `|dx| + |dy|`를 최대·최소로 만드는 점 쌍 찾기.

## 벡터

벡터(vector)는 크기와 방향을 가진 양입니다. 2차원에서는 `[dx, dy]`로 씁니다. 점 A에서 B로 향하는 벡터는 `B − A`입니다. 점과 벡터는 같은 배열이지만 점은 위치이고 벡터는 이동량입니다.

```js
const sub = (p, q) => [p[0] - q[0], p[1] - q[1]]
const add = (p, q) => [p[0] + q[0], p[1] + q[1]]
const scale = (v, k) => [v[0] * k, v[1] * k]
sub([4, 3], [1, 1]) // [3, 2] (A에서 B로의 이동량)
```

- 크기(길이)는 `Math.hypot(v[0], v[1])`이고, 크기의 제곱은 `v[0] ** 2 + v[1] ** 2`로 정수에서 정확히 구합니다.
- 벡터의 합은 이동을 이어 붙인 것이고, 스칼라 곱은 같은 방향으로 늘이거나 줄입니다.
- 영벡터 `[0, 0]`은 길이가 0이라서 방향이 없습니다. 방향이 필요한 계산(각도, 단위 벡터)에서는 0으로 나누지 않게 먼저 걸러냅니다.

이후 내적·외적 코드는 아래 두 함수를 씁니다.

```js
const dot = (a, b) => a[0] * b[0] + a[1] * b[1]
const cross = (a, b) => a[0] * b[1] - a[1] * b[0]
```

## 내적

내적(dot product)은 두 벡터의 대응하는 성분을 곱해 더한 값 `a · b = ax·bx + ay·by`입니다. 기하학적으로는 `|a| |b| cos θ`(θ는 두 벡터 사이의 각)입니다.

```js
dot([1, 0], [1, 1])  // 1
dot([1, 0], [0, 1])  // 0 (수직)
dot([1, 0], [-1, 1]) // -1
```

부호가 두 벡터 사이 각의 종류를 알려 줍니다.

| 내적 | 각 θ | 의미 |
|------|------|------|
| 양수 | 90도 미만 | 대체로 같은 방향 |
| 0 | 90도 | 수직 |
| 음수 | 90도 초과 | 대체로 반대 방향 |

- 같은 벡터의 내적은 길이의 제곱입니다(`dot(a, a) = |a|²`).
- 다른 벡터로의 정사영 길이는 `dot(a, b) / |b|`입니다. 아래 "점과 선분 거리"에서 씁니다.
- 각도 자체가 필요하면 `Math.acos(dot(a, b) / (|a| · |b|))`로 구합니다. 부동소수점 오차로 비율이 `1.0000000000000002`처럼 1을 조금 넘으면 `Math.acos`가 `NaN`을 돌려줍니다. `Math.min(1, Math.max(-1, ratio))`로 범위를 제한한 뒤 씁니다.
- 각도의 크기를 비교하는 것이 목적이면 각도를 구하지 말고 내적과 외적의 부호로 비교합니다.

**흔한 실수:** 직각을 `dot(a, b) === 0`이 아니라 각도 `=== 90`으로 판별하는 것입니다. 각도는 소수 오차가 있어 정확히 90이 되지 않습니다.

## 외적

2차원 외적(cross product)은 두 벡터가 이루는 평행사변형의 부호가 있는 넓이 `a × b = ax·by − ay·bx`입니다. 3차원 외적의 z 성분이며 스칼라(수 하나)입니다.

```js
cross([1, 0], [0, 1]) // 1  (a에서 b로 반시계로 90도)
cross([0, 1], [1, 0]) // -1 (시계 방향)
cross([2, 4], [1, 2]) // 0  (평행)
```

- 부호: 양수이면 `b`가 `a`의 반시계 방향(왼쪽)에 있고, 음수이면 시계 방향(오른쪽), 0이면 평행(같은 직선 위)입니다.
- 크기: `|a × b|`는 두 벡터가 만드는 평행사변형의 넓이이고, 두 벡터가 이루는 삼각형의 넓이는 그 절반입니다.
- 교환 법칙이 성립하지 않습니다. `a × b = −(b × a)`입니다. 순서를 바꾸면 부호가 뒤집힙니다.
- 삼각형의 넓이는 `|cross(b − a, c − a)| / 2`입니다. 정수 좌표이면 이 값(넓이의 2배)이 정수이므로, 2로 나누기 전의 값을 비교하면 소수 오차가 없습니다.

```js
// 삼각형 abc 넓이의 2배
const area2 = (a, b, c) =>
  Math.abs(cross(sub(b, a), sub(c, a)))
area2([0, 0], [4, 0], [0, 3]) // 12 (넓이는 6)
```

**문제의 단서:** "세 점이 한 직선 위", "삼각형의 넓이", "방향", "왼쪽·오른쪽".

## CCW

CCW(counter-clockwise)는 세 점 A, B, C를 이 순서로 지날 때 어느 쪽으로 도는지 알려 주는 판정입니다. 벡터 `AB`와 `AC`의 외적의 부호입니다.

```js
const ccw = (a, b, c) =>
  Math.sign(cross(sub(b, a), sub(c, a)))
ccw([0, 0], [4, 0], [2, 3])  // 1  (반시계)
ccw([0, 0], [4, 0], [2, -3]) // -1 (시계)
ccw([0, 0], [4, 0], [8, 0])  // 0  (한 직선 위)
```

| 결과 | 의미 | 그림 |
|------|------|------|
| `1` | 반시계 방향(좌회전) | C가 직선 AB의 왼쪽 |
| `-1` | 시계 방향(우회전) | C가 직선 AB의 오른쪽 |
| `0` | 세 점이 한 직선 위 | A, B, C가 일직선 |

- `Math.sign`으로 -1, 0, 1만 남기면 이후에 부호끼리 곱해도 값이 넘치지 않습니다. 외적 값 두 개를 그대로 곱하면 안전한 정수 범위를 쉽게 넘습니다.
- `Math.sign(-0)`은 `-0`이지만 `=== 0`은 `true`라서 `ccw(...) === 0` 비교는 그대로 동작합니다.
- 화면 좌표계(y축이 아래)에서는 반시계와 시계의 의미가 반대입니다. 문제 좌표계를 확인합니다.
- 볼록 껍질과 다각형 넓이는 이 판정 위에서 만듭니다(자세히는 61편).

**흔한 실수:** `cross(b - a, c - a)` 대신 `cross(a, b)`와 `cross(a, c)`처럼 원점 기준 벡터로 계산하는 것입니다. 기준점 A를 빼서 벡터를 만들어야 합니다.

## 점과 직선의 위치 관계

점 P가 방향이 있는 직선 AB의 어느 쪽에 있는지는 `ccw(A, B, P)`로 판정합니다. 1이면 왼쪽, -1이면 오른쪽, 0이면 직선 위입니다.

```js
const side = (a, b, p) => ccw(a, b, p)
side([0, 0], [4, 0], [1, 5])  // 1 (직선 위쪽 = 왼쪽)
side([0, 0], [4, 0], [9, 0])  // 0 (직선 위, 선분 밖)
```

직선 위(`0`)라고 해서 선분 위는 아닙니다. 선분 AB 위에 있으려면 한 직선 위이면서 A, B가 만드는 직사각형 범위 안에 있어야 합니다.

```js
const between = (u, v, w) =>
  Math.min(u, v) <= w && w <= Math.max(u, v)
const inBox = (a, b, p) =>
  between(a[0], b[0], p[0]) && between(a[1], b[1], p[1])
const onSegment = (a, b, p) =>
  ccw(a, b, p) === 0 && inBox(a, b, p)
```

- 점에서 직선까지의 거리는 `|cross(B − A, P − A)| / |AB|`입니다. 외적이 평행사변형의 넓이이고, 밑변 `|AB|`로 나누면 높이가 됩니다. 제곱으로 비교하려면 `cross² / |AB|²`를 분수로 둡니다.
- 직선의 방정식을 `y = ax + b`로 세워서 판정하면 수직선(기울기가 무한대)에서 0으로 나누는 문제가 생깁니다. 외적을 쓰면 수직선도 같은 식으로 처리됩니다.

**흔한 실수:** `ccw === 0`만으로 "선분 위"라고 판정하는 것입니다. 직선 위와 선분 위는 다릅니다.

## 평행 / 수직 판별

두 직선(또는 벡터)이 평행한지는 외적이 0인지, 수직인지는 내적이 0인지로 판별합니다.

```js
const parallel = (a, b) => cross(a, b) === 0
const perpendicular = (a, b) => dot(a, b) === 0
parallel([2, 4], [-1, -2])    // true (방향이 반대여도 평행)
perpendicular([1, 2], [-2, 1]) // true
```

- 직선 AB와 CD의 평행은 `parallel(sub(B, A), sub(D, C))`입니다. 평행이면서 `ccw(A, B, C) === 0`이면 같은 직선(일치)입니다.
- 기울기 `dy / dx`를 나눠서 비교하지 않습니다. `dx = 0`이면 `Infinity`가 되고, 실수 나눗셈은 오차를 만듭니다. 교차곱 `a.x * b.y === a.y * b.x`가 정확합니다.
- 영벡터는 외적과 내적이 모두 0이라 모든 벡터와 평행이고 수직으로 판정됩니다. 점이 겹친 입력이 가능하면 먼저 걸러냅니다.

**문제의 단서:** "직각삼각형인가", "두 선분이 평행한가", "직교". 직각삼각형은 세 변 중 두 벡터의 내적이 0인지로 확인합니다.

## 점과 선분 거리

점 P에서 선분 AB까지의 거리는 선분 위에서 P에 가장 가까운 점까지의 거리입니다. 직선까지의 거리와 달리, 수선의 발이 선분 밖에 떨어지면 가까운 끝점이 답입니다.

`t = dot(P − A, B − A) / |AB|²`로 정사영의 위치를 구합니다. `t`가 0 이하이면 끝점 A가, 1 이상이면 끝점 B가 가장 가깝고, 그 사이이면 수선의 발이 선분 위에 있습니다.

```js
function distSegment(p, a, b) {
  const ab = sub(b, a), ap = sub(p, a)
  const len2 = dot(ab, ab)
  const t = dot(ap, ab) // 나눗셈을 미뤄서 len2와 비교
  if (len2 === 0 || t <= 0) return Math.hypot(ap[0], ap[1])
  if (t >= len2) {
    const bp = sub(p, b)
    return Math.hypot(bp[0], bp[1])
  }
  return Math.abs(cross(ab, ap)) / Math.sqrt(len2)
}
distSegment([2, 3], [0, 0], [4, 0]) // 3 (수선의 발이 선분 위)
distSegment([6, 3], [0, 0], [4, 0]) // 3.6055... (끝점 B)
```

- 비교 `t <= 0`, `t >= len2`는 나눗셈 없이 정수로 합니다. `t / len2`를 만들면 오차가 생깁니다.
- `len2 === 0`은 A와 B가 같은 점(길이 0의 선분)입니다. 이때 `t / len2`는 0으로 나누게 되어 먼저 처리합니다.
- 수선의 발이 선분 위일 때 거리는 점과 직선 사이 거리 `|cross| / |AB|`입니다.
- 거리를 다른 거리와 비교하기만 하면 제곱 거리를 분수로 비교해서 제곱근을 피할 수 있습니다.

| P의 위치 | 가장 가까운 점 | 거리 |
|----------|----------------|------|
| `t`가 0 이하 | 끝점 A | A와 P 사이 거리 |
| `t`가 0과 `len2` 사이 | 수선의 발 | 외적의 절댓값을 AB 길이로 나눈 값 |
| `t`가 `len2` 이상 | 끝점 B | B와 P 사이 거리 |

**흔한 실수:** 점과 선분의 거리를 점과 직선의 거리 공식 하나로만 계산하는 것입니다. 점이 선분의 끝을 넘어서 있으면 틀린 값이 나옵니다.

## 선분 교차

두 선분 AB와 CD가 교차하는지는 CCW 네 번으로 판정합니다. 한 선분의 양 끝점이 다른 선분이 놓인 직선의 서로 반대편에 있고, 반대도 성립하면 교차합니다.

```js
function intersect(a, b, c, d) {
  const d1 = ccw(a, b, c), d2 = ccw(a, b, d)
  const d3 = ccw(c, d, a), d4 = ccw(c, d, b)
  if (d1 * d2 < 0 && d3 * d4 < 0) return true // 일반 교차
  if (d1 === 0 && inBox(a, b, c)) return true // 끝점이 닿음
  if (d2 === 0 && inBox(a, b, d)) return true
  if (d3 === 0 && inBox(c, d, a)) return true
  if (d4 === 0 && inBox(c, d, b)) return true
  return false
}
intersect([0, 0], [4, 4], [0, 4], [4, 0]) // true (X자)
intersect([0, 0], [2, 0], [3, 0], [5, 0]) // false
```

- `d1 * d2 < 0`은 C와 D가 직선 AB의 반대편이라는 뜻이고, `d3 * d4 < 0`은 A와 B가 직선 CD의 반대편이라는 뜻입니다. 둘 다 만족하면 선분의 안쪽에서 만납니다.
- 부호가 0인 경우는 끝점이 다른 직선 위에 있는 특수한 경우입니다. 그 점이 선분의 범위 안(`inBox`)에 있으면 끝점이 닿는 교차(T자, 꺾임)입니다.
- 네 점이 한 직선 위이면 네 `d`가 모두 0이고, 위 네 줄이 두 선분의 범위가 겹치는지 확인합니다. `[0,0]-[2,0]`과 `[3,0]-[5,0]`처럼 떨어져 있으면 `inBox`가 모두 `false`입니다. 겹치거나 한 점에서 닿으면 `true`입니다.
- 교차점이 필요한 문제라면 `intersect`로 먼저 거른 뒤 따로 계산합니다. 교차 여부만 필요하면 이 판정으로 충분하고, 교차점 좌표(분수)를 만들지 않아 오차가 없습니다.
- 선분이 N개이고 모든 쌍을 비교하면 O(N²)입니다. 쌍이 많으면 스위핑 기법(55편)이 필요합니다.

**문제의 단서:** "선분이 서로 교차하는가", "교차하는 선분 쌍의 수", 선분 그룹을 Union-Find(51편)로 묶는 문제의 판정 단계.

**흔한 실수:** 일반 교차 조건 `d1 * d2 < 0 && d3 * d4 < 0`만 쓰고 `0`인 경우(끝점 접촉, 겹침)를 빠뜨리는 것입니다. 또 외적 값 두 개를 `Math.sign` 없이 곱하면 큰 좌표에서 넘칩니다.

## 정수 좌표 유지와 실수 오차

입력이 정수 좌표이면 판정을 정수 연산으로만 끝낼 수 있고, 그러면 결과가 정확합니다. 부동소수점은 `0.1 + 0.2 === 0.30000000000000004`처럼 정확히 표현하지 못하는 값이 있어서, 같다·0이다 같은 판정이 오차에 흔들립니다(자세히는 02편).

| 하고 싶은 일 | 오차가 생기는 방법 | 정수로 유지하는 방법 |
|--------------|--------------------|----------------------|
| 거리 비교 | `Math.sqrt`로 거리를 구해 비교 | 제곱 거리끼리 비교 |
| 수직 판별 | 각도가 90인지 비교 | `dot(a, b) === 0` |
| 평행 판별 | 기울기를 나눠 비교 | `cross(a, b) === 0` |
| 넓이 비교 | 2로 나눈 넓이 | 2배 넓이 비교 |
| 방향 비교 | `Math.atan2`로 각도 | `cross`의 부호(`ccw`) |

- 정수 곱과 합이 안전한 범위(2^53 − 1)에 들어가는지 계산해 둡니다. 외적의 항은 `(좌표 차)²` 규모이므로 좌표 절댓값이 3 × 10^7 이하이면 안전합니다. 좌표가 10^9이면 항이 약 4 × 10^18로 넘칩니다.

```js
cross([2e9, 1], [1, 2e9]) // 4000000000000000000 (틀림)
// 정답은 3999999999999999999
```

- 넘치는 입력에서는 BigInt로 외적을 계산하고 부호만 취합니다. 부호가 필요하면 BigInt 결과를 `0n`과 비교합니다.

```js
function ccwBig(a, b, c) {
  const [ax, ay] = a.map(BigInt)
  const [bx, by] = b.map(BigInt)
  const [cx, cy] = c.map(BigInt)
  const v = (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)
  return v > 0n ? 1 : v < 0n ? -1 : 0
}
```

- 입력이 소수(`3.25`)인 경우, 자릿수가 고정이면 입력 문자열을 읽어 정수로 바꿉니다. 예를 들어 소수점 둘째 자리까지면 100을 곱한 정수로 변환합니다. `Math.round(4.35 * 100)`은 `435`이지만 `4.35 * 100` 자체는 `434.99999999999994`라서 `Math.floor`를 쓰면 틀립니다.
- 정수로 바꿀 수 없는 실수 입력은 비교에 허용 오차(epsilon)를 둡니다. `Number.EPSILON`은 1 근처의 수에만 맞는 값이라서, 좌표 크기에 맞춰 곱하거나 문제가 알려 준 허용 오차(`1e-9` 등)를 씁니다(자세히는 02편).
- 출력 요구가 "소수점 N자리"이면 마지막에만 `toFixed(N)`을 씁니다. 중간 계산을 반올림하면 오차가 쌓입니다.

**흔한 실수:** `Math.sqrt(...) === 정수`로 완전제곱 여부나 같은 거리를 판별하는 것입니다. 제곱 값으로 비교합니다.

## 45도 회전 변환

점 `(x, y)`를 `(x + y, x − y)`로 바꾸면 맨해튼 거리가 체비쇼프(Chebyshev) 거리로 바뀝니다. 체비쇼프 거리는 두 좌표 차의 최댓값 `max(|dx|, |dy|)`입니다.

변환 전 두 점의 차이가 `(a, b)`이면, 변환 후 차이는 `(a + b, a − b)`입니다. 아래 항등식이 성립하기 때문입니다.

```text
|a| + |b| = max(|a + b|, |a - b|)
```

- `a`와 `b`의 부호가 같으면 `|a + b| = |a| + |b|`이고 `|a − b|`는 그보다 작거나 같습니다. 부호가 다르면 반대입니다. 어느 경우든 둘 중 큰 쪽이 `|a| + |b|`입니다.
- 이 변환은 45도 회전과 √2배 확대가 합쳐진 것입니다. 원래의 맨해튼 거리가 변환 뒤 체비쇼프 거리와 정확히 같고 √2 배율이 남지 않습니다.
- 변환된 좌표 `(x + y, x − y)`는 합과 차의 짝수·홀수가 같은 점만 나옵니다. 변환된 격자의 모든 점이 원래의 점에 대응하는 것은 아닙니다.

효과는 두 가지입니다.

- 맨해튼 거리의 마름모(거리 R 이내의 점들)가 축에 평행한 정사각형이 됩니다. 영역 질의가 사각형 질의로 바뀌어 누적합(29편)이나 구간 자료구조에 얹을 수 있습니다.
- 두 점 사이 맨해튼 거리의 최댓값은 `x + y`의 최대와 최소의 차, `x − y`의 최대와 최소의 차 중 큰 값입니다. 모든 쌍을 보지 않고 O(N)에 구합니다.

```js
function maxManhattan(pts) {
  let s1 = -Infinity, s2 = Infinity
  let d1 = -Infinity, d2 = Infinity
  for (const [x, y] of pts) {
    s1 = Math.max(s1, x + y); s2 = Math.min(s2, x + y)
    d1 = Math.max(d1, x - y); d2 = Math.min(d2, x - y)
  }
  return Math.max(s1 - s2, d1 - d2)
}
maxManhattan([[0, 0], [3, 1], [-2, 4]]) // 8
```

- 위 점들에서 `x + y`는 0, 4, 2이고 최대·최소의 차는 4입니다. `x − y`는 0, 2, −6이고 차는 8입니다. 큰 쪽 8이 답이고, `(3, 1)`과 `(−2, 4)` 사이 `5 + 3 = 8`과 같습니다.
- 모든 쌍을 비교하는 방법은 O(N²)입니다. 같은 값을 구하는 데 이 변환은 O(N)입니다.

**문제의 단서:** "맨해튼 거리가 가장 먼 두 점", "맨해튼 거리 R 이내의 점", 격자에서 상하좌우 이동의 영향 범위가 마름모인 문제.

**흔한 실수:** 변환 후 거리를 √2로 나누는 것입니다. 이 변환은 나눗셈 없이 거리를 그대로 보존합니다.

## 핵심 정리

- 좌표는 길이 2의 배열로 다루고, 거리는 비교만 하면 제곱 거리를 씁니다. 격자 문제(화면 좌표계)에서는 CCW의 좌우 의미가 뒤바뀝니다.
- 내적의 부호는 각의 종류를, 0은 수직을 알려 줍니다. 외적의 부호는 방향을, 0은 평행을, 크기는 평행사변형 넓이를 알려 줍니다.
- CCW는 `cross(b − a, c − a)`의 부호이고, 점과 직선의 위치, 평행, 선분 위 여부, 선분 교차의 바탕입니다. 선분 위 판정은 CCW 0에 범위 확인(`inBox`)을 더해야 합니다.
- 점과 선분의 거리는 정사영 위치 `t`로 끝점과 수선의 발을 가르고, 선분 교차는 CCW 네 번과 끝점 접촉·겹침 처리로 판정합니다.
- 정수 좌표는 `sqrt`, 각도, 기울기를 피하고 내적·외적·제곱 거리로 정확히 판정합니다. 좌표 절댓값이 3 × 10^7을 넘으면 외적이 안전한 정수 범위를 넘으므로 BigInt를 씁니다.
- `(x, y)`를 `(x + y, x − y)`로 바꾸면 맨해튼 거리가 체비쇼프 거리가 되어, 맨해튼 최대 거리를 O(N)에 구합니다.
