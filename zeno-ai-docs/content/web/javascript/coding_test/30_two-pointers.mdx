## 투 포인터 개념

투 포인터(two pointers)는 배열 위에 인덱스 두 개를 두고, 조건에 따라 둘을 움직이며 답을 찾는 기법입니다. 이중 반복문이 훑는 O(N²)개의 쌍 중에서 답이 될 수 없는 쌍을 건너뛰어 O(N)으로 줄입니다.

- 포인터는 한 번 지나간 자리로 돌아가지 않습니다. 각 포인터가 최대 N번 움직이므로 전체 이동이 2N 이하이고 시간은 O(N)입니다. 조건 검사 한 번이 O(1)이어야 합니다.
- 쓰려면 단조성이 필요합니다. 포인터를 한쪽으로 움직일 때 값(합, 길이 등)이 한 방향으로만 변해야, 어느 포인터를 움직일지 바로 정할 수 있습니다.
- 추가 공간은 O(1)입니다. 자료구조 없이 인덱스 변수만 씁니다.

| 형태 | 시작 위치 | 이동 방향 | 대표 유형 |
|------|-----------|-----------|-----------|
| 양 끝 포인터 | 왼쪽 끝과 오른쪽 끝 | 서로 가운데로 | 회문, 정렬된 배열의 두 수의 합 |
| 같은 방향 포인터 | 둘 다 왼쪽 | 둘 다 오른쪽으로 | 구간 합, 중복 제거, 병합 |

- 쓰는 단서: "연속 부분 배열", "정렬된 배열에서 합이 ~인 쌍", "제자리(in-place)로 정리" 같은 문장과 N이 10^5 이상이라 O(N²)이 안 되는 제한입니다(자세히는 14편).
- 이분 탐색(28편)이 원소 하나를 O(log N)에 찾는다면, 투 포인터는 쌍이나 구간 전체를 O(N)에 훑습니다.

## 양 끝 포인터

양 끝 포인터는 `l = 0`, `r = N - 1`에서 시작해 `l < r`인 동안 가운데로 좁혀 오는 방식입니다. 두 포인터가 만나면 끝납니다. 매 단계 둘 중 하나가 한 칸 움직이므로 단계는 최대 N번입니다.

회문 검사가 가장 간단한 예입니다(자세히는 07편).

```js
function isPalindrome(s) {
  let l = 0, r = s.length - 1
  while (l < r) {
    if (s[l] !== s[r]) return false
    l++
    r--
  }
  return true
}
isPalindrome('level') // true
isPalindrome('abca')  // false
```

- 반복 조건이 `l <= r`이 아니라 `l < r`입니다. 같은 위치를 자기 자신과 비교하는 일은 의미가 없습니다.
- 홀수 길이에서는 가운데 원소 하나가 남아 비교하지 않고, 짝수 길이에서는 `l`과 `r`이 엇갈리며 끝납니다.
- 어느 포인터를 움직일지는 문제의 조건이 정합니다. 회문은 항상 둘 다 움직이고, 아래의 두 수의 합은 합의 크기에 따라 하나만 움직입니다.

## 같은 방향 포인터

같은 방향 포인터는 두 포인터가 모두 왼쪽에서 오른쪽으로 움직이는 방식입니다. 역할이 다른 두 유형이 있습니다.

| 유형 | 앞 포인터 | 뒤 포인터 |
|------|-----------|-----------|
| 읽기·쓰기 | 읽기 위치(모든 칸을 훑음) | 쓰기 위치(남길 값을 채움) |
| 구간 | 구간의 끝(넓힘) | 구간의 시작(좁힘) |

읽기·쓰기 포인터는 새 배열을 만들지 않고 같은 배열 안에서 값을 걸러 냅니다.

```js
function removeValue(a, v) {
  let w = 0 // 쓰기 위치
  for (let rd = 0; rd < a.length; rd++) {
    if (a[rd] !== v) a[w++] = a[rd]
  }
  a.length = w
  return w
}
const x = [3, 2, 2, 3, 4]
removeValue(x, 3) // 3
x                 // [2, 2, 4]
```

- 쓰기 위치는 항상 읽기 위치 이하라서 아직 읽지 않은 값을 덮어쓰지 않습니다.
- `a.length`를 줄이면 그 뒤의 원소가 지워집니다. 길이만 필요한 문제라면 반환값 `w`를 쓰고 `length`는 건드리지 않아도 됩니다.
- `filter`는 새 배열을 만들지만 이 방식은 O(1) 추가 공간입니다.

구간 유형은 아래 "연속 부분 배열"과 "부분합 Two Pointer"에서 다룹니다.

## 두 수의 합

정렬된 배열에서 합이 `target`인 두 원소의 위치를 찾습니다. 양 끝에서 시작해 합이 작으면 `l`을, 크면 `r`을 움직입니다.

```js
function twoSum(a, target) {
  let l = 0, r = a.length - 1
  while (l < r) {
    const sum = a[l] + a[r]
    if (sum === target) return [l, r]
    if (sum < target) l++
    else r--
  }
  return null
}
twoSum([1, 3, 4, 6, 9], 13) // [2, 4] (4 + 9)
twoSum([1, 3, 4, 6, 9], 2)  // null
```

`a = [1, 3, 4, 6, 9]`, `target = 13`의 추적입니다.

| 단계 | l | r | `a[l] + a[r]` | 판단 |
|------|---|---|---------------|------|
| 1 | 0 | 4 | 10 | 작다, `l` 증가 |
| 2 | 1 | 4 | 12 | 작다, `l` 증가 |
| 3 | 2 | 4 | 13 | 같다, 반환 |

왜 맞는가: `sum < target`이면 `a[l]`은 현재 `r` 이하 어느 원소와 짝지어도 합이 `a[r]`과의 합(= `sum`) 이하라서 `target`에 못 미칩니다. 그러므로 `a[l]`은 답에 쓰일 수 없어 버려도 됩니다. `sum > target`이면 `a[r]`에 대해 같은 논리가 성립합니다. 매 단계 후보 하나를 확실히 지우므로 N − 1단계 안에 끝납니다.

- 시간 O(N)입니다. 정렬되어 있지 않으면 먼저 정렬해야 하고 그러면 O(N log N)입니다.
- 정렬하지 않고 `Map`에 본 값을 저장해 `target - x`를 찾으면 O(N)에 풀립니다(자세히는 10편). 인덱스가 필요하고 정렬하면 위치가 섞이므로 이 경우는 해시가 낫습니다.
- 정렬된 입력에서 쌍의 개수를 세려면 같은 값이 여러 개일 때 곱을 더합니다. 합이 맞으면 `l`쪽 같은 값의 개수 × `r`쪽 같은 값의 개수를 더하고 두 포인터를 같은 값 구간 밖으로 옮깁니다. `l`과 `r`이 가리키는 값이 같으면 그 구간의 개수 m에서 `m × (m − 1) / 2`개입니다.

```js
// [1, 2, 2, 3, 3, 4]에서 합이 5인 쌍
// (1,4) 1개 + (2,3) 2 × 2 = 4개 → 5개
```

**흔한 실수:** 숫자 배열을 `sort()`에 비교 함수 없이 넘기는 것입니다. 기본 정렬은 값을 문자열로 바꿔 비교해서 `[1, 10, 2]`가 그대로 나옵니다(자세히는 26편).

```js
[1, 10, 2].sort()               // ❌ [1, 10, 2]
[1, 10, 2].sort((a, b) => a - b) // ✅ [1, 2, 10]
```

## 연속 부분 배열

연속 부분 배열 문제에서 같은 방향 포인터는 구간 `[start, end]`를 유지합니다. `end`를 하나씩 늘려 새 원소를 구간에 넣고, 조건이 깨지면 `start`를 늘려 조건이 다시 맞을 때까지 줄입니다.

원소가 모두 양수이면 구간을 늘릴수록 합이 커지고 줄일수록 작아져서 단조성이 성립합니다. "합이 K 이하인 연속 부분 배열의 개수"를 셉니다.

```js
function countAtMost(a, K) {
  let start = 0, sum = 0, ans = 0
  for (let end = 0; end < a.length; end++) {
    sum += a[end]
    while (sum > K) sum -= a[start++]
    ans += end - start + 1
  }
  return ans
}
countAtMost([2, 1, 3, 1], 4) // 7
```

- 각 `end`에서 조건을 만족하는 구간의 시작은 `start`부터 `end`까지라서, `end`로 끝나는 올바른 구간이 `end - start + 1`개입니다.
- `[2, 1, 3, 1]`, `K = 4`: `end = 0`에서 1개, `end = 1`에서 합 3이라 2개, `end = 2`에서 합이 6이 되어 `start`가 1(합 4), 구간 2개, `end = 3`에서 합 5가 되어 `start`가 2(합 4), 구간 2개입니다. 합은 1 + 2 + 2 + 2 = 7입니다.
- `start`는 줄어들지 않고 `end`는 N번 늘어나므로 두 포인터의 이동은 합쳐 2N 이하이고 시간 O(N)입니다. `while`이 안에 있지만 O(N²)이 아닙니다(분할 상환, 자세히는 14편).
- 가장 긴 구간을 구하려면 매 `end`에서 `end - start + 1`의 최댓값을 갱신합니다.
- 구간 길이를 고정하거나 구간 안의 값을 관리하는 확장은 슬라이딩 윈도우입니다(자세히는 31편).

**제한:** 음수 원소가 있으면 구간을 늘려도 합이 줄 수 있어서 단조성이 깨집니다. 그때는 누적합과 해시(29편)를 씁니다.

## 중복 제거

정렬된 배열에서 같은 값은 서로 붙어 있으므로, 읽기·쓰기 포인터로 앞의 값과 다른 값만 남기면 제자리에서 중복을 제거할 수 있습니다.

```js
function dedupe(a) {
  if (a.length === 0) return 0
  let w = 1 // a[0]은 항상 남긴다
  for (let rd = 1; rd < a.length; rd++) {
    if (a[rd] !== a[w - 1]) a[w++] = a[rd]
  }
  a.length = w
  return w
}
const u = [1, 1, 2, 2, 2, 3]
dedupe(u) // 3
u         // [1, 2, 3]
```

- 비교 대상은 `a[rd - 1]`이 아니라 `a[w - 1]`, 즉 마지막으로 남긴 값입니다. 쓰기 위치 앞이 이미 덮어쓰였을 수 있어서 읽기 위치 바로 앞과 다를 수 있습니다.
- 빈 배열은 `a[0]`이 없으므로 먼저 걸러 냅니다.
- 시간 O(N), 공간 O(1)입니다. 정렬되어 있지 않으면 정렬(O(N log N)) 후 적용하거나 `Set`으로 걸러냅니다. `Set`은 `SameValueZero`로 같은 값을 하나만 남기고 삽입 순서를 유지합니다(자세히는 10편).
- 같은 값을 최대 두 개까지 남기는 변형은 비교 대상을 `a[w - 2]`로 바꿉니다.

## 정렬과 투 포인터

정렬은 배열에 순서 정보를 만들어 단조성을 얻는 수단입니다. 순서가 없는 배열에서는 한 포인터를 움직여도 값이 어느 방향으로 변할지 알 수 없습니다. 정렬하면 "합이 작으면 왼쪽을 키운다" 같은 판단이 가능해집니다.

- 정렬이 O(N log N)이라 전체 시간은 정렬이 지배합니다. 투 포인터 구간만 O(N)입니다.
- 정렬은 원래 위치를 잃습니다. 위치가 답이면 값과 원래 인덱스를 함께 정렬합니다(인덱스 정렬, 자세히는 26편).
- 순서가 상관없는 "쌍 찾기" 문제에서 정렬 후 투 포인터는 해시 없이 O(1) 공간으로 풀 수 있는 장점이 있습니다.

합이 `target`에 가장 가까운 두 원소를 구하는 문제입니다. 정렬된 배열을 양 끝 포인터로 훑으며 차이의 최솟값을 갱신합니다.

```js
function closestPair(a, target) { // a는 정렬됨
  let l = 0, r = a.length - 1
  let best = null, gap = Infinity
  while (l < r) {
    const sum = a[l] + a[r]
    const d = Math.abs(sum - target)
    if (d < gap) { gap = d; best = [a[l], a[r]] }
    if (sum < target) l++
    else if (sum > target) r--
    else break
  }
  return best
}
closestPair([1, 4, 5, 7, 10], 13)
// [4, 10] (합 14, 차 1. [5, 7]도 차 1이지만 나중에 찾음)
```

- 합이 `target`보다 작으면 `l`을, 크면 `r`을 움직이는 규칙은 두 수의 합과 같습니다. 정확히 같을 때는 더 가까울 수 없으니 멈춥니다.
- 값이 아니라 차이 기준으로 짝을 찾는 문제도 정렬 후 같은 방향 포인터로 풀립니다. `a[j] - a[i]`는 `j`가 커질수록 커지고 `i`가 커질수록 작아지므로 단조성이 있습니다.

## 부분합 Two Pointer

양수 배열에서 구간 합이 정확히 K인 구간의 개수를 구합니다. "연속 부분 배열"의 코드에서 `ans`를 세는 조건만 바뀝니다.

```js
function countExact(a, K) {
  let start = 0, sum = 0, count = 0
  for (let end = 0; end < a.length; end++) {
    sum += a[end]
    while (sum > K) sum -= a[start++]
    if (sum === K) count++
  }
  return count
}
countExact([1, 2, 1, 3, 2], 3) // 3 ([1,2] [2,1] [3])
```

- `sum > K`이면 `start`를 늘려 합을 줄이고, 줄인 뒤 `sum === K`이면 구간 하나를 센 것입니다.
- 원소가 모두 양수라서 `end`를 고정하면 합이 K인 `start`는 많아야 하나입니다. 그래서 한 번만 세면 됩니다.
- 0이 섞이면 같은 `end`에서 합이 K인 `start`가 여러 개일 수 있어 위 코드가 개수를 놓칩니다. 0과 음수가 있으면 누적합과 해시(29편)를 씁니다.
- 합이 K 이상인 가장 짧은 구간은 `while (sum >= K)` 안에서 길이를 갱신하는 형태입니다(자세히는 31편).

| 조건 | 포인터 이동 | 쓰는 이유 |
|------|-------------|-----------|
| 합이 K보다 큼 | `start` 증가 | 구간을 줄여 합을 내림 |
| 합이 K보다 작음 | `end` 증가 | 구간을 넓혀 합을 올림 |
| 합이 K | 개수 증가 | 이후 `end`를 늘리며 계속 |

## 세 수의 합 응용

세 수의 합은 한 원소를 고정하고 나머지 두 원소를 두 수의 합으로 찾습니다. 합이 0인 서로 다른 세 값의 조합을 모두 구합니다. 중복 조합은 한 번만 냅니다.

```js
function collect(a, i, res) { // a는 정렬됨, a[i]를 고정
  let l = i + 1, r = a.length - 1
  while (l < r) {
    const s = a[i] + a[l] + a[r]
    if (s < 0) l++
    else if (s > 0) r--
    else {
      res.push([a[i], a[l++], a[r--]])
      while (l < r && a[l] === a[l - 1]) l++
    }
  }
}
```

```js
function threeSum(a) {
  a.sort((p, q) => p - q)
  const res = []
  for (let i = 0; i < a.length - 2; i++) {
    if (i > 0 && a[i] === a[i - 1]) continue
    collect(a, i, res)
  }
  return res
}
```

합이 0이면 조합을 담고 `l`을 같은 값 밖으로 옮깁니다. `r` 쪽 중복은 따로 건너뛰지 않아도 됩니다. `l`의 값이 바뀌면 이전 조합과 다른 조합이기 때문입니다.

```js
threeSum([-1, 0, 1, 2, -1, -4])
// [[-1, -1, 2], [-1, 0, 1]]
threeSum([0, 0, 0, 0]) // [[0, 0, 0]]
```

- 정렬 O(N log N)에 바깥 반복 N번 × 안쪽 투 포인터 O(N)이라 전체 O(N²)입니다. 모든 세 쌍을 보는 O(N³)보다 빠릅니다.
- 중복을 건너뛰는 위치가 두 군데입니다. 고정 원소 `i`(앞 원소와 같으면 건너뜀)와 합이 맞은 뒤의 `l`입니다. 이를 빼먹으면 같은 조합이 여러 번 나옵니다.
- 합이 `target`으로 일반화되고 `i`를 하나 더 고정하면 네 수의 합(O(N³))입니다. k개의 합은 O(N^(k − 1))입니다.
- 가장 가까운 합이나 합이 K 이하인 조합의 개수도 같은 구조입니다. 합이 `target` 이하인 조합은 `s <= target`일 때 `r - l`개를 한꺼번에 세고 `l`을 올립니다.

## 정렬된 두 배열 병합

정렬된 두 배열 `a`, `b`를 합쳐 정렬된 하나로 만듭니다. 배열마다 읽기 포인터를 두고 더 작은 값을 결과에 넣은 뒤 그 포인터를 올립니다.

```js
function merge(a, b) {
  const res = []
  let i = 0, j = 0
  while (i < a.length && j < b.length) {
    res.push(a[i] <= b[j] ? a[i++] : b[j++])
  }
  while (i < a.length) res.push(a[i++])
  while (j < b.length) res.push(b[j++])
  return res
}
merge([1, 4, 7], [2, 4, 9, 10]) // [1, 2, 4, 4, 7, 9, 10]
```

- 두 포인터는 각각 한 방향으로만 움직이고 합쳐 N + M번 이동하므로 시간 O(N + M)입니다.
- 값이 같을 때 `a`의 값을 먼저 넣으면(`<=`) 같은 값의 원래 순서가 유지되는 안정 병합입니다.
- 한쪽이 끝나면 남은 쪽을 그대로 붙입니다. 이미 정렬되어 있어서 비교가 필요 없습니다.
- 이 병합이 병합 정렬의 결합 단계이며(자세히는 27편), 두 정렬된 배열의 교집합·차집합도 같은 두 포인터로 구합니다. 같으면 둘 다 올리고, 다르면 작은 쪽을 올립니다.

## 세 구간 분할

세 구간 분할(Dutch national flag)은 값이 세 종류(0, 1, 2)뿐인 배열을 한 번의 순회, 추가 공간 없이 정렬하는 방법입니다. 포인터 세 개 `lo`, `mid`, `hi`를 씁니다.

```js
function sortThree(a) {
  let lo = 0, mid = 0, hi = a.length - 1
  const swap = (i, j) => { [a[i], a[j]] = [a[j], a[i]] }
  while (mid <= hi) {
    if (a[mid] === 0) swap(lo++, mid++)
    else if (a[mid] === 1) mid++
    else swap(mid, hi--)
  }
  return a
}
sortThree([2, 0, 2, 1, 1, 0]) // [0, 0, 1, 1, 2, 2]
```

항상 성립하는 불변식입니다.

| 구간 | 내용 |
|------|------|
| `a[0..lo-1]` | 모두 0 |
| `a[lo..mid-1]` | 모두 1 |
| `a[mid..hi]` | 아직 확인하지 않음 |
| `a[hi+1..N-1]` | 모두 2 |

- `a[mid]`가 0이면 `lo` 자리와 바꿉니다. `lo` 자리의 값은 1이거나 `mid`와 같은 위치라서 `mid`도 같이 올립니다.
- 2이면 `hi` 자리와 바꾸고 `hi`만 내립니다. 가져온 값을 아직 모르므로 `mid`를 올리면 안 됩니다.
- 한 번의 순회로 끝나므로 시간 O(N), 공간 O(1)입니다. 값을 세어 다시 채우는 계수 정렬(자세히는 27편)은 두 번 훑습니다.
- 기준값(pivot)보다 작음, 같음, 큼의 세 구간으로 나누는 퀵 정렬의 3-way 분할과 같은 구조입니다.

**흔한 실수:** 2를 만났을 때 `mid`도 함께 올리는 것입니다. `hi` 자리에서 가져온 값을 확인하지 못하고 지나쳐서, 그 값이 0이나 2였다면 제자리를 잃습니다.

## 핵심 정리

- 투 포인터는 인덱스 두 개가 각각 한 방향으로만 움직여 전체 이동이 2N 이하이므로 O(N)이며, 단조성이 있어야 쓸 수 있습니다.
- 양 끝 포인터는 가운데로 좁히고(회문, 정렬된 두 수의 합), 같은 방향 포인터는 읽기·쓰기(제자리 제거, 중복 제거)나 구간의 끝과 시작(연속 부분 배열)으로 쓰입니다.
- 두 수의 합은 합이 작으면 `l`, 크면 `r`을 옮기고, 그 이유는 버려지는 포인터가 어떤 짝과도 답이 될 수 없기 때문입니다.
- 구간 합 유형은 원소가 모두 양수일 때만 통하며, 음수나 0이 있으면 누적합과 해시를 씁니다.
- 세 수의 합은 한 원소를 고정하고 나머지에 두 수의 합을 적용해 O(N²)이며, 정렬한 뒤 중복 건너뛰기가 필요합니다.
- 두 정렬된 배열의 병합은 O(N + M), 값이 세 종류인 배열은 `lo`·`mid`·`hi` 세 포인터로 한 번에 분할합니다.
