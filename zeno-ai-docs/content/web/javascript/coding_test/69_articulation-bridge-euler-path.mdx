## 단절점 (Articulation Point)

단절점(articulation point, cut vertex)은 그 정점과 붙은 간선을 지웠을 때 연결 요소의 수가 늘어나는 무방향 그래프의 정점입니다. 네트워크에서 하나만 고장 나도 망이 갈라지는 지점입니다(정점·간선·연결 요소는 35편, DFS는 36편).

이 문서의 무방향 예제 그래프입니다. 삼각형 `0-1-2`와 삼각형 `3-4-5`가 간선 `2-3`으로 이어지고, 정점 6이 5에 매달려 있습니다.

```js
const edges = [
  [0, 1], [1, 2], [2, 0], [2, 3],
  [3, 4], [4, 5], [5, 3], [5, 6],
]
const n = 7
const adj = Array.from({ length: n }, () => [])
for (const [a, b] of edges) {
  adj[a].push(b)
  adj[b].push(a)
}
```

- 단절점은 2, 3, 5입니다. 2를 지우면 `{0, 1}`과 `{3, 4, 5, 6}`으로 갈라집니다.
- 모든 정점을 하나씩 지워 보는 방법은 정점마다 O(V + E)라서 전체 O(V(V + E))입니다. DFS 한 번으로 O(V + E)에 구합니다.

무방향 그래프를 DFS하면 간선은 두 종류입니다. 새 정점으로 내려가는 트리 간선과, 이미 방문한 조상으로 올라가는 역방향 간선입니다. 무방향 DFS에는 서로 다른 가지를 잇는 간선이 없습니다. 두 값을 정의합니다.

- `tin[u]`: u를 처음 방문한 순서 번호(발견 시간)입니다.
- `low[u]`: u의 서브트리에서 역방향 간선을 최대 한 번 써서 닿을 수 있는 가장 작은 `tin`입니다. `tin[u]` 자신, u에서 나가는 역방향 간선이 가리키는 정점의 `tin`, 자식 v의 `low[v]` 가운데 최솟값으로 계산합니다.

판정 규칙은 두 가지입니다.

| 정점 | 단절점 조건 |
|------|-------------|
| DFS 루트 | DFS 트리의 자식이 2개 이상 |
| 루트가 아닌 u | 어떤 자식 v에 대해 `low[v] >= tin[u]` |

- `low[v] >= tin[u]`는 v의 서브트리가 u 위쪽(u의 조상)으로 올라갈 길이 없다는 뜻입니다. u를 지우면 그 서브트리가 떨어져 나갑니다.
- 루트는 조상이 없어서 모든 자식에서 `low[v] >= tin[루트]`가 성립합니다. 그래서 자식 수로 따로 판정합니다. 자식이 하나면 나머지 정점이 모두 그 서브트리 안에 있어서 루트를 지워도 갈라지지 않습니다.

```js
function dfs(u, p) {              // p: 부모 정점(루트는 -1)
  tin[u] = low[u] = timer++
  let kids = 0
  for (const v of adj[u]) {
    if (v === p) continue
    if (tin[v] === -1) {
      dfs(v, u)
      kids++
      low[u] = Math.min(low[u], low[v])
      if (p !== -1 && low[v] >= tin[u]) isCut[u] = true
    } else low[u] = Math.min(low[u], tin[v])
  }
  if (p === -1 && kids > 1) isCut[u] = true
}
```

`tin`(−1로 초기화)과 `low`, `isCut`은 길이 n 배열이고 `timer`는 0으로 시작하며, 모두 `dfs` 바깥에 선언합니다. 연결되지 않은 그래프도 처리하도록 바깥에서 `for (let s = 0; s < n; s++) if (tin[s] === -1) dfs(s, -1)`로 모든 정점에서 시작합니다.


예제 그래프에서 0번을 루트로 한 DFS 결과입니다. 이웃은 입력 순서대로 방문합니다.

| 정점 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|------|---|---|---|---|---|---|---|
| `tin` | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| `low` | 0 | 0 | 0 | 3 | 3 | 3 | 6 |

- 정점 2: 자식 3의 `low`가 3이고 `tin[2]`는 2라서 3 ≥ 2, 단절점입니다.
- 정점 3: 자식 4의 `low`가 3이고 `tin[3]`은 3이라서 3 ≥ 3, 단절점입니다(같아도 단절점).
- 정점 5: 자식 6의 `low`가 6이고 `tin[5]`는 5라서 6 ≥ 5, 단절점입니다.
- 정점 1: 자식 2의 `low`가 0이라 0 ≥ 1이 아니므로 아닙니다. 루트 0은 자식이 1개라서 아닙니다.

- 시간은 O(V + E), 공간은 O(V)입니다. 루트 판정은 DFS 트리마다 따로 합니다.
- 단절점 판정에서는 부모를 건너뛰는 `if (v === p) continue`가 없어도 결과가 같습니다. 부모의 `tin`으로 `low`가 내려가도 `low[v] >= tin[u]`는 그대로이기 때문입니다. 단절선에서는 건너뛰어야 합니다(아래 단절선).
- 재귀 DFS는 일직선에 가까운 그래프에서 깊이가 정점 수만큼 커져 호출 스택이 넘칠 수 있습니다. 정점이 많으면 반복문으로 바꿉니다(자세히는 86편).

**문제의 단서:** "한 곳이 고장 났을 때 연결이 끊기는 지점", "제거하면 둘로 갈라지는 정점"이 나오면 단절점입니다.

**흔한 실수:**

- 루트에도 `low[v] >= tin[u]`를 적용하는 것입니다. 루트는 항상 참이 되어 자식이 하나뿐이어도 단절점이 됩니다.
- 루트의 자식 수를 DFS 트리의 자식이 아니라 이웃 수로 세는 것입니다. 이웃이 여럿이어도 한 자식의 서브트리 안에서 서로 이어져 있으면 자식은 하나입니다.
- 비연결 그래프에서 0번에서만 DFS를 시작하는 것입니다.

## 단절선 (Bridge)

단절선(bridge)은 그 간선을 지웠을 때 연결 요소의 수가 늘어나는 간선입니다. 같은 말로 어떤 사이클에도 속하지 않는 간선입니다. 트리의 간선은 모두 단절선입니다.

DFS 트리 간선 `u → v`(u가 부모)가 단절선일 조건은 다음 하나입니다.

```text
low[v] > tin[u]
```

v의 서브트리에서 u를 포함해 u 위쪽으로 가는 역방향 간선이 없다는 뜻입니다. 단절점은 `>=`, 단절선은 `>`입니다. 서브트리에서 u 자신으로 올라오는 역방향 간선이 있으면(`low[v] == tin[u]`) 간선 `u-v`는 사이클 위에 있어서 단절선이 아니지만 u는 여전히 단절점일 수 있습니다.

역방향 간선은 트리 간선이 아니므로 단절선이 될 수 없어서 판정은 트리 간선에서만 합니다.

```js
function dfs(u, pe) {            // pe: u로 들어온 간선의 id
  tin[u] = low[u] = timer++
  for (const [v, id] of adj[u]) {
    if (id === pe) continue
    if (tin[v] === -1) {
      dfs(v, id)
      low[u] = Math.min(low[u], low[v])
      if (low[v] > tin[u]) bridges.push(id)
    } else low[u] = Math.min(low[u], tin[v])
  }
}
```


- `tin`, `low`, `timer`, 결과 배열 `bridges`는 단절점 코드와 같은 방식으로 `dfs` 바깥에 선언합니다. 인접 리스트는 간선 목록의 `id`번째 간선 `[a, b]`에 대해 `adj[a].push([b, id]); adj[b].push([a, id])`로 만듭니다.
- 예제 그래프의 결과는 간선 id 3(`2-3`)과 7(`5-6`)입니다. 앞의 표에서 `low[3] = 3 > tin[2] = 2`이고 `low[6] = 6 > tin[5] = 5`입니다. 간선 `3-4`는 `low[4] = 3`이 `tin[3] = 3`과 같아서 단절선이 아닙니다.
- 시간은 O(V + E)입니다. 문제가 "정점 쌍을 작은 번호가 앞에 오도록 정렬해 출력"을 요구하면 `edges[id]`의 두 끝을 정렬한 뒤 목록을 정렬합니다.

단절점과 단절선을 비교합니다.

| 항목 | 단절점 | 단절선 |
|------|--------|--------|
| 대상 | 정점 | 간선 |
| 조건 | 루트: 자식 2개 이상, 그 외: `low[v] >= tin[u]` | `low[v] > tin[u]` |
| 부모 건너뛰기 | 하지 않아도 됨 | 부모 간선 하나만 건너뜀 |
| 루트 특수 처리 | 필요 | 불필요 |

부모로 되돌아가는 간선을 역방향 간선으로 세면 안 됩니다. 부모 정점이 아니라 부모로 온 간선의 id로 건너뜁니다. 정점 기준으로 건너뛰면 같은 두 정점을 잇는 평행 간선(multi-edge)이 있을 때 둘 다 건너뛰어서 사이클을 놓칩니다.

```js
// 0-1 간선이 두 개: 서로 사이클이라 단절선이 아니다
const edges2 = [[0, 1], [0, 1]]
// id 기준: 두 번째 간선이 역방향 간선으로 잡혀 단절선 없음 ✅
// 정점 기준: 두 간선을 모두 건너뛰어 단절선 2개 ❌
```

**문제의 단서:** "지우면 네트워크가 둘로 나뉘는 연결선", "중요한 도로·회선"이 나오면 단절선입니다. 평행 간선이 입력에 나올 수 있는지 먼저 확인합니다.

**흔한 실수:**

- 단절점의 `>=`를 단절선에 그대로 쓰는 것입니다. 모든 트리 간선이 단절선으로 나옵니다.
- 부모 정점을 건너뛰고 평행 간선을 처리하지 않는 것입니다.
- 이미 방문한 정점(역방향 간선)에서 `tin[v]`가 아니라 `low[v]`를 쓰는 것입니다. low의 정의는 역방향 간선을 한 번만 쓰는 것이므로 방문한 정점에는 `tin[v]`를 씁니다.

## 이중 연결 요소 (Biconnected Component) 개요

이중 연결 요소(biconnected component, 블록)는 정점 하나를 지워도 연결이 유지되는 극대 부분 그래프입니다. 간선 하나만 있는 부분도 블록입니다. 두 간선이 한 단순 사이클 위에 있으면 같은 블록이고, 그래서 간선은 정확히 한 블록에 속합니다. 정점은 여러 블록에 속할 수 있고, 두 블록 이상에 속하는 정점이 단절점입니다.

예제 그래프의 블록은 네 개입니다.

| 블록 | 간선 | 비고 |
|------|------|------|
| A | `0-1`, `1-2`, `2-0` | 삼각형 |
| B | `2-3` | 단절선 하나 |
| C | `3-4`, `4-5`, `5-3` | 삼각형 |
| D | `5-6` | 단절선 하나 |

- 정점 2는 A와 B, 정점 3은 B와 C, 정점 5는 C와 D에 속합니다. 이 세 정점이 단절점입니다.
- 모든 단절선은 정점 두 개만 가진 블록입니다. 단절선은 그 간선만으로 하나의 블록입니다.

블록을 실제로 구하는 방법은 Hopcroft와 Tarjan(1973)의 알고리즘으로, DFS를 하면서 간선을 스택에 쌓다가 `low[v] >= tin[u]`인 순간에 그 간선까지 스택에서 꺼내 한 블록으로 묶습니다. 단절선 코드의 DFS 안에서 달라지는 부분입니다(스택 `stack`과 결과 `blocks`는 바깥에 선언).

```js
if (tin[v] !== -1) {                  // 이미 방문한 정점
  low[u] = Math.min(low[u], tin[v])
  if (tin[v] < tin[u]) stack.push(id) // 조상으로 가는 간선만 한 번
  continue
}
stack.push(id)                        // 트리 간선
dfs(v, id)
low[u] = Math.min(low[u], low[v])
if (low[v] >= tin[u]) {               // u가 이 블록의 최상단
  const block = []
  let e
  do { e = stack.pop(); block.push(e) } while (e !== id)
  blocks.push(block)
}
```

- 시간은 O(V + E)입니다.
- 블록과 단절점을 노드로 하고 블록과 그 안의 단절점을 간선으로 이으면 트리가 됩니다. 이를 블록-단절점 트리(block-cut tree)라 하고, "정점 x를 지우면 a와 b가 끊기는가" 같은 질의를 트리 위의 경로 문제로 바꿉니다.
- 간선이 없는 고립 정점은 이 방식으로는 블록에 잡히지 않습니다. 문제에서 고립 정점을 블록으로 세는지 확인합니다.
- 정점 연결성(정점을 지움)과 간선 연결성(간선을 지움)은 다른 개념입니다. 아래 단절선 트리와 혼동하지 않습니다.

## 단절선 트리 (Bridge Tree) 개요

이중 간선 연결 요소(2-edge-connected component)는 간선 하나를 지워도 연결이 유지되는 극대 부분 그래프입니다. 단절선을 모두 지우면 남는 연결 요소가 정확히 이것입니다. 각 요소를 정점 하나로 압축하고 단절선을 간선으로 남긴 그래프가 단절선 트리(bridge tree, bridge-block tree)입니다. 압축하면 사이클이 없어서 연결 그래프에서는 트리, 아니면 숲(forest)입니다.

| 구분 | 이중 연결 요소(블록) | 이중 간선 연결 요소 |
|------|----------------------|----------------------|
| 지우는 대상 | 정점 | 간선 |
| 경계 | 단절점 | 단절선 |
| 정점이 속하는 개수 | 여러 블록 가능 | 정확히 하나 |
| 압축한 구조 | 블록-단절점 트리 | 단절선 트리 |

예제 그래프에서 요소는 `{0, 1, 2}`, `{3, 4, 5}`, `{6}` 세 개이고, 단절선 `2-3`과 `5-6`이 이들을 `{0,1,2} - {3,4,5} - {6}` 경로로 잇습니다.

단절선을 구하는 DFS에 정점 스택을 더하면 요소 번호를 한 번에 붙일 수 있습니다. `low[u] === tin[u]`이면 u의 부모 간선이 단절선이거나 u가 루트라는 뜻이어서, u가 요소의 최상단입니다.

```js
// findBridges의 dfs 전체. vs, comp, cnt는 바깥에 선언
function dfs(u, pe) {
  tin[u] = low[u] = timer++
  vs.push(u)
  for (const [v, id] of adj[u]) {
    if (id === pe) continue
    if (tin[v] !== -1) low[u] = Math.min(low[u], tin[v])
    else { dfs(v, id); low[u] = Math.min(low[u], low[v]) }
  }
  if (low[u] === tin[u]) {          // u가 한 요소의 최상단
    let w
    do { w = vs.pop(); comp[w] = cnt } while (w !== u)
    cnt++
  }
}
```

- `comp[x]`가 정점 x의 요소 번호이고 요소는 `cnt`개입니다. 단절선 `(a, b)`마다 `comp[a]`와 `comp[b]`를 잇는 간선을 만들면 단절선 트리입니다.
- 시간은 O(V + E)입니다.
- 쓰임: 간선을 몇 개 추가해야 2-간선연결이 되는가(리프 개수), 두 정점 사이에 반드시 지나야 하는 단절선의 개수(트리 위의 거리)처럼 사이클을 압축해 트리 문제로 바꾸는 유형입니다. 트리 위에서는 LCA(66편)와 트리 DP(67편)를 씁니다.

**흔한 실수:** 블록(정점 기준)과 이중 간선 연결 요소(간선 기준)를 섞는 것입니다. 정점 2가 단절점이어도 `{0, 1, 2}` 요소에 속하며 요소는 정점을 겹쳐 갖지 않습니다.

## 오일러 경로 (Euler Path)

오일러 경로(Euler path, trail)는 그래프의 모든 간선을 정확히 한 번씩 지나는 경로입니다. 정점은 여러 번 지나도 됩니다. 정점을 한 번씩만 지나는 해밀턴 경로와 다르며, 오일러 경로는 차수만 보면 존재를 판정할 수 있습니다. 1736년 오일러가 쾨니히스베르크의 일곱 다리 문제를 푼 데서 시작했습니다. 그 문제는 네 땅덩이 모두 홀수 개의 다리가 닿아서 오일러 경로가 없는 경우입니다.

차수(degree)는 정점에 붙은 간선 수이고, 방향 그래프에서는 들어오는 간선 수(진입)와 나가는 간선 수(진출)로 나눕니다. 자기 자신으로 가는 간선(자기 루프)은 무방향 차수에 2를 더합니다.

존재 조건은 다음과 같습니다. 두 경우 모두 간선이 하나라도 있는 정점들이 한 덩어리로 이어져 있어야 하고, 간선이 없는 고립 정점은 무시합니다.

| 그래프 | 오일러 경로(시작과 끝이 다름) | 오일러 회로(시작=끝) |
|--------|-------------------------------|----------------------|
| 무방향 | 홀수 차수 정점이 정확히 2개 | 홀수 차수 정점이 0개 |
| 방향 | 진출 − 진입 = 1인 정점 1개(시작), 진입 − 진출 = 1인 정점 1개(끝), 나머지는 진출 = 진입 | 모든 정점에서 진출 = 진입 |

- 무방향에서 홀수 차수 정점의 수는 항상 짝수입니다(차수의 합이 간선 수의 2배). 그래서 가능한 경우는 0개, 2개뿐이고 4개 이상이면 경로가 없습니다.
- 경로의 시작 정점은 무방향이면 홀수 차수 정점 중 하나, 방향이면 진출이 진입보다 1 큰 정점입니다. 끝은 나머지 홀수 차수 정점, 진입이 1 큰 정점입니다.
- 방향 그래프의 회로는 간선이 있는 정점이 하나의 강연결 요소에 있어야 합니다. 진출과 진입이 같은 정점끼리 두 덩어리로 갈라져 있으면 차수 조건은 맞아도 한 번에 지날 수 없습니다.
- 차수 조건과 연결성을 따로 구현하지 않아도 됩니다. 아래 Hierholzer 알고리즘으로 경로를 만든 뒤 길이가 `간선 수 + 1`인지 보면 연결성까지 확인됩니다.

차수로 존재만 판정하는 코드입니다. 무방향 그래프에서 홀수 차수 정점 수를 셉니다.

```js
function oddCount(n, edges) {
  const deg = new Array(n).fill(0)
  for (const [a, b] of edges) { deg[a]++; deg[b]++ }
  return deg.filter((d) => d % 2 === 1).length
}
// 쾨니히스베르크: 차수 3, 3, 3, 5 → 4개 → 경로 없음
// 삼각형 하나: 차수 2, 2, 2 → 0개 → 회로 있음
// 삼각형 + 꼬리 간선: 3, 2, 2, 1 → 2개 → 경로만 있음
```

자기 루프는 `[a, a]`에서 `deg[a]`가 2 늘어서 위 코드가 그대로 맞습니다.

**문제의 단서:** "모든 간선을 정확히 한 번씩", "한붓그리기", "연필을 떼지 않고 그린다"가 나오면 오일러 경로입니다. "모든 정점을 한 번씩"이면 해밀턴 경로이고 완전탐색이나 비트마스크 DP(73편)로 풉니다.

**흔한 실수:**

- 정점 연결성을 확인하지 않고 차수만 보는 것입니다. 삼각형 두 개가 떨어져 있으면 모든 차수가 짝수여도 회로가 없습니다.
- 간선이 없는 고립 정점까지 연결성 검사에 넣는 것입니다.
- 방향 그래프에서 무방향 조건(홀수 차수)을 쓰는 것입니다.

## 오일러 회로 (Euler Circuit)

오일러 회로(Euler circuit, cycle)는 모든 간선을 정확히 한 번씩 지나 출발한 정점으로 돌아오는 오일러 경로입니다. 경로의 첫 정점과 끝 정점이 같습니다.

- 회로는 경로의 특수한 경우입니다. 홀수 차수 정점이 0개면 회로도 있고, 2개면 경로만 있습니다.
- 회로가 있으면 간선이 있는 어느 정점에서 출발해도 됩니다. 경로만 있으면 정해진 시작 정점(홀수 차수 정점 또는 진출이 1 큰 정점)에서만 출발할 수 있습니다.
- 홀수 차수 정점이 2개일 때 그 둘을 잇는 가상 간선을 하나 추가하면 모든 차수가 짝수라서 회로가 됩니다. 이 회로에서 가상 간선을 빼면 오일러 경로입니다.

```js
// 0-1, 1-2, 2-0 삼각형: 회로 0 1 2 0
// 0-1, 1-2, 2-3, 3-1: 홀수 차수 0과 1 → 경로 0 1 2 3 1
//                     (1-0 가상 간선을 더하면 회로)
```

방향 그래프에서는 회로가 곧 모든 간선을 쓰는 사이클입니다. 문자열을 겹치는 조각으로 이어 붙이는 문제(De Bruijn 수열, 재구성)와 항공권 일정 복원처럼 "간선을 모두 쓰는 한 줄 순서"가 필요한 문제가 방향 그래프의 오일러 경로·회로입니다.

**시험에서 묻는 방식:** 정점의 차수 목록을 주고 오일러 경로·회로가 가능한지, 경로면 어느 정점에서 시작하는지를 묻습니다. 연결성이 깨진 그래프를 섞어 차수 조건만으로는 답할 수 없게 내는 것도 흔합니다.

**흔한 실수:** 오일러 회로와 경로를 구분하지 않는 것입니다. 홀수 차수 정점이 2개인데 회로를 구하려 하면 시작 정점이 어디든 실패합니다.

## Hierholzer 알고리즘

Hierholzer 알고리즘(1873)은 오일러 경로·회로를 O(V + E)에 구성하는 방법입니다. 스택에 정점을 쌓으며 아직 쓰지 않은 간선이 있으면 따라가고, 막다른 길에서 돌아올 때 그 정점을 결과에 기록합니다.

1. 시작 정점을 스택에 넣는다.
2. 스택 맨 위 정점 u에서 쓰지 않은 간선이 있으면 하나를 골라 쓴 표시를 하고, 그 간선의 도착 정점을 스택에 넣는다.
3. 쓰지 않은 간선이 없으면 u를 스택에서 꺼내 결과에 기록한다.
4. 스택이 빌 때까지 2–3을 반복한다.

결과는 정점을 꺼낸 순서, 즉 경로의 역순입니다. 방향 그래프는 뒤집어야 올바른 경로가 됩니다. 무방향 그래프는 역순도 같은 경로를 반대로 걷는 것이라서 그대로 써도 유효하지만, 시작 정점이 정해진 문제면 뒤집어서 맞춥니다.

정당성은 이렇습니다. 시작 정점에서 막다른 곳까지 걸으면 차수 조건 때문에 회로에서는 시작 정점에서, 경로에서는 끝 정점에서만 막힙니다. 이 걸음에 쓰이지 않은 간선이 남은 정점은 되돌아오는 길에 만나고, 그 정점에서 다시 걸으면 그 정점으로 돌아오는 작은 회로가 만들어집니다. 되돌아올 때 기록하는 방식이 이 작은 회로를 원래 걸음의 알맞은 자리에 끼워 넣습니다.

방향 그래프의 구현입니다. 진출 간선 목록에서 `pop`으로 간선을 하나씩 소비하므로 한 간선을 한 번만 씁니다.

```js
function directedStart(n, edges) {   // 시작 정점, 불가능하면 -1
  const diff = new Array(n).fill(0)  // 진출 - 진입
  for (const [a, b] of edges) { diff[a]++; diff[b]-- }
  let start = edges.length ? edges[0][0] : 0
  let plus = 0, minus = 0
  for (let v = 0; v < n; v++) {
    if (diff[v] === 1) { plus++; start = v }
    else if (diff[v] === -1) minus++
    else if (diff[v] !== 0) return -1
  }
  return plus > 1 || minus > 1 ? -1 : start
}
```

```js
function eulerDirected(n, edges) {
  const start = directedStart(n, edges)
  if (start === -1) return null
  const adj = Array.from({ length: n }, () => [])
  for (const [a, b] of edges) adj[a].push(b)
  const stack = [start], path = []
  while (stack.length) {
    const u = stack[stack.length - 1]
    if (adj[u].length) stack.push(adj[u].pop())
    else path.push(stack.pop())
  }
  if (path.length !== edges.length + 1) return null
  return path.reverse()
}
```

- 반환값이 `null`이면 차수 조건이 틀렸거나 일부 간선을 못 쓴 것(연결이 안 됨)입니다. 간선이 `m`개면 경로의 정점 수는 `m + 1`입니다.
- `pop`은 배열 끝에서 꺼내서 O(1)입니다. `shift`는 O(n)이라 간선이 많으면 느려집니다(자세히는 20편).
- 사전순으로 가장 작은 경로를 요구하면 각 `adj[u]`를 내림차순으로 정렬합니다. `pop`이 가장 작은 도착 정점부터 꺼냅니다.

다음 방향 그래프로 따라갑니다. 간선은 `0→1`, `1→2`, `2→1`, `1→0`이고 `adj[1]`은 `[2, 0]`이라서 `pop`이 0을 먼저 냅니다. 시작은 0입니다.

| 동작 | 스택 | 결과 |
|------|------|------|
| 시작 | `[0]` | `[]` |
| 0 → 1 | `[0, 1]` | `[]` |
| 1 → 0 | `[0, 1, 0]` | `[]` |
| 0 막힘 | `[0, 1]` | `[0]` |
| 1 → 2 | `[0, 1, 2]` | `[0]` |
| 2 → 1 | `[0, 1, 2, 1]` | `[0]` |
| 1 막힘 | `[0, 1, 2]` | `[0, 1]` |
| 2 막힘 | `[0, 1]` | `[0, 1, 2]` |
| 1 막힘 | `[0]` | `[0, 1, 2, 1]` |
| 0 막힘 | `[]` | `[0, 1, 2, 1, 0]` |

뒤집으면 `0 1 2 1 0`입니다. 처음 걸음 `0 → 1 → 0`은 시작 정점에서 막혔지만 간선 `1→2`, `2→1`이 남아서, 되돌아오는 길에 1에서 작은 회로 `1 → 2 → 1`을 만들어 끼워 넣었습니다.

무방향 그래프는 같은 간선이 양쪽 목록에 들어 있어서 쓴 표시가 필요합니다. 간선 id를 두 목록에 함께 넣고 `used[id]`로 막습니다.

```js
function hierholzer(adj, start, m) { // adj[u]: [v, id]
  const used = new Array(m).fill(false)
  const stack = [start], path = []
  while (stack.length) {
    const u = stack[stack.length - 1]
    let next = -1
    while (adj[u].length && next === -1) {
      const [v, id] = adj[u].pop()
      if (!used[id]) { used[id] = true; next = v }
    }
    if (next === -1) path.push(stack.pop())
    else stack.push(next)
  }
  return path
}
```

아래 함수가 목록을 만들고 홀수 차수 정점 수가 0 또는 2인지 확인한 뒤 호출합니다. 홀수 차수 정점이 있으면 거기서, 없으면 간선이 있는 정점에서 시작합니다.

```js
function eulerUndirected(n, edges) {
  const adj = Array.from({ length: n }, () => [])
  edges.forEach(([a, b], id) => {
    adj[a].push([b, id])
    adj[b].push([a, id])
  })
  let start = edges.length ? edges[0][0] : 0
  let odd = 0
  for (let v = 0; v < n; v++)
    if (adj[v].length % 2) { odd++; start = v }
  if (odd !== 0 && odd !== 2) return null
  const path = hierholzer(adj, start, edges.length)
  return path.length === edges.length + 1 ? path : null
}
```

- 이미 반대쪽에서 쓴 간선은 꺼내서 버립니다. 간선마다 목록에서 최대 두 번 꺼내므로 전체 O(V + E)입니다.
- 목록에 `[도착 정점, 간선 id]`를 넣어 두면 `used[id]`가 두 방향을 함께 막습니다.
- 자기 루프는 같은 id가 한 목록에 두 번 들어가고 한 번 쓰면 `used`가 막아서 한 번만 지나갑니다.
- 재귀로 쓰면 깊이가 간선 수만큼 커질 수 있어 위처럼 스택 반복문이 안전합니다(자세히는 86편).

**흔한 실수:**

- 방향 그래프의 결과를 뒤집지 않는 것입니다. 꺼낸 순서는 경로의 역순입니다.
- 무방향 그래프에서 `used`로 양방향 간선의 한쪽만 표시해 같은 간선을 반대 방향으로 다시 쓰는 것입니다.
- 마지막에 `path.length === m + 1`을 확인하지 않는 것입니다. 연결되지 않은 그래프에서는 일부 간선만 쓴 짧은 경로가 나옵니다.
- 경로가 가능한 그래프에서 아무 정점에서나 시작하는 것입니다. 홀수 차수 정점(진출이 1 큰 정점)에서 시작합니다.

## 핵심 정리

- 단절점은 루트가 자식 2개 이상이거나, 루트가 아닌 u에 `low[v] >= tin[u]`인 자식 v가 있을 때입니다. 단절선은 트리 간선에서 `low[v] > tin[u]`입니다.
- 단절선 DFS는 부모 정점이 아니라 부모 간선 id를 건너뛰어야 평행 간선이 맞게 처리됩니다. 둘 다 O(V + E)입니다.
- 블록(정점 기준)은 간선을 정확히 한 블록에 나누고 단절점을 공유하며, 이중 간선 연결 요소(간선 기준)를 압축하면 단절선 트리가 됩니다.
- 오일러 회로는 무방향에서 홀수 차수 정점 0개, 방향에서 모든 정점의 진출 = 진입이고, 경로는 홀수 차수 정점 2개(방향이면 진출 − 진입 = 1과 −1이 하나씩)입니다. 간선이 있는 정점은 한 덩어리여야 합니다.
- Hierholzer는 스택으로 간선을 따라가다 막히면 정점을 결과에 기록하는 O(V + E) 알고리즘이고, 결과를 뒤집어야 하며 길이가 `간선 수 + 1`인지 확인합니다.
