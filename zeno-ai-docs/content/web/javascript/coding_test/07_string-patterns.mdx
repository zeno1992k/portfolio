## 문자열 뒤집기

문자열을 거꾸로 만드는 유형입니다. 문자열에는 `reverse`가 없어서 배열로 바꿔 뒤집은 뒤 다시 잇습니다(문자열 메서드는 06편, 배열 `reverse`는 04편).

```js
const s = 'abc'
const r1 = [...s].reverse().join('') // 'cba'
let r2 = ''
for (let i = s.length - 1; i >= 0; i--) r2 += s[i] // 'cba'
```

- 시간과 공간은 모두 O(n)입니다.
- `[...s]`는 코드 포인트 단위로 쪼개서 이모지가 깨지지 않습니다. `s.split('')`은 코드 유닛 단위입니다.
- 배열 `reverse`는 제자리에서 바꿉니다. 새 배열 `[...s]`에 쓰면 원본 문자열에 영향이 없습니다.
- 단어 순서를 뒤집는 변형은 `s.split(' ').reverse().join(' ')`이고, 단어 안의 글자만 뒤집는 변형은 `map`으로 단어마다 뒤집습니다.

```js
const words = 'ab cd'.split(' ')
words.toReversed().join(' ') // 'cd ab' (단어 순서)
words.map((w) => [...w].reverse().join('')).join(' ')
// 'ba dc' (단어 안의 글자)
```

**흔한 실수:** 숫자를 뒤집는 문제에서 결과 앞의 `0`이 사라지는 것을 놓치는 것입니다. `'120'`을 뒤집으면 `'021'`이고, 숫자로 바꾸면 `21`입니다. 문제가 숫자와 문자열 중 무엇을 요구하는지 확인합니다.

## 팰린드롬

앞에서 읽어도 뒤에서 읽어도 같은 문자열입니다. 양끝에서 안쪽으로 좁혀 오며 비교하는 투 포인터가 표준입니다(자세히는 30편).

```js
function isPalindrome(s) {
  let l = 0, r = s.length - 1
  while (l < r) {
    if (s[l] !== s[r]) return false
    l++
    r--
  }
  return true
}
// isPalindrome('abcba') true, isPalindrome('ab') false
```

- 뒤집은 문자열과 비교하는 `s === [...s].reverse().join('')`도 맞습니다. 투 포인터는 추가 공간이 필요 없고 불일치에서 바로 끝납니다. 시간은 둘 다 O(n)입니다.
- 길이가 홀수이면 가운데 글자는 비교하지 않아도 되므로 `l < r` 조건에서 자동으로 건너뜁니다.
- 대소문자와 기호를 무시하는 변형은 비교 전에 정규화합니다.

```js
const clean = s.toLowerCase().replace(/[^a-z0-9]/g, '')
```

- 한 글자를 지워서 팰린드롬이 되는지 묻는 변형은 처음 불일치한 `l`, `r`에서 `l`을 건너뛰는 경우와 `r`을 건너뛰는 경우 두 가지만 다시 검사합니다.
- 팰린드롬 부분 문자열을 찾는 문제는 가운데에서 양쪽으로 넓히는 방식으로 O(n²)에 풉니다. 그보다 빠른 알고리즘은 이 과목에서 다루지 않습니다.

## 애너그램 (Anagram)

두 문자열이 글자의 종류와 개수가 같고 순서만 다른 관계입니다. 풀이는 두 가지입니다.

| 방법 | 시간 | 공간 | 조건 |
|------|------|------|------|
| 정렬 후 비교 | O(n log n) | O(n) | 글자 종류 제한 없음 |
| 빈도수 비교 | O(n) | 알파벳 수 | 글자 범위를 알 때 유리 |

```js
function isAnagram(a, b) {
  if (a.length !== b.length) return false
  const cnt = Array(26).fill(0)
  for (const ch of a) cnt[ch.charCodeAt(0) - 97]++
  for (const ch of b) cnt[ch.charCodeAt(0) - 97]--
  return cnt.every((v) => v === 0)
}
// isAnagram('listen', 'silent') true
```

- 하나는 더하고 하나는 빼서 모두 0이면 같은 구성입니다. 길이가 다르면 바로 `false`입니다(구성이 다르다는 것이 확정이라 검사를 줄입니다).
- 정렬 방식은 `[...a].sort().join('') === [...b].sort().join('')`입니다. 비교 함수 없는 `sort`는 문자열 순서라서 글자 정렬에 그대로 맞습니다.
- 소문자 26개가 아니면 배열 크기를 바꾸거나 `Map`을 씁니다(자세히는 10편).
- 애너그램끼리 묶는 문제는 정렬한 문자열을 키로 써서 `Map`에 모읍니다. `'eat'`, `'tea'`, `'ate'`는 모두 키 `'aet'`입니다.
- 한 문자열의 애너그램이 다른 문자열 안에 부분 문자열로 있는지 묻는 변형은 길이 고정 슬라이딩 윈도우입니다(자세히는 31편).

**흔한 실수:** 글자 범위 가정을 확인하지 않는 것입니다. 대문자나 숫자가 섞이면 `charCodeAt(0) - 97`이 음수이거나 26 이상이 되어 배열 밖 위치에 `NaN` 프로퍼티가 생기고, `every`는 인덱스 0–25만 검사하므로 틀린 입력도 `true`가 될 수 있습니다.

## 문자열 빈도수

각 글자가 몇 번 나왔는지 세는 유형입니다. 글자 범위가 작으면 카운트 배열, 넓으면 `Map`이나 `Object`입니다(자세히는 05편, 10편).

```js
const s = 'banana'
const freq = new Map()
for (const ch of s) freq.set(ch, (freq.get(ch) ?? 0) + 1)
console.log([...freq]) // [['b', 1], ['a', 3], ['n', 2]]
```

- `Map`은 삽입 순서를 유지해서 처음 나온 순서로 순회됩니다.
- 가장 많이 나온 글자를 찾을 때는 동률 규칙을 확인합니다. "여러 개면 사전순으로 가장 앞"이면 알파벳 순서로 훑으면서 `>`로 갱신하면 같은 값에서 먼저 나온 글자가 유지됩니다.

```js
const cnt = Array(26).fill(0)
for (const ch of s) cnt[ch.charCodeAt(0) - 97]++
let best = 0
for (let i = 1; i < 26; i++) {
  if (cnt[i] > cnt[best]) best = i
}
const ans = String.fromCharCode(97 + best) // 'a'
```

- 모든 글자의 빈도가 같은 문자열인지는 `Set`으로 빈도 값의 종류가 하나인지 봅니다.
- 한 번만 나온 첫 글자를 찾으려면 빈도를 센 뒤 원래 순서로 다시 훑습니다. 빈도를 세는 순회와 찾는 순회가 따로입니다.
- 소문자와 대문자를 구분하는 문제는 배열 크기가 52이거나 `Map`입니다. 구분하지 않으면 먼저 `toLowerCase()`합니다.

## 부분 문자열

연속한 구간입니다. 길이 n인 문자열에는 시작 위치와 끝 위치를 고르는 n(n+1)/2개의 부분 문자열이 있습니다. 중간을 건너뛰는 부분 수열(subsequence)과 구별합니다.

```js
const s = 'abc'
for (let i = 0; i < s.length; i++) {
  for (let j = i + 1; j <= s.length; j++) {
    console.log(s.slice(i, j)) // a, ab, abc, b, bc, c
  }
}
```

| 구분 | 연속 | 예 ('abc'에서) | 개수 |
|------|------|----------------|------|
| 부분 문자열 | 연속 | `ab`, `bc` | n(n+1)/2 |
| 부분 수열 | 비연속 허용 | `ac` | 2의 n제곱 |

- 모든 부분 문자열을 만들면 `slice` 비용까지 더해 O(n³)입니다. n이 수천이면 위험하므로 필요한 구간만 쓰거나 투 포인터·윈도우로 바꿉니다.
- 길이가 k로 고정된 부분 문자열은 `s.slice(i, i + k)`를 `i`가 `s.length - k`까지 돌립니다.
- 서로 다른 부분 문자열의 개수는 `Set`에 넣어서 셉니다.
- 패턴이 부분 문자열로 있는지는 `includes`, 위치는 `indexOf`, 겹치는 등장 횟수는 `indexOf`를 시작 위치를 옮기며 반복합니다.

```js
function countOverlap(s, p) { // p는 빈 문자열이 아니어야 함
  let cnt = 0, pos = s.indexOf(p)
  while (pos !== -1) {
    cnt++
    pos = s.indexOf(p, pos + 1)
  }
  return cnt
}
// countOverlap('aaaa', 'aa') 3
```

- `s.split(p).length - 1`은 겹치지 않는 등장 횟수입니다. `'aaaa'`와 `'aa'`에서 2입니다.
- 부분 수열인지 판별은 `t`의 글자를 `s`를 훑으며 차례로 맞추는 포인터 하나로 O(n)입니다.

```js
function isSubsequence(t, s) {
  let i = 0
  for (const ch of s) if (ch === t[i]) i++
  return i === t.length
}
// isSubsequence('ace', 'abcde') true
```

- 가장 긴 공통 부분 문자열·수열은 동적 계획법 유형입니다(자세히는 42편). 문자열 매칭 알고리즘은 58편에서 다룹니다.

## 파싱 (Parsing)

정해진 형식의 문자열을 쪼개서 필요한 값으로 바꾸는 유형입니다. 구분자가 있으면 `split`, 위치가 고정이면 `slice`, 규칙이 복잡하면 정규식입니다.

```js
const [h, m] = '09:05'.split(':').map(Number)
const minutes = h * 60 + m // 545
const [k, v] = 'age=20'.split('=') // 'age', '20'
const nums = 'a12b3c'.match(/\d+/g) ?? [] // ['12', '3']
```

- 변환 방법에 따라 결과가 다릅니다. `Number('12px')`는 `NaN`이고 `parseInt('12px', 10)`은 `12`입니다. 뒤에 붙은 글자를 버리고 싶으면 `parseInt`, 형식이 틀리면 알아내야 하면 `Number`입니다(자세히는 02편).
- 숫자 문자열 앞의 `0`은 `Number('007')`에서 `7`이 됩니다. 원래 문자열이 필요하면 변환하지 않고 보관합니다.
- 값에 구분자가 들어갈 수 있으면 `split`이 틀립니다. 첫 구분자만 쓰려면 `indexOf`로 위치를 찾아 `slice`합니다.

```js
const line = 'url=a=b'
const p = line.indexOf('=')
const key = line.slice(0, p)      // 'url'
const value = line.slice(p + 1)   // 'a=b'
```

- 천 단위 쉼표가 있으면 `replaceAll(',', '')`로 없앤 뒤 변환합니다.
- 여러 구분자는 `split(/[ ,]+/)`처럼 정규식 구분자로 한 번에 나눕니다(06편). 앞뒤 구분자에서 생기는 빈 문자열은 `filter(Boolean)`이나 `trim`으로 제거합니다.
- 입력 줄을 파싱하는 방법과 형식은 08편에서 다룹니다.
- `HH:MM` 같은 시각 문제는 분 단위 정수로 바꿔 계산한 뒤 `padStart(2, '0')`로 되돌립니다.

## 런 길이 부호화(문자열 압축)

같은 글자가 연속된 구간을 글자와 길이로 줄이는 방법입니다. `'aaabcc'`는 `'a3b1c2'`가 됩니다. 연속한 구간을 하나씩 처리하는 두 포인터 방식으로 O(n)에 구현합니다.

```js
function encode(s) {
  let out = '', i = 0
  while (i < s.length) {
    let j = i
    while (j < s.length && s[j] === s[i]) j++
    out += s[i] + (j - i)
    i = j
  }
  return out
}
// encode('aaabcc') 'a3b1c2'
```

| i | 구간 | 출력 누적 |
|---|------|-----------|
| 0 | `aaa` (j=3) | `a3` |
| 3 | `b` (j=4) | `a3b1` |
| 4 | `cc` (j=6) | `a3b1c2` |

- 안쪽 `while`이 같은 글자를 끝까지 읽고, `i`를 `j`로 옮겨서 각 글자를 한 번만 봅니다. 이중 반복문이어도 전체는 O(n)입니다.
- 문제에 따라 길이가 1일 때 숫자를 생략합니다. `out += s[i] + (j - i > 1 ? j - i : '')`입니다.
- 길이가 두 자리 이상이면 숫자도 글자 수로 세므로 압축 후 길이는 `String(j - i).length`로 셉니다.
- 복원(디코딩)은 정규식 치환으로 쓸 수 있습니다. 원문에 숫자가 없을 때만 성립합니다.

```js
'a3b1c2'.replace(/(\D)(\d+)/g, (_, ch, n) => ch.repeat(+n))
// 'aaabcc'
```

- 일정한 단위 길이로 잘라 반복을 압축하고 가장 짧은 결과를 구하는 변형은 단위 길이를 1부터 절반까지 모두 시도하는 완전탐색입니다(자세히는 16편).

**흔한 실수:** 마지막 구간을 처리하지 않는 것입니다. 글자가 바뀔 때만 출력하는 구조에서는 반복문이 끝난 뒤 남은 구간을 따로 출력해야 합니다. 위 코드는 안쪽 `while`이 끝까지 읽으므로 이 문제가 없습니다.

## 자릿수 단위 문자열 덧셈(큰 수 덧셈)

숫자가 `Number`의 안전한 범위를 넘을 때 문자열로 받아 한 자리씩 더하는 유형입니다. 낮은 자리(오른쪽)에서 시작하고 올림(carry)을 다음 자리로 넘깁니다.

```js
function addStr(a, b) {
  let i = a.length - 1, j = b.length - 1, carry = 0
  const out = []
  while (i >= 0 || j >= 0 || carry > 0) {
    const x = i >= 0 ? Number(a[i--]) : 0
    const y = j >= 0 ? Number(b[j--]) : 0
    const sum = x + y + carry
    out.push(sum % 10)
    carry = Math.floor(sum / 10)
  }
  return out.reverse().join('')
}
```

`addStr('999', '1')`의 추적입니다.

| 단계 | x | y | carry 전 | sum | 출력 자리 | carry 후 |
|------|---|---|----------|-----|-----------|----------|
| 1 | 9 | 1 | 0 | 10 | 0 | 1 |
| 2 | 9 | 0 | 1 | 10 | 0 | 1 |
| 3 | 9 | 0 | 1 | 10 | 0 | 1 |
| 4 | 0 | 0 | 1 | 1 | 1 | 0 |

- 낮은 자리부터 출력 배열에 쌓이므로 마지막에 `reverse`합니다. 결과는 `'1000'`입니다.
- 반복 조건에 `carry > 0`이 있어서 마지막 올림이 새 자리를 만듭니다. 이 조건을 빼면 `'999' + '1'`이 `'000'`이 됩니다.
- 길이가 다른 수는 짧은 쪽이 끝나면 `0`으로 채워서 처리합니다. 시간은 두 길이 중 큰 쪽에 비례하는 O(max(n, m))입니다.
- 두 수 모두 앞에 불필요한 `0`이 있을 수 있는지 입력 조건을 확인합니다. 결과 앞 `0`은 제거해야 하는지도 확인합니다.
- BigInt가 쓸 수 있으면 `(BigInt(a) + BigInt(b)).toString()`으로 끝납니다. `BigInt`는 임의 길이의 10진 문자열을 받고, 숫자가 아닌 문자열은 SyntaxError입니다. `Number`로 바꾸면 안전한 정수 범위(2의 53제곱 − 1)를 넘는 순간 정밀도를 잃습니다(자세히는 02편).
- 자릿수 단위 덧셈은 뺄셈·곱셈 변형이나 진법 변환 문제의 기본 뼈대입니다. 곱셈은 자릿수 곱을 결과 배열 `res[i + j]`에 누적한 뒤 올림을 정리합니다.

## 핵심 정리

- 뒤집기는 `[...s].reverse().join('')`, 팰린드롬은 양끝 투 포인터로 O(n)입니다.
- 애너그램은 정렬 비교(O(n log n)) 또는 빈도수 배열 가감(O(n))으로 판별하고, 빈도수는 글자 범위가 작으면 배열, 넓으면 `Map`입니다.
- 부분 문자열은 연속 구간이라 n(n+1)/2개이고 모두 만들면 O(n³)이며, 부분 수열과 구별합니다.
- 파싱은 구분자면 `split`, 위치면 `slice`, 복잡하면 정규식이고, `Number`와 `parseInt`의 차이와 앞자리 `0`을 확인합니다.
- 런 길이 부호화는 연속 구간을 한 번씩만 읽는 O(n) 두 포인터이고, 큰 수 덧셈은 낮은 자리부터 더하며 올림을 `carry`로 넘깁니다.
