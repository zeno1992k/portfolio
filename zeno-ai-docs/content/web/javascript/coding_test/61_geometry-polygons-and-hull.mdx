## 삼각형 넓이

세 꼭짓점 A, B, C로 이루어진 삼각형의 넓이는 외적으로 구합니다. 벡터 AB와 AC의 외적 절댓값은 두 벡터가 만드는 평행사변형의 넓이이고, 삼각형은 그 절반입니다. 외적과 방향 판정(CCW)은 60편에서 다뤘고, 이 문서의 모든 코드가 쓰는 함수를 다시 적으면 다음과 같습니다.

```js
const cross = (o, a, b) => {
  const ax = a[0] - o[0], ay = a[1] - o[1]
  const bx = b[0] - o[0], by = b[1] - o[1]
  return ax * by - ay * bx   // o→a 에서 o→b 로 가는 외적
}
const d2 = (a, b) => (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2
const tri2 = (a, b, c) => Math.abs(cross(a, b, c))
tri2([0, 0], [4, 0], [1, 3]) // 12 (넓이의 두 배)
```

넓이는 `tri2(...) / 2`로 6입니다. 넓이를 구하는 방법 세 가지를 비교하면 다음과 같습니다.

| 방법 | 필요한 값 | 문제점 |
|------|-----------|--------|
| 밑변 × 높이 ÷ 2 | 높이 | 높이를 구하려면 나눗셈이나 제곱근이 필요하다 |
| 헤론 공식 | 세 변의 길이 | 제곱근이 있어서 실수 오차가 생긴다 |
| 외적 | 좌표 | 정수 곱셈과 뺄셈뿐이라 오차가 없다 |

- 외적은 정수만 쓰므로 두 배 넓이는 정수이고, 넓이는 항상 0.5의 배수입니다. 0.5의 배수는 Number로 정확히 표현됩니다. 크기 비교는 두 배 넓이끼리 하고, 나누기 2는 출력할 때 한 번만 합니다.
- 부호 없는 외적이 0이면 세 점이 한 직선 위에 있어서 넓이가 0입니다.
- 부호를 남기면 방향을 알 수 있습니다. `cross(a, b, c)`가 양수이면 A, B, C 순서가 반시계입니다.
- 소수점 첫째 자리까지 출력하라는 문제는 `(tri2(a, b, c) / 2).toFixed(1)`로 씁니다. 값이 0.5의 배수라서 반올림이 끼어들지 않습니다.

좌표의 절댓값이 최대 C이면 외적 한 번의 크기는 8C² 이하입니다. 이 값이 `Number.MAX_SAFE_INTEGER`(2^53 − 1)를 넘으면 안 되므로 C가 약 3 × 10^7 이하일 때 안전합니다. 그보다 크면 좌표를 BigInt로 바꿔 계산합니다(자세히는 02편).

**흔한 실수:** 두 배 넓이를 구하자마자 2로 나눠 실수로 만든 뒤, 넓이가 같은지 `===`로 비교하는 것입니다. 정수로 비교하면 이 문제가 없습니다.

## 다각형 넓이

꼭짓점을 이은 변이 서로 교차하지 않는 단순 다각형의 넓이는 신발끈 공식(shoelace formula)으로 구합니다. 꼭짓점이 시계 방향이나 반시계 방향으로 순서대로 주어져야 합니다.

$$
S = \sum_{i=0}^{N-1} (x_i \, y_{i+1} - x_{i+1} \, y_i)
$$

- `S`는 두 배 넓이에 부호를 붙인 값이고, 넓이는 `|S| / 2`입니다.
- `(x_i, y_i)`는 i번째 꼭짓점이고, 마지막 꼭짓점의 다음은 0번 꼭짓점입니다.
- 각 항은 원점과 변 하나가 이루는 삼각형의 부호 있는 두 배 넓이입니다. 모두 더하면 다각형 밖으로 겹친 부분이 서로 상쇄되고 다각형의 넓이만 남습니다.

```js
function area2(p) {
  let s = 0
  for (let i = 0; i < p.length; i++) {
    const [x1, y1] = p[i]
    const [x2, y2] = p[(i + 1) % p.length]
    s += x1 * y2 - x2 * y1
  }
  return s   // 양수 반시계, 음수 시계
}
const L = [[0, 0], [4, 0], [4, 2], [2, 2], [2, 4], [0, 4]]
area2(L) // 24 → 넓이 12
```

위 L자 도형은 한 변이 4인 정사각형(16)에서 한 변이 2인 정사각형(4)을 뺀 모양이므로 넓이가 12이고, `area2`의 결과 24와 맞습니다.

- 부호가 방향을 알려 줍니다. 입력의 꼭짓점 방향을 모를 때 `area2`의 부호로 판별하고, 반대면 배열을 뒤집습니다.
- 볼록이든 오목이든 쓸 수 있습니다. 변이 서로 교차하는 다각형에서는 겹친 부분의 부호가 상쇄되어 넓이가 아닌 값이 나옵니다.
- 시간은 O(N)입니다.
- 좌표가 원점에서 멀면 항 하나가 커집니다. 첫 꼭짓점을 모든 좌표에서 빼서 평행이동한 뒤 계산하면 넓이는 그대로이고 중간 값이 작아집니다. 합의 상한 N × 2C²가 2^53 − 1 이하인지 확인하고, 넘으면 BigInt를 씁니다.

**흔한 실수:**

- 마지막 꼭짓점에서 0번으로 돌아오는 변을 빠뜨리는 것입니다. `% p.length`가 그 역할입니다.
- 꼭짓점을 입력 순서가 아닌 정렬된 순서로 넣는 것입니다. 변을 따라가는 순서를 지켜야 합니다.
- 방향을 모르는데 `s`를 그대로 넓이로 쓰는 것입니다. 시계 방향이면 음수입니다.

## Convex Hull

볼록 껍질(convex hull)은 점 집합의 모든 점을 포함하는 가장 작은 볼록 다각형입니다. 못을 점마다 박고 고무줄을 바깥에서 감았을 때 고무줄이 만드는 모양입니다. 껍질의 꼭짓점은 입력 점 중 일부입니다.

- 볼록 다각형은 변을 따라 걸을 때 모든 꼭짓점에서 같은 방향으로만 꺾입니다. 반시계로 걸으면 항상 왼쪽으로 꺾입니다.
- 껍질 알고리즘은 모두 같은 생각으로 움직입니다. 점을 정해진 순서로 훑으며 스택에 쌓다가, 마지막 두 점에서 새 점으로 오른쪽으로 꺾이면(외적이 0 이하이면) 스택의 마지막 점은 껍질이 아니라서 버립니다.
- 점 N개의 껍질은 O(N log N)에 구합니다. 정렬이 시간을 정하고 스택 처리는 O(N)입니다.
- 결과는 반시계 방향의 꼭짓점 목록입니다.

경계 조건을 먼저 정해야 합니다.

| 상황 | 처리 |
|------|------|
| 같은 좌표의 점이 여러 개 | 정렬 뒤 중복을 하나로 줄인다 |
| 서로 다른 점이 1개 또는 2개 | 껍질은 점 또는 선분이라서 그대로 돌려준다 |
| 모든 점이 한 직선 위 | 껍질은 양 끝점 2개다 |
| 변 위에 놓인 점(공선점) | 문제에 따라 버리거나 남긴다 |

공선점을 버리는 껍질(꼭짓점만)은 외적이 0 이하일 때 pop하고, 남기는 껍질은 0 미만일 때만 pop합니다. 문제 문장이 "껍질 위의 점 개수"를 묻는지 "꼭짓점 개수"를 묻는지 확인합니다.

```js
const byXY = (a, b) => a[0] - b[0] || a[1] - b[1]
function uniqSorted(pts) {
  const p = pts.slice().sort(byXY)
  return p.filter((q, i) => !i || byXY(q, p[i - 1]) !== 0)
}
uniqSorted([[2, 1], [1, 5], [2, 1]]) // [[1, 5], [2, 1]]
```

껍질을 구한 뒤의 활용은 정해진 몇 가지입니다. 둘레는 변 길이의 합(`Math.hypot`)이고, 넓이는 다각형 넓이(앞 절)이며, 가장 먼 두 점은 Rotating Calipers로 구합니다. "가장 바깥", "울타리", "모든 점을 감싸는" 같은 표현이 단서입니다.

**흔한 실수:** 점이 1–2개이거나 전부 일직선인 입력을 시험하지 않는 것입니다. 껍질 코드는 이런 입력에서 길이가 2인 결과를 돌려주어야 합니다.

## Graham Scan

Graham Scan은 기준점에서 본 각도 순서로 점을 훑는 껍질 알고리즘입니다.

1. 기준점을 y가 가장 작은 점으로 잡는다. y가 같으면 x가 가장 작은 점이다.
2. 나머지 점을 기준점에서 본 반시계 각도 순으로 정렬한다. 각도가 같으면 기준점에서 가까운 점이 먼저다.
3. 기준점부터 차례로 스택에 넣는다. 새 점으로 오른쪽으로 꺾이면(외적 0 이하) 스택의 마지막 점을 버리고 다시 비교한다.

기준점이 가장 아래쪽(같으면 왼쪽)이어서 나머지 점은 모두 기준점에서 0도 이상 180도 미만에 있습니다. 이 범위에서는 두 점의 각도 순서가 외적의 부호와 일치하므로 `Math.atan2` 없이 외적으로 비교합니다.

```js
function scan(seq) {
  const h = []
  for (const q of seq) {
    while (h.length >= 2) {
      const a = h[h.length - 2], b = h[h.length - 1]
      if (cross(a, b, q) > 0) break
      h.pop()
    }
    h.push(q)
  }
  return h
}
```

```js
function grahamScan(pts) {
  const p = uniqSorted(pts)
  if (p.length < 3) return p
  const o = p.reduce((m, q) => (q[1] < m[1] ? q : m))
  const rest = p.filter((q) => q !== o)
  rest.sort((a, b) => {
    const c = cross(o, a, b)
    return c !== 0 ? -c : d2(o, a) - d2(o, b)
  })
  return scan([o, ...rest])
}
```

- `p`가 x, y 순으로 정렬되어 있어서 `reduce`가 y가 가장 작은 점 중 x가 가장 작은 점을 고릅니다.
- 비교 함수에서 `cross(o, a, b)`가 양수이면 b가 a보다 반시계 쪽이라 a가 먼저 와야 하므로 음수를 돌려줍니다(정렬과 Comparator는 26편).

`[2,1] [4,0] [0,0] [4,4] [1,3] [0,4] [2,2]`를 처리하는 과정입니다. 기준점은 `[0,0]`이고 정렬 결과는 `[4,0] [2,1] [2,2] [4,4] [1,3] [0,4]`입니다.

| 새 점 | 버리는 점 | 스택 |
|-------|-----------|------|
| `[4,0]` | 없음 | `[0,0] [4,0]` |
| `[2,1]` | 없음 | `[0,0] [4,0] [2,1]` |
| `[2,2]` | `[2,1]` | `[0,0] [4,0] [2,2]` |
| `[4,4]` | `[2,2]` | `[0,0] [4,0] [4,4]` |
| `[1,3]` | 없음 | `[0,0] [4,0] [4,4] [1,3]` |
| `[0,4]` | `[1,3]` | `[0,0] [4,0] [4,4] [0,4]` |

- 정렬 O(N log N), 스택 처리 O(N)입니다. 점은 스택에 한 번 들어가고 최대 한 번 나오기 때문입니다.
- 같은 각도의 점 중 가까운 점이 먼저 와야 합니다. 나중에 오는 먼 점이 가까운 점을 외적 0으로 버리게 만들기 위해서입니다.
- 이 코드는 공선점을 버리는 껍질입니다. 변 위의 점을 남기려면 마지막 각도 묶음의 순서를 뒤집어야 해서 코드가 복잡해집니다. 그 경우는 다음 절의 방법이 간단합니다.

**흔한 실수:**

- 기준점을 입력의 첫 점으로 잡는 것입니다. 가장 아래쪽 점이 아니면 각도가 0–180도 범위를 벗어나서 외적 비교가 순서를 정하지 못합니다.
- 중복 점을 제거하지 않는 것입니다. 기준점과 같은 점은 외적이 모두 0이라 비교 결과가 무너집니다.

## Monotonic Chain

Monotonic Chain(Andrew의 알고리즘)은 점을 x 순으로 정렬해 아래 껍질과 위 껍질을 따로 만든 뒤 이어 붙입니다. 각도 정렬이 필요 없어서 외적 비교 함수 없이 정렬이 끝나고, 공선점도 다루기 쉽습니다.

1. 점을 x, y 순으로 정렬한다.
2. 왼쪽에서 오른쪽으로 `scan`하면 아래 껍질이 나온다.
3. 오른쪽에서 왼쪽으로 `scan`하면 위 껍질이 나온다.
4. 두 껍질은 서로의 시작점을 끝점으로 가지므로 각각 마지막 점을 하나씩 빼고 이어 붙인다.

```js
function monotoneChain(pts) {
  const p = uniqSorted(pts)
  if (p.length < 3) return p
  const lower = scan(p)
  const upper = scan(p.slice().reverse())
  lower.pop()   // 마지막 점은 upper의 첫 점과 같다
  upper.pop()   // 마지막 점은 lower의 첫 점과 같다
  return lower.concat(upper)
}
monotoneChain([[0, 0], [2, 0], [1, 1], [2, 2], [0, 2]])
// [[0, 0], [2, 0], [2, 2], [0, 2]]
```

- `scan`은 Graham Scan과 같은 함수입니다. 점을 넣는 순서만 다릅니다.
- 점이 모두 한 직선 위이면 `lower`는 양 끝점, `upper`는 반대 순서의 양 끝점이 되어 `pop` 뒤에 양 끝점 2개가 남습니다.
- 시간은 정렬이 O(N log N), 두 번의 스캔이 O(N)입니다.
- 공선점을 남기려면 `scan`의 `cross(a, b, q) > 0` 검사를 `cross(a, b, q) >= 0`으로 바꿉니다. 오른쪽으로 꺾일 때만 버리게 됩니다. 이때 점이 모두 한 직선 위인 입력은 점이 중복되어 나오므로 따로 처리해야 합니다.

두 방법을 비교하면 다음과 같습니다.

| 항목 | Graham Scan | Monotonic Chain |
|------|-------------|-----------------|
| 정렬 기준 | 기준점에서 본 각도(외적 비교) | x, y 좌표 |
| 스캔 횟수 | 1번 | 2번(아래·위) |
| 일직선 입력 | 별도 처리가 필요할 수 있다 | 자연스럽게 처리된다 |
| 공선점 포함 | 마지막 묶음을 뒤집어야 한다 | 부등호 한 글자 |
| 시간 | O(N log N) | O(N log N) |

코딩테스트에서는 Monotonic Chain을 기본으로 외워 두면 충분합니다. 두 형식으로 감싸면 다음과 같습니다.

```js
// 프로그래머스식: 꼭짓점 개수 반환
function solution(dots) {
  return monotoneChain(dots).length
}
// 표준 입력식: 첫 줄 N, 다음 N줄에 x y
const fs = require('fs')
const lines = fs.readFileSync(0, 'utf8').split('\n')
const n = Number(lines[0])
const pts = []
for (let i = 1; i <= n; i++) {
  pts.push(lines[i].split(' ').map(Number))
}
console.log(monotoneChain(pts).length)
```

입력을 읽는 방식과 줄 끝의 `\r` 처리는 08편에서 다룹니다.

**흔한 실수:** 위 껍질을 만들 때 정렬된 배열을 `reverse()`로 뒤집어 원본을 망가뜨리는 것입니다. 위 코드는 `slice()`로 복사한 뒤 뒤집습니다.

## Point in Polygon

점이 다각형의 안쪽, 경계, 바깥 중 어디에 있는지 판정하는 문제입니다. 가장 널리 쓰는 방법은 광선 투사(ray casting)입니다. 점에서 오른쪽으로 반직선을 쏴서 다각형의 변과 몇 번 만나는지 세고, 홀수이면 안쪽, 짝수이면 바깥쪽입니다.

- 반직선이 꼭짓점을 정확히 지날 때가 가장 까다롭습니다. 한 변의 두 끝점이 반직선의 위와 아래에 정확히 나뉠 때만 교차로 세서 해결합니다. 한 끝점의 y가 점의 y보다 크고 다른 끝점은 그렇지 않을 때입니다(반열린 구간 규칙).
- 변과 반직선이 만나는 지점이 점의 오른쪽인지는 나눗셈 없이 외적 부호로 판정합니다. 변이 위로 향하면 점이 변의 왼쪽(외적이 양수)일 때, 아래로 향하면 오른쪽일 때 교차점이 점의 오른쪽에 있습니다.
- 점이 변 위에 있는 경우는 광선 투사가 일관되게 처리해 주지 않으므로 먼저 따로 검사합니다. 세 점이 한 직선 위이고(외적 0) 점이 두 끝점 사이에 있으면 경계입니다.

```js
function onSegment(a, b, p) {
  if (cross(a, b, p) !== 0) return false
  const dx = (a[0] - p[0]) * (b[0] - p[0])
  const dy = (a[1] - p[1]) * (b[1] - p[1])
  return dx + dy <= 0   // p가 a와 b 사이에 있다
}
```

```js
// 0 바깥, 1 경계, 2 안쪽
function locate(p, poly) {
  let inside = false
  const n = poly.length
  for (let i = 0, j = n - 1; i < n; j = i++) {
    const a = poly[j], b = poly[i]
    if (onSegment(a, b, p)) return 1
    const straddle = (a[1] > p[1]) !== (b[1] > p[1])
    const left = cross(a, b, p) > 0
    if (straddle && left === (b[1] > a[1])) inside = !inside
  }
  return inside ? 2 : 0
}
```

앞의 L자 도형(`L`)에서 질의한 결과입니다.

| 점 | 결과 | 이유 |
|----|------|------|
| `[1, 3]` | 2 | 왼쪽 세로 막대 안쪽 |
| `[3, 3]` | 0 | 파인 부분 바깥 |
| `[2, 3]` | 1 | 변 위 |
| `[4, 1]` | 1 | 변 위 |
| `[5, 1]` | 0 | 오른쪽 바깥 |

- 시간은 질의 하나에 O(N)입니다. 볼록 다각형이면 한 꼭짓점을 기준으로 삼각형 부채꼴을 만들고 이분 탐색해서 O(log N)에 판정할 수 있습니다.
- 볼록 다각형이면 모든 변에서 같은 방향(반시계 껍질이면 모든 `cross(a, b, p)`가 0 이상)이라는 조건만 확인해도 됩니다. N이 작을 때 가장 간단합니다.
- 광선 투사는 변이 서로 교차하지 않는 단순 다각형에서만 맞습니다.
- 좌표가 정수이면 위 코드는 오차가 없습니다. 실수 좌표에서는 경계 판정이 오차에 민감해서 허용 오차(epsilon)를 둬야 합니다.

**흔한 실수:**

- 두 끝점의 y를 비교할 때 한쪽만 등호를 포함하지 않고 양쪽을 같게 쓰는 것입니다. 반직선이 꼭짓점을 지나면 교차를 두 번 세거나 한 번도 못 셉니다.
- 경계를 따로 검사하지 않고 광선 투사 결과만 믿는 것입니다. 경계의 점이 어느 쪽으로 나올지는 변의 방향에 따라 달라집니다.

## Rotating Calipers 개요

Rotating Calipers는 볼록 다각형의 둘레를 따라 서로 반대편의 두 평행한 접선을 회전시키며 답을 찾는 기법입니다. 이름은 다각형 바깥을 캘리퍼스로 물고 한 바퀴 도는 모습에서 왔습니다. 한 날이 다각형의 변에 붙을 때 반대편 날이 닿는 점이나 변이 대척점(antipodal) 쌍입니다.

- 볼록 껍질이 있으면 O(N)에 돕니다. 점 집합에서 시작하면 껍질을 구하는 O(N log N)이 전체 시간입니다.
- 풀 수 있는 문제는 지름(가장 먼 두 점), 너비(가장 좁은 폭), 다각형을 감싸는 최소 직사각형, 두 볼록 다각형 사이의 거리 등입니다.
- "점들 중 가장 먼 두 점의 거리"가 가장 흔한 형태입니다. 가장 먼 두 점은 반드시 껍질의 꼭짓점이므로 N개 점의 O(N²) 비교를 껍질 꼭짓점 사이의 O(N) 회전으로 줄입니다.

변 AB를 하나 고정하면 껍질에서 AB로부터 가장 먼 꼭짓점이 대척점입니다. 변이 반시계로 하나씩 넘어갈 때 그 꼭짓점도 같은 방향으로만 이동하므로 두 포인터처럼 한 바퀴만 돕니다.

```js
function diameter2(h) {   // h: 반시계 껍질, 결과는 거리의 제곱
  const n = h.length
  if (n < 3) return n === 2 ? d2(h[0], h[1]) : 0
  let best = 0, j = 1
  for (let i = 0; i < n; i++) {
    const a = h[i], b = h[(i + 1) % n]
    const area = (k) => Math.abs(cross(a, b, h[k % n]))
    while (area(j + 1) > area(j)) j = (j + 1) % n
    best = Math.max(best, d2(a, h[j]), d2(b, h[j]))
  }
  return best
}
const box = [[0, 0], [4, 0], [4, 3], [0, 3], [2, 1]]
diameter2(monotoneChain(box)) // 25 (대각선 5의 제곱)
```

- `area(k)`는 변 AB와 꼭짓점 k가 이루는 삼각형의 두 배 넓이라서 AB로부터의 거리에 비례합니다. 넓이가 더 커지는 동안 `j`를 앞으로 옮깁니다.
- 거리의 제곱을 정수로 비교하고 제곱근은 출력할 때 한 번만 구합니다.
- 껍질 꼭짓점이 3개 미만이면 점 또는 선분이라서 따로 처리합니다.
- 이 절은 개요이므로 너비와 최소 직사각형 같은 변형은 원리만 알아 두면 됩니다. 시험에서는 "가장 먼 두 점"이 사실상 전부입니다.

**흔한 실수:** 껍질을 만들 때 공선점을 남겨 두는 것입니다. 이 코드는 꼭짓점만 있는 껍질을 전제로 하므로 공선점을 버린 껍질을 넘깁니다.

## 픽의 정리 개요

픽의 정리(Pick's theorem)는 꼭짓점이 모두 격자점(정수 좌표)인 단순 다각형의 넓이를 격자점 개수로 알려 줍니다.

$$
A = I + \frac{B}{2} - 1
$$

- `A`는 다각형의 넓이입니다.
- `I`는 다각형 내부에 있는 격자점의 개수입니다.
- `B`는 다각형의 경계 위에 있는 격자점의 개수로, 꼭짓점과 변 위의 점을 모두 포함합니다.

넓이는 신발끈 공식으로 구할 수 있으므로 식을 거꾸로 써서 내부 격자점의 개수를 셉니다. 두 배 넓이를 `S2`라 하면 `I = (S2 - B + 2) / 2`입니다. 경계 점 `B`는 각 변마다 두 끝점 사이의 격자점 수를 더해서 구하고, 한 변의 격자점 수(한쪽 끝점 제외)는 두 좌표 차의 절댓값의 최대공약수입니다(최대공약수는 12편).

```js
const gcd = (a, b) => (b === 0 ? a : gcd(b, a % b))
function pick(p) {
  let b = 0
  for (let i = 0; i < p.length; i++) {
    const q = p[(i + 1) % p.length]
    const dx = Math.abs(p[i][0] - q[0])
    const dy = Math.abs(p[i][1] - q[1])
    b += gcd(dx, dy)
  }
  const s2 = Math.abs(area2(p))
  return { boundary: b, inside: (s2 - b + 2) / 2 }
}
pick(L) // { boundary: 16, inside: 5 } (12 = 5 + 16/2 - 1)
```

- 격자점을 하나씩 세면 좌표 범위에 비례해 오래 걸리지만, 이 방법은 O(N log C)입니다(C는 좌표 크기).
- 꼭짓점이 격자점이 아니거나 변이 교차하거나 구멍이 있는 도형에는 쓸 수 없습니다.
- `gcd(0, d)`는 `d`이므로 가로·세로 변도 같은 식으로 처리됩니다.

**흔한 실수:** 경계 점 `B`를 꼭짓점 수로만 세는 것입니다. 변 위의 격자점도 포함해야 합니다. `L`에서 꼭짓점은 6개이지만 `B`는 16입니다.

## 최근접 점 쌍 개요

최근접 점 쌍(closest pair of points)은 N개 점 중 거리가 가장 짧은 두 점을 찾는 문제입니다. 모든 쌍을 비교하면 O(N²)이고, 분할 정복(25편)으로 O(N log N)에 풉니다.

1. 점을 x 순으로 정렬한다(한 번만).
2. x 중앙값을 기준으로 점을 왼쪽 절반과 오른쪽 절반으로 나눈다.
3. 각 절반에서 재귀로 최소 거리를 구하고, 둘 중 작은 값을 `h`라 한다.
4. 두 절반에 걸친 쌍 중 거리가 `h`보다 작은 쌍이 있는지 본다. 분할선에서 x 거리가 `h` 이내인 점(띠 영역)만 후보다.
5. 띠 안의 점을 y 순으로 보며, 각 점을 y 차이가 `h` 미만인 점들과만 비교한다.

5단계가 선형 시간인 이유가 이 알고리즘의 핵심입니다. 한 점과 비교해야 하는 점은 폭 2h, 높이 h의 직사각형 안에 있고, 각 절반 안의 점들은 서로 거리가 `h` 이상이므로 그 직사각형에는 점이 많아야 8개 들어갑니다. 그래서 점마다 비교는 상수 번입니다.

| 항목 | 값 |
|------|----|
| 점화식 | `T(N) = 2T(N/2) + O(N)` |
| 시간 | O(N log N) |
| 공간 | O(N) |

- 띠의 점을 y로 정렬하는 일을 재귀마다 새로 하면 한 단계가 O(N log N)이 되어 전체가 O(N log² N)입니다. 병합 정렬처럼 재귀가 돌아오며 y 순서를 합치면 O(N log N)이 됩니다.
- 비교는 거리의 제곱으로 하고 제곱근은 출력할 때만 씁니다. 좌표가 정수이면 오차가 없습니다.
- 같은 좌표의 점이 있으면 답이 0입니다. 재귀 전에 중복을 확인하면 간단합니다.

**흔한 실수:** 띠 안에서 y 차이가 `h` 이상이 되면 비교를 멈추지 않고 모든 쌍을 비교하는 것입니다. 띠에 점이 몰려 있으면 O(N²)이 됩니다.

## 핵심 정리

- 삼각형과 다각형의 넓이는 외적으로 두 배 넓이를 정수로 구하고, 나누기 2는 마지막에 한 번만 합니다. 신발끈 공식의 부호는 꼭짓점 방향(양수이면 반시계)을 알려 줍니다.
- 볼록 껍질은 점을 정해진 순서로 훑으며 오른쪽으로 꺾이는 점을 스택에서 버려 구하고, 정렬 때문에 O(N log N)입니다. 중복 점과 점이 1–2개이거나 일직선인 입력을 먼저 처리합니다.
- Graham Scan은 y가 가장 작은 기준점에서 본 각도 순, Monotonic Chain은 x 순으로 훑습니다. 코딩테스트에서는 Monotonic Chain이 더 다루기 쉽습니다.
- 점의 위치 판정은 광선 투사로 O(N)에 하되, 경계 검사를 먼저 하고 꼭짓점 처리는 반열린 구간 규칙으로 합니다.
- Rotating Calipers는 껍질 위에서 대척점을 한 바퀴 돌며 가장 먼 두 점 같은 값을 O(N)에 구하고, 픽의 정리는 `A = I + B/2 - 1`로 내부 격자점 수를 셉니다.
- 최근접 점 쌍은 분할 정복으로 O(N log N)에 풀며, 띠 안에서는 점마다 상수 개만 비교합니다.
