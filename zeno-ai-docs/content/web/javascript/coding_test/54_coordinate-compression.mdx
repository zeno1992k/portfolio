## Coordinate Compression

좌표 압축(coordinate compression)은 값의 크기 순서는 유지하면서 값을 0, 1, 2, … 같은 작은 순위로 바꾸는 기법입니다. 값이 최대 10억이어도 서로 다른 값이 20만 개뿐이면 순위는 0에서 199999까지입니다.

```js
// 원래 값:   1000000  5  5000  5  70
// 압축 결과:        3  0     2  0   1
```

- 압축하면 배열의 인덱스로 쓸 수 있습니다. 값이 10억인 배열은 만들 수 없지만 순위 20만 개짜리 배열은 만들 수 있습니다.
- 유지되는 것은 대소 관계입니다. 원래 값이 작으면 순위도 작고, 같으면 순위도 같습니다. 값 사이의 거리는 유지되지 않습니다.
- 순서만 중요하고 크기는 중요하지 않은 문제에 씁니다. 빈도 세기, 누적합, 펜윅 트리·세그먼트 트리의 인덱스(62편, 64편), 구간 겹침 계산(55편)이 대표적입니다.

쓸지 말지는 입력 크기와 값의 범위로 정합니다.

| 상황 | 선택 |
|------|------|
| 값의 범위가 100만 정도 이하 | 값을 그대로 인덱스로 사용 |
| 값이 최대 10억, 개수는 최대 20만 | 좌표 압축 |
| 값이 음수 | 압축하거나 최솟값만큼 밀어서 0부터 시작 |
| 값 자체가 문자열·좌표 쌍 | Map으로 번호 부여 |

흐름은 세 단계입니다: 값을 모아 정렬·중복 제거, 값마다 순위 찾기, 필요하면 순위를 원래 값으로 복원.

## 정렬과 중복 제거

압축의 첫 단계는 모든 값을 모아 정렬하고 중복을 없애는 것입니다. 결과 배열 `sorted`에서 값의 위치가 곧 순위입니다.

```js
const arr = [1000000, 5, 5000, 5, 70]
const sorted = [...new Set(arr)].sort((a, b) => a - b)
// [5, 70, 5000, 1000000]
```

- `Set`은 같은 값을 하나로 합치고 삽입 순서대로 순회합니다(자세히는 09편). 스프레드로 배열로 바꿔 정렬합니다.
- 정렬은 숫자 비교 함수가 필수입니다. 기본 `sort()`는 값을 문자열로 바꿔 비교하므로 `[10, 9, 100]`이 `[10, 100, 9]`가 됩니다(자세히는 26편).
- 정렬과 중복 제거를 한 번에 하는 방법이 둘 있습니다. 위처럼 `Set`을 먼저 쓰는 방법과, 정렬한 뒤 앞 값과 다른 것만 남기는 방법입니다.

```js
const s = [...arr].sort((a, b) => a - b)
const uniq = s.filter((v, i) => i === 0 || v !== s[i - 1])
// 정렬된 상태에서는 같은 값이 이웃해 있다
```

- 정렬 뒤 비교하는 쪽은 `Set`을 만들지 않아서 메모리가 적습니다. 어느 쪽이든 O(N log N)입니다.
- 정렬은 원본을 바꿉니다. 원본이 필요하면 `[...arr]`로 복사하고 정렬합니다(자세히는 04편).
- 입력이 `Int32Array` 같은 TypedArray이면 `sort()`가 기본으로 숫자 순서입니다. 비교 함수 없이 쓸 수 있지만, 일반 배열에 적용하는 습관과 헷갈리지 않게 비교 함수를 쓰는 편이 안전합니다(자세히는 05편).

**흔한 실수:** 비교 함수 없이 `sort()`를 쓰는 것입니다. 자릿수가 같은 샘플은 통과하고, 자릿수가 다른 큰 입력에서 순위가 틀립니다.

## 값을 순위로 변환

값 `x`의 순위는 정렬된 고유 배열에서 `x`가 놓인 위치, 곧 `x`보다 작은 서로 다른 값의 개수입니다. 이분 탐색의 lower bound로 찾습니다(자세히는 28편).

```js
function lowerBound(a, x) {      // x 이상인 첫 위치
  let lo = 0, hi = a.length
  while (lo < hi) {
    const mid = (lo + hi) >> 1
    if (a[mid] < x) lo = mid + 1
    else hi = mid
  }
  return lo
}
const rank = arr.map((v) => lowerBound(sorted, v))
// [3, 0, 2, 0, 1]
```

- 값 하나의 순위를 찾는 데 O(log K)이고(K는 서로 다른 값의 수), 전체는 정렬 O(N log N) + 변환 O(N log K)입니다.
- 순위는 0부터 시작합니다. 1부터 필요하면 `+ 1`을 하거나 `sorted` 앞에 자리를 하나 두는 방식으로 일관되게 맞춥니다. 펜윅 트리는 1부터 쓰므로 `+ 1`이 필요합니다.
- `x`가 `sorted`에 없는 값이면 lower bound는 그 값이 들어갈 자리를 줍니다. 질의 값이 압축 대상이 아니어도 "이 값보다 작은 값이 몇 개인가"를 구할 수 있습니다.
- 같은 값은 항상 같은 순위를 받습니다. 순위가 같다고 오류가 아닙니다.

중복을 없애지 않고 정렬한 배열에서 lower bound를 쓰면 의미가 달라집니다.

| 사용한 배열 | 같은 값 5의 결과 | 의미 |
|-------------|------------------|------|
| 고유 값 배열 `[5, 70, 5000, 1000000]` | 0 | 더 작은 서로 다른 값의 수 |
| 중복 포함 `[5, 5, 70, 5000, 1000000]` | 0 | 더 작은 원소의 수(70은 2) |

- 위 예제에서 70의 결과는 고유 배열이면 1, 중복 포함이면 2입니다. 문제가 "서로 다른 값 중" 몇 번째인지, "원소 중" 몇 번째인지 묻는지 확인해야 합니다.
- 순위를 구하고 나서 원래 입력과 짝지을 수 있도록 입력 순서를 유지합니다. `arr.map(...)`은 입력 순서 그대로 결과를 줍니다.

**흔한 실수:** 비교 함수에 `<=`를 쓴 lower bound입니다. 같은 값이 있으면 한 칸 뒤를 가리켜 순위가 하나씩 밀립니다(upper bound).

## Map 기반 좌표 압축

값마다 이분 탐색을 하는 대신 `Map`에 값 → 순위를 한 번 저장해 두면 조회가 평균 O(1)입니다. 질의가 많을 때 유리합니다.

```js
function compress(vals) {
  const list = [...new Set(vals)].sort((a, b) => a - b)
  const idx = new Map(list.map((v, i) => [v, i]))
  return { list, idx }   // list[순위] = 값, idx.get(값) = 순위
}
const { list, idx } = compress([1000000, 5, 5000, 5, 70])
idx.get(5000) // 2
list[2]       // 5000 (복원)
```

- `list`가 순위 → 값, `idx`가 값 → 순위입니다. 양방향이 모두 있으면 압축 값에서 원래 값을 복원할 수 있습니다.
- 복원은 `list[rank]`로 O(1)입니다. 압축한 좌표 위에서 계산을 마치고 결과를 원래 단위로 출력할 때 씁니다.
- `Map`은 키를 SameValueZero로 비교하므로 숫자 키 `5`와 문자열 `'5'`는 다른 키입니다. 입력을 문자열로 읽었다면 `Number`로 바꾼 뒤 넣어야 합니다(자세히는 09편).
- 없는 값을 `idx.get`하면 `undefined`가 나옵니다. 그대로 인덱스로 쓰면 `NaN` 계산이 퍼지므로 모든 질의 값을 압축 대상에 미리 넣어 둡니다.
- 값이 BigInt이면 `1n`끼리는 같은 키로 취급되지만, 정렬 비교 함수에 뺄셈을 쓸 수 없어서 `a < b ? -1 : a > b ? 1 : 0`으로 써야 합니다(자세히는 02편).

값이 숫자가 아닐 때도 같은 방식입니다. 문자열은 정렬해 번호를 매기면 사전순 순위가 됩니다.

```js
const names = ['pear', 'apple', 'pear', 'fig']
const list = [...new Set(names)].sort()
// ['apple', 'fig', 'pear'] (문자열은 기본 정렬이 사전순)
```

- 이 경우 기본 `sort()`가 올바른 정렬입니다. 한글·대소문자가 섞여 있으면 UTF-16 코드 유닛 순서임을 기억합니다(자세히는 06편).
- 압축 순위를 단순한 번호 부여로만 쓰고 순서가 필요 없다면 정렬 없이 처음 만난 순서로 번호를 줍니다. `Map`에 없으면 `map.size`를 번호로 넣으면 됩니다.

```js
const id = new Map()
for (const v of vals) if (!id.has(v)) id.set(v, id.size)
// 첫 등장 순서대로 0, 1, 2, ...
```

- 이 방식은 대소 관계를 유지하지 않습니다. 인덱스 배열만 필요한 빈도 세기, 그래프 정점 번호 매기기에 쓰고 대소가 필요하면 정렬 방식을 씁니다.

**흔한 실수:**

- 압축한 순위 사이의 차이를 실제 거리처럼 쓰는 것입니다. 순위 2와 3이 이웃해도 원래 값은 5000과 1000000일 수 있습니다. 길이나 넓이를 구할 때는 `list[i + 1] - list[i]`처럼 원래 값으로 계산합니다.
- 구간 `[l, r)`의 끝점 `r`을 압축 대상에 넣지 않는 것입니다. 구간의 양 끝점은 모두 `vals`에 넣어야 합니다.

## 2차원 좌표 압축

2차원 좌표는 x와 y를 각각 따로 압축합니다. 점 `(x, y)`를 `(순위x, 순위y)`로 바꾸면 값이 10억인 평면이 점의 개수에 맞는 작은 격자로 줄어듭니다.

```js
const pts = [[10, 900], [500, 30], [10, 30]]
const X = compress(pts.map((p) => p[0]))  // list [10, 500]
const Y = compress(pts.map((p) => p[1]))  // list [30, 900]
const cp = pts.map(([x, y]) => [X.idx.get(x), Y.idx.get(y)])
// [[0, 1], [1, 0], [0, 0]]
```

- 점의 상대적 위치가 유지됩니다. x가 더 큰 점은 압축 x도 크고, 같은 x인 점은 같은 압축 x를 가집니다.
- 두 축은 독립으로 압축하므로 `(x, y)` 쌍 하나를 정수 하나로 만들 때는 `순위x * Y.list.length + 순위y`로 인코딩하면 Map 키로 쓰기 좋습니다(자세히는 09편).

사각형이 주어지는 문제에서는 압축한 격자의 칸이 원래 평면의 직사각형 영역이 됩니다. 칸 `(i, j)`는 x가 `X.list[i]`에서 `X.list[i + 1]` 사이, y가 `Y.list[j]`에서 `Y.list[j + 1]` 사이인 영역입니다. 칸 안은 모든 사각형에 대해 완전히 안 또는 밖이라서 칸마다 한 번만 판단하면 됩니다.

사각형 여러 개가 덮는 전체 넓이(겹침은 한 번만 계산)를 구하는 예입니다.

```js
function coverGrid(rects) {            // [x1, y1, x2, y2]
  const X = compress(rects.flatMap((r) => [r[0], r[2]]))
  const Y = compress(rects.flatMap((r) => [r[1], r[3]]))
  const ky = Y.list.length
  const hit = X.list.map(() => new Array(ky).fill(false))
  for (const [x1, y1, x2, y2] of rects) {
    for (let i = X.idx.get(x1); i < X.idx.get(x2); i++) {
      for (let j = Y.idx.get(y1); j < Y.idx.get(y2); j++) {
        hit[i][j] = true
      }
    }
  }
  return { X, Y, hit }
}
```

덮인 칸의 실제 넓이를 더합니다.

```js
function unionArea(rects) {
  const { X, Y, hit } = coverGrid(rects)
  let area = 0n
  for (let i = 0; i + 1 < X.list.length; i++) {
    for (let j = 0; j + 1 < Y.list.length; j++) {
      if (!hit[i][j]) continue
      const w = BigInt(X.list[i + 1] - X.list[i])
      const h = BigInt(Y.list[j + 1] - Y.list[j])
      area += w * h
    }
  }
  return area
}
unionArea([[0, 0, 4, 4], [2, 2, 6, 6]]) // 28n (16 + 16 - 4)
```

- 사각형 `[0,0,4,4]`와 `[2,2,6,6]`은 x 좌표 0, 2, 4, 6과 y 좌표 0, 2, 4, 6으로 압축됩니다. 3 × 3 칸 중 덮인 칸은 7개이고 칸 하나가 2 × 2이므로 넓이는 28입니다.
- 격자 크기는 K × K입니다(K는 한 축의 서로 다른 좌표 수, 최대 2N). 사각형이 N개면 격자가 최대 4N²칸이라 N이 수천을 넘으면 메모리·시간이 부족합니다. 그런 크기는 스위프 선(55편)과 구간 트리를 씁니다.
- 칸을 칠하는 반복이 느리면 사각형마다 네 모서리에 +1, -1을 찍고 2차원 누적합(29편)으로 한 번에 계산합니다. 사각형당 O(1)이 되어 전체 O(N + K²)입니다.
- 넓이는 한 변이 10억이면 곱이 10^18이라 Number의 안전한 정수 범위(2^53 - 1)를 넘을 수 있습니다. 그래서 칸 넓이를 BigInt로 곱했습니다(자세히는 02편).

**흔한 실수:** 사각형의 오른쪽·위쪽 끝 좌표를 압축 목록에 넣지 않거나, 마지막 칸 `X.list.length - 1`을 칸의 시작으로 쓰는 것입니다. 칸의 개수는 좌표 수보다 하나 적습니다.

## 핵심 정리

- 좌표 압축은 대소 관계를 유지한 채 큰 값을 작은 순위로 바꿔 인덱스로 쓰게 하는 기법이며 값 사이의 거리는 유지되지 않습니다.
- 정렬과 중복 제거는 `[...new Set(arr)].sort((a, b) => a - b)`이고 비교 함수를 빠뜨리면 문자열 순서가 됩니다.
- 값의 순위는 고유 값 배열에서의 lower bound이고, 같은 값은 같은 순위입니다. 중복을 지우지 않으면 의미가 달라집니다.
- `Map`에 값 → 순위를 저장하면 O(1)로 조회하고, 정렬된 배열로 순위 → 값 복원을 합니다. 순위 차이가 아니라 원래 값으로 거리를 계산합니다.
- 2차원은 x와 y를 따로 압축하고, 압축 격자의 칸은 원래 평면의 직사각형 영역이며 길이·넓이는 원래 좌표로 계산합니다.
