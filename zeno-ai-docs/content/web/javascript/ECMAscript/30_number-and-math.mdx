## 핵심 먼저 보기

- Number는 64비트 부동소수점이라 `0.1 + 0.2`처럼 2진수로 끝나지 않는 소수에 오차가 생기고, 정수는 `2 ** 53 - 1`까지만 정확합니다. 비교는 `Number.EPSILON`을 크기에 맞춰 씁니다.
- 판별은 인수를 변환하지 않는 `Number.isNaN`·`isFinite`·`isInteger`·`isSafeInteger`를 쓰고, `toFixed`·`toPrecision`·`toString`·`toLocaleString`의 결과는 문자열입니다.
- BigInt는 정수 전용이며 Number와 산술 연산을 섞거나 `JSON.stringify`·`Math` 메서드에 넘기면 TypeError입니다.
- `Math.round`는 동점을 `+Infinity` 쪽으로 보내 `-2.5`가 `-2`가 됩니다. min 이상 max 이하의 정수 난수는 `Math.floor(Math.random() * (max - min + 1)) + min`입니다.
- `Math.sumPrecise`(ES2026)는 정확한 합을 한 번만 반올림하고, `Math.f16round`(ES2025)는 16비트 부동소수점 값으로 반올림합니다.

## Number 생성자

Number 생성자는 값을 숫자로 바꾸는 함수이고, `new`와 함께 호출하면 숫자를 감싼 래퍼 객체를 만드는 생성자입니다. Number 타입의 값은 모두 하나의 형식(64비트 부동소수점)으로 저장되므로 정수와 실수를 구분하지 않습니다(자세히는 05편).

| 구분 | 멤버 | 다루는 곳 |
|------|------|-----------|
| 상수 | `MAX_VALUE`, `MIN_VALUE`, `EPSILON`, `MAX_SAFE_INTEGER`, `MIN_SAFE_INTEGER`, `POSITIVE_INFINITY`, `NEGATIVE_INFINITY`, `NaN` | 버전별 추가 기능 |
| 검사 | `isNaN`, `isFinite`, `isInteger`, `isSafeInteger` | 검사 절 |
| 파싱 | `parseInt`, `parseFloat` | 아래 |
| 서식 | `toFixed`, `toPrecision`, `toExponential`, `toString`, `toLocaleString` | 서식 절 |

## IEEE 754와 부동소수점 오차

IEEE 754는 부동소수점(floating point) 수의 저장 형식과 연산 규칙을 정한 국제 표준이고, Number는 그중 배정밀도(double precision) 64비트 형식입니다. 소수점의 위치를 지수로 옮기는 방식이라 아주 큰 수와 아주 작은 수를 함께 다룰 수 있는 대신, 모든 실수를 정확히 저장하지는 못합니다.

| 필드 | 비트 수 | 역할 |
|------|---------|------|
| 부호 | 1 | 0이면 양수, 1이면 음수 |
| 지수 | 11 | 편향값 1023을 뺀 2의 거듭제곱 |
| 가수 | 52 | `1.xxx` 형태의 소수부. 맨 앞의 1은 저장하지 않는다 |

```text
값 = (-1)^부호 × (1 + 가수 / 2^52) × 2^(지수 - 1023)
```

## Number.EPSILON

`Number.EPSILON`은 1 근처의 표현 간격입니다. 모든 크기의 숫자에 통하는 오차 한계가 아닙니다. 근삿값 비교에는 값의 크기와 문제에서 허용하는 절대·상대 오차를 함께 고려합니다.

## 안전한 정수 범위

안전한 정수는 Number로 정확히 표현되고, 이웃한 다른 정수와 같은 값으로 뭉개지지 않는 정수입니다. 범위는 `-(2 ** 53 - 1)`부터 `2 ** 53 - 1`까지입니다.

| 값의 범위 | 표현할 수 있는 정수 |
|-----------|---------------------|
| 2의 53제곱 미만 | 모든 정수 |
| 2의 53제곱 이상 2의 54제곱 미만 | 2의 배수만 |
| 2의 54제곱 이상 2의 55제곱 미만 | 4의 배수만 |

## NaN과 Infinity

`NaN`은 계산 결과가 유효한 수가 아님을 나타내는 Number 값이고, `Infinity`는 표현 범위를 넘는 크기를 나타내는 Number 값입니다. 둘 다 전역 프로퍼티(읽기 전용)이면서 `Number.NaN`, `Number.POSITIVE_INFINITY`로도 접근합니다. `NaN`의 성질(자기 자신과 같지 않음, 모든 비교가 `false`, falsy)은 05편에서 다룹니다.

| 원인 | 예 |
|------|----|
| 숫자로 변환 실패 | `Number('abc')`, `parseInt('x')`, `undefined + 1` |
| 결과가 정의되지 않는 연산 | `0 / 0`, `Infinity - Infinity`, `Infinity * 0`, `Infinity / Infinity` |
| 정의역 밖의 Math 인수 | `Math.sqrt(-1)`, `Math.log(-1)`, `Math.acos(2)` |
| `NaN`이 섞인 연산 | `NaN + 1`, `Math.max(1, NaN)` |

## isFinite·isInteger·isNaN·isSafeInteger

Number의 정적 메서드 네 개는 값이 어떤 종류의 숫자인지 검사합니다. 모두 ES2015에서 추가되었고 인수를 숫자로 변환하지 않습니다. 변환하는 쪽은 전역 함수 `isNaN`과 `isFinite`입니다(ES1).

| 함수 | `true`가 되는 조건 | 인수 변환 |
|------|--------------------|-----------|
| `Number.isNaN(x)` | Number 타입이고 `NaN` | 없음 |
| `Number.isFinite(x)` | Number 타입이고 `NaN`·`±Infinity`가 아님 | 없음 |
| `Number.isInteger(x)` | Number 타입이고 유한하며 소수부가 0 | 없음 |
| `Number.isSafeInteger(x)` | `isInteger`이면서 안전한 정수 범위 안 | 없음 |
| `isNaN(x)` | `Number(x)`가 `NaN` | 있음 |
| `isFinite(x)` | `Number(x)`가 유한한 수 | 있음 |

## toFixed·toPrecision·toString

`Number.prototype`의 서식 메서드는 숫자를 문자열로 만듭니다. 반환값이 문자열이므로 계산에 다시 쓰려면 `Number()`로 변환해야 합니다.

| 절댓값 | 표기 | 예 |
|--------|------|----|
| 1e21 이상 | 지수 표기 | `1e+21` |
| 1e-6 이상 1e21 미만 | 일반 표기 | `0.000001`, `123456789012345680000` |
| 1e-6 미만 | 지수 표기 | `1e-7`, `5e-7` |

## toLocaleString

`Number.prototype.toLocaleString(locales, options)`는 숫자를 지역 관습과 옵션에 맞춰 서식화한 문자열을 반환합니다. 내부적으로 `Intl.NumberFormat`을 쓰는 단축 호출입니다(자세히는 31편).

| 옵션 | 값 | 효과 |
|------|----|------|
| `style` | `'currency'`(+ `currency`), `'percent'`, `'unit'`(+ `unit`) | 통화·백분율·단위 서식 |
| `minimumFractionDigits`, `maximumFractionDigits` | 정수 | 소수 자릿수 범위 |
| `minimumIntegerDigits` | 정수 | 정수부 최소 자릿수(앞을 0으로 채움) |
| `notation` | `'compact'` | 큰 수를 줄여서 표기 |

## 숫자 구분자와 진법 리터럴

숫자 리터럴은 10진수 외에 16진·8진·2진과 지수 형태로 쓸 수 있고, 긴 숫자는 `_`로 끊어 읽기 쉽게 만들 수 있습니다. 어떤 표기든 결과는 같은 Number 값이며 출력은 항상 10진수입니다.

| 진법 | 접두사 | 예 | 값 |
|------|--------|----|----|
| 10진 | 없음 | `255` | 255 |
| 16진 | `0x`, `0X` | `0xff` | 255 |
| 2진 (ES2015) | `0b`, `0B` | `0b11111111` | 255 |
| 8진 (ES2015) | `0o`, `0O` | `0o377` | 255 |
| 지수 | `e`, `E` | `2.55e2` | 255 |

## BigInt

BigInt는 크기에 제한이 없는 정수를 정확히 다루는 원시 타입입니다(ES2020). Number의 안전한 정수 범위를 넘는 값을 다루려고 추가되었습니다.

| 입력 | 예 | 결과 |
|------|----|------|
| 정수인 Number | `BigInt(10)` | `10n` |
| 소수·`NaN`·`Infinity` | `BigInt(1.5)` | RangeError |
| 정수 형태의 문자열 | `BigInt(' 12 ')`, `BigInt('')`, `BigInt('0x1f')` | `12n`, `0n`, `31n` |
| 정수가 아닌 문자열 | `BigInt('1.5')`, `BigInt('1e3')`, `BigInt('abc')` | SyntaxError |
| 불리언 | `BigInt(true)` | `1n` |
| `null`, `undefined`, Symbol | `BigInt(null)` | TypeError |

## BigInt의 제약: 혼합 연산·JSON·Math

BigInt는 Number 중심으로 설계된 기능과 자동으로 호환되지 않습니다. 어느 방향으로 변환해도 정보를 잃을 수 있으므로 암묵적 변환을 허용하지 않고 명시적으로 변환하게 합니다.

## Math 객체

`Math`는 수학 상수와 함수를 담은 내장 객체입니다(내장 객체 전반은 20편). 생성자도 함수도 아니며 모든 멤버가 정적입니다. 호출은 `Math.메서드()` 형태로만 합니다.

| 상수 | 값 | 의미 |
|------|----|------|
| `Math.PI` | 3.141592653589793 | 원주율 |
| `Math.E` | 2.718281828459045 | 자연로그의 밑 |
| `Math.LN2` | 0.6931471805599453 | 2의 자연로그 |
| `Math.LN10` | 2.302585092994046 | 10의 자연로그 |
| `Math.LOG2E` | 1.4426950408889634 | e의 밑 2 로그 |
| `Math.LOG10E` | 0.4342944819032518 | e의 상용로그 |
| `Math.SQRT2` | 1.4142135623730951 | 2의 제곱근 |
| `Math.SQRT1_2` | 0.7071067811865476 | 1/2의 제곱근 |

## round·ceil·floor·abs

`Math.round(x)`는 가장 가까운 정수를 반환하고, 소수부가 정확히 `.5`인 동점이면 `+Infinity` 쪽(큰 쪽) 정수를 고릅니다. `Math.floor(x)`는 `x` 이하의 가장 큰 정수(내림), `Math.ceil(x)`는 `x` 이상의 가장 작은 정수(올림)입니다. 둘 다 수직선 방향이므로 음수에서는 "0에서 멀어지는 방향"이 아닙니다.

| x | `round` | `floor` | `ceil` |
|---|---------|---------|--------|
| 2.5 | 3 | 2 | 3 |
| 1.5 | 2 | 1 | 2 |
| 0.5 | 1 | 0 | 1 |
| -0.5 | -0 | -1 | -0 |
| -1.5 | -1 | -2 | -1 |
| -2.5 | -2 | -3 | -2 |

## max·min·pow·sqrt

`Math.max(...values)`와 `Math.min(...values)`는 인수 중 최댓값·최솟값을 반환합니다.

## Math.random과 정수 난수 공식

`Math.random()`은 0 이상 1 미만의 의사난수입니다. 정수 `min` 이상 `max` 이하가 필요하면 `Math.floor(Math.random() * (max - min + 1)) + min`을 씁니다. 비밀번호·토큰 등 보안 용도에는 암호학적 난수 API를 씁니다.

## Math.trunc·sign·hypot·cbrt·log 계열

`Math.trunc(x)`는 소수부를 버려 0 방향의 정수를 반환합니다(ES2015). 음수에서 `Math.floor`와 결과가 다릅니다.

| 메서드 | 값 | 예 |
|--------|----|----|
| `Math.exp(x)` | e의 x제곱 | `Math.exp(1)` → `2.718281828459045` |
| `Math.log(x)` | 자연로그 | `Math.log(Math.E)` → `1` |
| `Math.log10(x)` | 상용로그 | `Math.log10(1000)` → `3` |
| `Math.log2(x)` | 밑이 2인 로그 | `Math.log2(1024)` → `10` |
| `Math.log1p(x)` | `Math.log(1 + x)` | 0에 가까운 `x`에서 정밀 |
| `Math.expm1(x)` | `Math.exp(x) - 1` | 0에 가까운 `x`에서 정밀 |

## Math.sumPrecise (ES2026)

`Math.sumPrecise(iterable)`는 숫자들의 합을 중간 반올림 없이 정확한 값으로 계산한 뒤 한 번만 Number로 반올림해 반환합니다(ES2026). MDN은 2026년 4월부터 최신 브라우저에서 쓸 수 있다고 표시합니다. 지원하지 않는 환경이 있을 수 있으므로 쓰기 전에 `typeof Math.sumPrecise === 'function'`으로 확인합니다.

## Math.f16round (ES2025)

`Math.f16round(x)`는 `x`를 16비트 반정밀도 부동소수점으로 표현할 수 있는 가장 가까운 값으로 반올림해, 그 값을 일반 Number로 반환합니다(ES2025). 같은 해 추가된 `Float16Array`(48편)에 저장될 값을 미리 계산하거나 낮은 정밀도를 흉내 낼 때 씁니다. MDN은 2025년 4월부터 최신 브라우저에서 쓸 수 있다고 표시합니다.

| 형식 | 크기 | 지수 | 가수 | 반올림 메서드 |
|------|------|------|------|---------------|
| 배정밀도 (Number) | 64비트 | 11 | 52 | 없음 |
| 단정밀도 | 32비트 | 8 | 23 | `Math.fround` (ES2015) |
| 반정밀도 | 16비트 | 5 | 10 | `Math.f16round` (ES2025) |
