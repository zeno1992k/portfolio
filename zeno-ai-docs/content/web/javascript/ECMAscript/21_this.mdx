## 핵심 먼저 보기

- `this`는 함수가 호출될 때 호출 방식으로 정해집니다. 선언 위치로 정해지는 스코프와 다릅니다.
- 일반 호출은 `globalThis`(비엄격)·`undefined`(엄격), 메서드 호출은 점 앞의 객체, `new`는 새 인스턴스, `call`·`apply`·`bind`는 지정한 값입니다.
- 메서드를 변수·콜백·구조 분해로 떼어 내면 일반 호출이 되어 `this`를 잃습니다. 클래스 메서드는 엄격 모드라서 TypeError가 납니다.
- 화살표 함수는 자신의 `this`가 없어 바깥 `this`를 쓰고 `call`·`apply`·`bind`·`new`로 바꿀 수 없습니다. 콜백에는 알맞고 메서드와 생성자에는 맞지 않습니다.
- 최상위 `this`는 일반 스크립트에서 `globalThis`, ES 모듈에서 `undefined`, CommonJS에서 `module.exports`입니다.
- 우선순위는 화살표 함수, `new`, 바운드 함수, `call`·`apply`, 메서드 호출, 일반 호출 순입니다.

## this의 필요성

`this`는 코드가 속한 객체, 또는 생성자가 만들 인스턴스를 가리키는 키워드입니다. 메서드가 자기 객체의 프로퍼티를 읽으려면 그 객체를 가리킬 방법이 필요합니다.

```js
const circle = {
  radius: 5,
  getDiameter() { return 2 * circle.radius }, // ❌
}
const copy = { ...circle, radius: 10 }
copy.getDiameter() // 10 (기대값은 20)
```

## 호출 방식과 this 바인딩

this 바인딩은 `this`에 값이 연결되는 일이며, 함수가 호출되는 시점에 호출 방식으로 결정됩니다. 스코프는 함수를 어디에 선언했는지로 정해지고(자세히는 12편), `this`는 어떻게 호출했는지로 정해집니다. 객체 안에 선언한 함수도 떼어 내 호출하면 객체와 관계가 끊깁니다.

| 호출 방식 | 예 | this |
|-----------|----|------|
| 일반 함수 호출 | `f()` | 비엄격 모드는 `globalThis`, 엄격 모드는 `undefined` |
| 메서드 호출 | `obj.f()` | `obj` |
| 생성자 호출 | `new F()` | 새로 만든 인스턴스 |
| 간접 호출 | `f.call(x)`, `f.apply(x)`, `f.bind(x)()` | `x` |
| 화살표 함수 | `() => this` | 바깥 스코프의 `this` |

```js
function show() { 'use strict'; return this }
const obj = { show }

show()             // undefined
obj.show() === obj // true
new show()         // show {} (새 인스턴스)
show.call(7)       // 7
```

## 일반 함수 호출

일반 함수 호출은 `f()`처럼 앞에 점이나 `new`가 없는 호출입니다. 객체 안에서 선언했더라도 호출 형태가 `f()`이면 일반 호출이고, 중첩 함수, 콜백, 즉시 실행 함수도 모두 해당합니다.

| 모드 | this |
|------|------|
| 비엄격 모드 | `globalThis` |
| 엄격 모드 | `undefined` |

## 메서드 호출

`obj.fn()`에서 `this`는 `obj`입니다. `const fn = obj.fn; fn()`처럼 꺼내 호출하면 원래 객체와의 연결이 사라집니다. 콜백에는 `bind`하거나 `() => obj.fn()`처럼 감싸 넘깁니다.

## 생성자 함수 호출

`new F()`로 호출하면 `this`는 엔진이 새로 만든 인스턴스입니다. 생성 과정과 반환 규칙은 15편에서 다루고, 여기서는 `this`와 관련된 규칙만 정리합니다.

## call·apply·bind

`call`, `apply`, `bind`는 호출 방식과 무관하게 `this`를 직접 지정하는 `Function.prototype`의 메서드입니다(자세히는 17편). 모든 함수가 프로토타입 체인으로 상속받습니다.

| 메서드 | 함수 호출 | 인수 전달 | 반환값 |
|--------|-----------|-----------|--------|
| `call(thisArg, a, b)` | 즉시 호출 | 낱개로 나열 | 함수의 결과 |
| `apply(thisArg, [a, b])` | 즉시 호출 | 배열 하나 | 함수의 결과 |
| `bind(thisArg, a, b)` | 호출하지 않음 | 낱개로 나열(미리 채움) | `this`가 고정된 새 함수 |

## 중첩 함수와 콜백의 this 손실

메서드 안에서 일반 호출되는 중첩 함수와 콜백의 `this`는 메서드의 `this`가 아니라 일반 호출 규칙을 따릅니다. 함수 안에 함수를 선언해도 호출 방식이 바뀌지 않기 때문입니다.

| 방법 | 형태 | 비고 |
|------|------|------|
| 화살표 함수 | `[1].map(() => this.id)` | ES2015. 가장 간단하다 |
| 변수에 저장 | `const self = this` 후 `self.id` | 클로저로 동작(자세히는 23편). ES5 시대 관용구 |
| bind | `read.bind(this)` | 기존 함수를 재사용할 때 |
| thisArg | `[1].map(read, this)` | 지원하는 내장 API만 |

## 화살표 함수의 this

화살표 함수는 자신의 `this` 바인딩이 없습니다. `this`를 쓰면 스코프 체인을 따라 바깥 함수나 전역의 `this`를 찾으며(렉시컬 this), 호출 방식이 아니라 함수가 정의된 위치가 값을 정합니다.

| 용도 | 권장 | 이유 |
|------|------|------|
| 객체 메서드, 프로토타입 메서드 | 메서드 축약 표현, 일반 함수 | 호출한 객체가 `this`여야 한다 |
| 생성자 | 일반 함수, 클래스 | 화살표 함수는 `new` 불가 |
| 메서드 안의 콜백, 중첩 함수 | 화살표 함수 | 바깥 `this`를 유지한다 |
| 리스너에서 `this`로 요소를 받을 때 | 일반 함수 | 화살표 함수는 요소를 `this`로 받지 못한다. `event.currentTarget`은 쓸 수 있다 |

## 클래스 메서드를 콜백으로 넘길 때

클래스 본문은 항상 엄격 모드이므로(자세히는 24편), 메서드를 떼어 내 일반 호출하면 `this`가 `undefined`가 되어 TypeError가 납니다. 비엄격 모드의 일반 함수는 `globalThis`로 조용히 틀리지만 클래스는 바로 에러로 드러납니다.

| 방법 | 코드 | 특징 |
|------|------|------|
| 호출 지점에서 감싸기 | `() => b.handle()` | 간단하지만 호출처마다 써야 한다 |
| 호출 지점에서 bind | `b.handle.bind(b)` | 호출할 때마다 새 함수가 생긴다 |
| 생성자에서 bind | `this.handle = this.handle.bind(this)` | 인스턴스마다 바운드 함수를 만든다 |
| 클래스 필드 화살표 함수 | `handle = () => this.label` | ES2022. 인스턴스마다 함수를 만든다 |

## 모듈·전역 최상위의 this

함수 밖 최상위 코드의 `this`는 실행 환경과 코드 종류에 따라 다릅니다.

| 위치 | this |
|------|------|
| 브라우저 일반 스크립트 최상위 | `window`(`globalThis`) |
| 브라우저 모듈 스크립트(`type="module"`) 최상위 | `undefined` |
| Node.js CommonJS 파일 최상위 | `module.exports`(처음에는 빈 객체) |
| Node.js ES 모듈 최상위 | `undefined` |
| 비엄격 함수 안의 일반 호출 | `globalThis` |
| 엄격 함수 안의 일반 호출 | `undefined` |

## bind는 다시 바인딩되지 않음

`bind`가 반환하는 바운드 함수는 `this`를 내부 슬롯에 고정해 두고 호출될 때마다 그 값을 대상 함수에 넘깁니다. 그래서 이후 어떤 방법으로도 `this`를 바꿀 수 없습니다.

## 결정 규칙 우선순위 표

화살표 함수는 바깥 `this`를 유지합니다. 일반 함수는 `new` 호출, 바인딩된 함수, `call`·`apply`, 메서드 호출, 일반 호출 여부를 확인합니다. `new`로 바인딩된 함수를 호출하면 바인딩해 둔 `this`는 무시됩니다.
