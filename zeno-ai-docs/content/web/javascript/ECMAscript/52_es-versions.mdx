## 핵심 먼저 보기

- ES5(2009)는 strict mode, JSON, 배열 반복 메서드, `Object.defineProperty`를 추가했고, ES2015는 `let`·`const`, 화살표 함수, 클래스, 모듈, 프로미스, 이터러블 등 언어의 뼈대를 만들었습니다.
- ES2016–2022는 `**`·`includes`, `async`/`await`, 객체 스프레드, `?.`·`??`, `BigInt`, `replaceAll`, 클래스 필드, 최상위 `await`로 이어집니다.
- ES2023–2025는 복사본 반환 배열 메서드, `groupBy`, `withResolvers`, `Set` 집합 메서드, 이터레이터 헬퍼, `Promise.try`, `RegExp.escape`를 추가했습니다.
- ES2026은 `Array.fromAsync`, `Error.isError`, `Math.sumPrecise`, `Uint8Array` Base64·Hex, `Iterator.concat`, `JSON.parse` 원문 접근, `getOrInsert`를 추가했고, Temporal과 `using`은 ES2027 예정입니다.
- 3단계 이하 제안은 바뀔 수 있으므로 지원 여부는 MDN·Baseline으로, 메서드는 기능 검사로, 문법은 `new Function` 파싱으로 확인하고, 구형 대상은 트랜스파일러와 폴리필로 대응합니다.

## 판 번호와 표기

ECMA-262는 2015년 이전에는 판 번호(ES3, ES5)로, 2015년 이후에는 연도(ES2015, ES2016)로 부릅니다. ES6과 ES2015는 같은 판입니다.

| 표기 | 판 번호 | 발행 |
|------|---------|------|
| ES3 | 3판 | 1999년 |
| ES4 | - | 폐기(2008년) |
| ES5 / ES5.1 | 5판 | 2009년 / 2011년 |
| ES2015 | 6판 | 2015년 6월 |
| ES2016 – ES2025 | 7판 – 16판 | 매년 6월 |
| ES2026 | 17판 | 2026년 6월 30일 총회 승인 |

## ES5 (2009)

ES5는 2009년에 발행되고 2011년에 ES5.1로 정리된 판입니다. 구형 환경을 지원할 때 기준선이 되는 판이며, 오늘날 `var`·함수 중심 코드는 대부분 ES5 문법입니다.

<details>
<summary>전체 비교표 펼치기</summary>

| 기능 | 동작 | 자세히 |
|------|------|--------|
| strict mode | `'use strict'`로 켜는 제한 모드 | 19편 |
| JSON | `JSON.parse`, `JSON.stringify` | 39편 |
| 배열 반복 메서드 | `forEach` `map` `filter` `reduce` `reduceRight` `every` `some` | 29편 |
| 배열 검사·검색 | `Array.isArray`, `indexOf`, `lastIndexOf` | 28편 |
| 프로퍼티 이름 조회 | `Object.keys`, `Object.getOwnPropertyNames` | 18편 |
| 프로토타입 | `Object.create`, `Object.getPrototypeOf` | 17편 |
| 프로퍼티 어트리뷰트 | `Object.defineProperty`, `defineProperties`, `getOwnPropertyDescriptor` | 14편 |
| 객체 잠금 | `Object.freeze`, `seal`, `preventExtensions`와 `isFrozen` 등 검사 함수 | 14편 |
| 접근자 프로퍼티 | 리터럴 안의 `get`·`set` | 14편 |
| `Function.prototype.bind` | `this`를 고정한 새 함수 반환 | 21편 |
| 기타 | `String.prototype.trim`, `Date.now`, `Date.prototype.toISOString` | 33·31편 |

</details>

```js
var o = Object.create({ hi: 1 })
Object.defineProperty(o, 'id', { value: 7 })
o.id = 8        // strict면 TypeError, 아니면 무시
o.id            // 7 (writable 기본값 false)
Object.keys(o)  // [] (enumerable 기본값 false)
o.hi            // 1 (프로토타입에서 상속)
```

## ES2015

ES2015(ES6)는 역대 최대 개편으로, 오늘날 JavaScript 문법의 뼈대를 만들었습니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `let`, `const` | 블록 스코프, 선언 전 접근은 ReferenceError(TDZ) | 13편 |
| 화살표 함수 | 자체 `this`·`arguments`가 없다 | 27편 |
| 기본값·나머지 매개변수 | `function f(a, b = 1, ...rest)` | 27편 |
| `new.target` | 생성자 호출 여부 확인 | 15편 |
| 블록 수준 함수 선언 | 블록 안의 함수 선언을 블록 스코프로 | 12편 |
| 꼬리 호출 최적화 | 명세에는 있으나 Safari(JavaScriptCore)만 구현 | - |

```js
const [a, b = 2, ...rest] = [1, undefined, 3, 4]
// a=1, b=2, rest=[3, 4]
const f = (x, y = x * 2) => x + y
f(1)                 // 3
`1+1=${1 + 1}`       // '1+1=2'
function* nat() { let i = 0; while (true) yield i++ }
const [p, q] = nat() // p=0, q=1
```

## ES2016–2017

ES2016은 변경이 두 가지뿐인 작은 판입니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `**`, `**=` | 거듭제곱. 오른쪽 결합 | 06편 |
| `Array.prototype.includes` | 요소 포함 여부를 boolean으로 반환 | 28편 |

## ES2018–2019

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 객체 나머지·스프레드 | `{ ...obj }`, `const { a, ...rest } = obj` | 36·37편 |
| 비동기 이터레이션 | `for await...of`, 비동기 제너레이터, `Symbol.asyncIterator` | 42·43편 |
| `Promise.prototype.finally` | 성공·실패와 무관하게 실행 | 41편 |
| 정규식 이름 붙은 캡처 그룹 | `(?<y>\d{4})`, `groups.y` | 32편 |
| 정규식 후방 탐색 | `(?<=…)`, `(?<!…)` | 32편 |
| 정규식 `s` 플래그 | `.`이 줄바꿈도 매칭 | 32편 |
| 정규식 유니코드 속성 이스케이프 | `\p{Script=Hangul}` (`u` 플래그 필요) | 32편 |
| 태그드 템플릿 제한 완화 | 잘못된 이스케이프를 태그 함수에서 허용 | 33편 |

- 객체 스프레드는 자체 열거 가능 프로퍼티만 얕게 복사합니다. `{ ...null }`은 오류 없이 `{}`입니다.
- 태그드 템플릿에서 잘못된 이스케이프(`\unicode`)가 있으면 `strings[0]`은 `undefined`, `raw`는 원문입니다. 태그 없는 템플릿은 여전히 SyntaxError입니다.
- `finally` 콜백의 반환값은 결과를 바꾸지 않습니다. 콜백이 예외를 던지거나 거부된 프로미스를 반환할 때만 바뀝니다.

## ES2020

<details>
<summary>전체 비교표 펼치기</summary>

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 옵셔널 체이닝 `?.` | `null`·`undefined`면 `undefined`로 중단 | 06편 |
| 널 병합 `??` | `null`·`undefined`일 때만 오른쪽 값 | 08편 |
| `BigInt` | 크기 제한 없는 정수, 리터럴 `10n` | 05편 |
| `Promise.allSettled` | 모든 프로미스의 결과를 상태와 함께 반환 | 41편 |
| `globalThis` | 환경 무관 전역 객체 | 13편 |
| 동적 `import()` | 모듈을 프로미스로 로드 | 45편 |
| `import.meta` | 현재 모듈 메타데이터(`import.meta.url`) | 46편 |
| `String.prototype.matchAll` | 모든 매칭을 이터레이터로 | 32편 |
| `export * as ns from` | 모듈 전체를 이름 붙여 재내보내기 | 45편 |
| `for-in` 순회 순서 | 순회 규칙을 명세에 규정 | 18편 |

</details>

- `?.`는 뒤따르는 체인 전체를 건너뜁니다. `a?.b.c`에서 `a`가 `null`이면 `.c`는 평가되지 않습니다.
- `a?.b = 1`처럼 옵셔널 체인에 대입하면 SyntaxError입니다.
- `??`를 괄호 없이 `||`·`&&`와 섞으면 SyntaxError입니다. `null ?? 1 || 2`는 오류, `(null ?? 1) || 2`는 1입니다.
- `BigInt`와 `Number`는 섞을 수 없습니다. `1n + 1`은 TypeError이고, 나눗셈은 버림이라 `5n / 2n`은 `2n`입니다. `JSON.stringify`도 `BigInt`에서 TypeError입니다.
- `matchAll`에 `g` 플래그 없는 정규식을 넘기면 TypeError입니다.

## ES2021–2022

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `String.prototype.replaceAll` | 모든 일치를 치환 | 33편 |
| `Promise.any` | 가장 먼저 이행한 프로미스, 모두 거부면 `AggregateError` | 41편 |
| 논리 대입 연산자 | `&&=`, `??=`와 `\|\|=` | 06편 |
| 숫자 구분자 | `1_000_000` | 05편 |
| `WeakRef`, `FinalizationRegistry` | 약한 참조와 정리 콜백 | 49편 |

- 논리 대입은 단락 평가합니다. `a ||= b`는 `a || (a = b)`와 같아서 `a`가 참이면 대입이 일어나지 않고 setter도 호출되지 않습니다.
- `replaceAll`에 정규식을 넘기면 `g` 플래그가 필수이며, 없으면 TypeError입니다.
- 모든 프로미스가 거부되면 `Promise.any`는 `AggregateError`로 거부하고 각 이유는 `errors` 배열에 담깁니다.
- `WeakRef`의 `deref()`와 정리 콜백의 실행 시점은 보장되지 않습니다.

## ES2023–2025

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `toSorted`, `toReversed`, `toSpliced`, `with` | 원본을 바꾸지 않는 복사본 반환 | 28편 |
| `findLast`, `findLastIndex` | 뒤에서부터 검색 | 28편 |
| 해시뱅 문법 | 첫 줄 `#!/usr/bin/env node`를 주석으로 허용 | 46편 |
| 심벌을 `WeakMap` 키로 | 등록되지 않은 심벌만 가능 | 38편 |

- `with`의 인덱스가 범위를 벗어나면 RangeError입니다.
- Typed Array도 `toSorted`, `toReversed`, `with`를 가집니다. `toSpliced`는 배열만 가집니다.
- `Symbol.for`로 만든 등록 심벌은 `WeakMap` 키로 쓸 수 없습니다(TypeError).
- 해시뱅은 파일 맨 첫 줄에서만 유효합니다.

## ES2026 확정 기능

ES2026(17판)은 2026년 6월 30일 총회에서 승인되었습니다. TC39 목록 기준으로 일곱 가지 기능이 추가되었습니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Array.fromAsync` | 비동기 이터러블을 배열로 | 28편 |
| `Error.isError` | 값이 에러 객체인지 판별 | 44편 |
| `Math.sumPrecise` | 부동소수점 오차를 최소화한 합 | 30편 |
| `Uint8Array` Base64·Hex | `toBase64`, `fromBase64`, `toHex`, `fromHex` | 48편 |
| `Iterator.concat` | 여러 이터러블을 순서대로 이어 붙임 | 35편 |
| `JSON.parse` 원문 접근 | reviver의 `context.source`, `JSON.rawJSON` | 39편 |
| `Map`·`WeakMap` upsert | `getOrInsert`, `getOrInsertComputed` | 38편 |

## ES2027 예정 기능

2026년 10월 기준으로 4단계에 올라 2027년 판에 들어갈 예정인 기능입니다. 판은 2027년 6월 승인이 예정되어 있으며, 아직 확정 전입니다. 엔진 지원은 MDN에서 확인합니다.

| 기능 | 동작 |
|------|------|
| Temporal | `Date`를 대체하는 날짜·시간 API |
| 명시적 자원 관리 | `using`, `await using`, `Symbol.dispose` |
| Joint Iteration | `Iterator.zip`, `Iterator.zipKeyed` |
| 이터레이터 청킹 | `chunks(n)`, `windows(n)` |
| `Iterator.prototype.join` | 이터레이터를 문자열로 합치기 |
| `Iterator.prototype.includes` | 이터레이터 요소 포함 여부 |
| `Atomics.pause` | 스핀 루프용 짧은 대기 |

## Stage 제안

4단계 아래에 있는 제안은 문법과 동작이 바뀔 수 있습니다. 단계의 정의와 절차는 01편에서 다룹니다. 아래는 2026년 10월 확인한 TC39 제안 목록입니다.

<details>
<summary>전체 비교표 펼치기</summary>

| 제안 | 내용 |
|------|------|
| Source Phase Imports | `import source x from './m.wasm'`처럼 모듈을 실행하지 않고 소스 객체로 가져옴 |
| Deferring Module Evaluation | `import defer * as ns from 'y'`처럼 로드만 하고 평가는 첫 접근까지 미룸 |
| Import Text | `import t from './a.txt' with { type: 'text' }` |
| Await Dictionary | `Promise.allKeyed`, `Promise.allSettledKeyed`로 객체의 프로미스 값을 병렬 대기 |
| RegExp Buffer Boundaries | `u` 모드에서 `\A`, `\z`, `\Z`로 입력 전체의 시작·끝 지정 |
| Non-extensible Applies to Private | 확장 불가 객체에 private 필드 추가를 TypeError로 |
| Error Stack Accessor | `Error`의 `stack`을 접근자로 표준화 |
| Legacy RegExp features | `RegExp.$1` 같은 정적 프로퍼티와 `compile` 표준화 |
| Dynamic Code Brand Checks | `eval`·`Function`에 호스트 보안 검사(Trusted Types) 연동 |
| Curtailing the power of Thenables | thenable 처리 범위 축소 |

</details>

## 지원 여부 확인 방법

기능이 표준이 되었다고 해서 대상 환경에서 동작하는 것은 아닙니다. 판 번호, 엔진 지원, 대상 환경 세 가지를 따로 확인합니다.

| 확인 대상 | 도구 |
|-----------|------|
| 브라우저·엔진별 지원 | MDN의 Browser compatibility 표, Can I use |
| 표준 상태·판 | TC39 finished-proposals |
| Node.js 버전별 지원 | node.green, Node.js 문서의 버전 표기 |
| 종합 지원표 | compat-table(ES2016 이후 항목) |
| 안정성 판단 | Baseline (Widely available = 모든 주요 브라우저에서 30개월 이상) |
