## 판 번호와 표기

ECMA-262는 2015년 이전에는 판 번호(ES3, ES5)로, 2015년 이후에는 연도(ES2015, ES2016)로 부릅니다. ES6과 ES2015는 같은 판입니다.

| 표기 | 판 번호 | 발행 |
|------|---------|------|
| ES3 | 3판 | 1999년 |
| ES4 | - | 폐기(2008년) |
| ES5 / ES5.1 | 5판 | 2009년 / 2011년 |
| ES2015 | 6판 | 2015년 6월 |
| ES2016 – ES2025 | 7판 – 16판 | 매년 6월 |
| ES2026 | 17판 | 2026년 6월 30일 총회 승인 |

- 새 판에는 그해 초까지 4단계에 오른 제안만 들어갑니다. 판의 연도와 엔진이 기능을 출시한 시점은 다릅니다. 이미 쓸 수 있는 기능이 나중 판에 기록되기도 합니다.
- 이 문서의 판별 분류는 TC39의 finished-proposals 목록(2026년 10월 확인)을 기준으로 합니다.

## ES5 (2009)

ES5는 2009년에 발행되고 2011년에 ES5.1로 정리된 판입니다. 구형 환경을 지원할 때 기준선이 되는 판이며, 오늘날 `var`·함수 중심 코드는 대부분 ES5 문법입니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| strict mode | `'use strict'`로 켜는 제한 모드 | 19편 |
| JSON | `JSON.parse`, `JSON.stringify` | 39편 |
| 배열 반복 메서드 | `forEach` `map` `filter` `reduce` `reduceRight` `every` `some` | 29편 |
| 배열 검사·검색 | `Array.isArray`, `indexOf`, `lastIndexOf` | 28편 |
| 프로퍼티 이름 조회 | `Object.keys`, `Object.getOwnPropertyNames` | 18편 |
| 프로토타입 | `Object.create`, `Object.getPrototypeOf` | 17편 |
| 프로퍼티 어트리뷰트 | `Object.defineProperty`, `defineProperties`, `getOwnPropertyDescriptor` | 14편 |
| 객체 잠금 | `Object.freeze`, `seal`, `preventExtensions`와 `isFrozen` 등 검사 함수 | 14편 |
| 접근자 프로퍼티 | 리터럴 안의 `get`·`set` | 14편 |
| `Function.prototype.bind` | `this`를 고정한 새 함수 반환 | 21편 |
| 기타 | `String.prototype.trim`, `Date.now`, `Date.prototype.toISOString` | 33·31편 |

문법도 완화되었습니다.

- 객체 리터럴 마지막 프로퍼티 뒤의 쉼표를 허용합니다.
- 예약어를 프로퍼티 이름으로 쓸 수 있습니다(`obj.class`).
- 문자열 인덱스 접근을 허용합니다(`'abc'[0]`).
- `parseInt('010')`은 10입니다. 이전에는 구현에 따라 8진수로 해석했습니다.

```js
var o = Object.create({ hi: 1 })
Object.defineProperty(o, 'id', { value: 7 })
o.id = 8        // strict면 TypeError, 아니면 무시
o.id            // 7 (writable 기본값 false)
Object.keys(o)  // [] (enumerable 기본값 false)
o.hi            // 1 (프로토타입에서 상속)
```

- `Object.freeze`는 얕은 잠금입니다. 중첩 객체의 프로퍼티는 계속 바꿀 수 있습니다.
- 초깃값 없이 빈 배열에 `reduce`를 호출하면 TypeError입니다.
- `forEach`와 `map`은 중간에 멈출 수 없습니다.

## ES2015

ES2015(ES6)는 역대 최대 개편으로, 오늘날 JavaScript 문법의 뼈대를 만들었습니다.

### 선언과 함수

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `let`, `const` | 블록 스코프, 선언 전 접근은 ReferenceError(TDZ) | 13편 |
| 화살표 함수 | 자체 `this`·`arguments`가 없다 | 27편 |
| 기본값·나머지 매개변수 | `function f(a, b = 1, ...rest)` | 27편 |
| `new.target` | 생성자 호출 여부 확인 | 15편 |
| 블록 수준 함수 선언 | 블록 안의 함수 선언을 블록 스코프로 | 12편 |
| 꼬리 호출 최적화 | 명세에는 있으나 Safari(JavaScriptCore)만 구현 | - |

### 문법

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 템플릿 리터럴 | 백틱, `${}` 삽입, 여러 줄, 태그드 템플릿 | 33편 |
| 구조 분해 할당 | 배열·객체 패턴 | 37편 |
| 스프레드·나머지 | 배열 요소와 인수 펼치기 | 36편 |
| 객체 리터럴 확장 | 단축 프로퍼티, 계산된 이름, 메서드 축약 | 09편 |
| 이진·8진 리터럴 | `0b101`, `0o17` | 05편 |
| 유니코드 이스케이프 | `\u{1F600}` | 33편 |

### 클래스·모듈·비동기

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `class` | 생성자 함수·프로토타입 위의 문법, `extends`, `super` | 24·25편 |
| 모듈 | `import`, `export` | 45편 |
| 이터러블, `for...of` | `Symbol.iterator` 프로토콜 | 35편 |
| 제너레이터 | `function*`, `yield` | 42편 |
| `Symbol` | 유일한 원시 값, 잘 알려진 심벌 | 34편 |
| `Promise` | 비동기 결과 객체 | 41편 |

### 내장 객체와 메서드

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Map`, `Set`, `WeakMap`, `WeakSet` | 새 컬렉션 | 38편 |
| `Proxy`, `Reflect` | 객체 연산 가로채기 | 47편 |
| Typed Array, `ArrayBuffer` | 바이너리 데이터 | 48편 |
| `Object` | `assign`, `is`, `setPrototypeOf`, `getOwnPropertySymbols` | 20편 |
| `Array` | `from`, `of`, `find`, `findIndex`, `fill`, `copyWithin`, `keys`, `values`, `entries` | 28편 |
| `String` | `includes`, `startsWith`, `endsWith`, `repeat`, `codePointAt`, `fromCodePoint`, `normalize`, `raw` | 33편 |
| `Number`, `Math` | `Number.isInteger`, `isSafeInteger`, `EPSILON`, `Math.trunc`, `sign`, `cbrt`, `hypot` 등 | 30편 |
| 정규식 | `u`(유니코드), `y`(sticky) 플래그 | 32편 |

```js
const [a, b = 2, ...rest] = [1, undefined, 3, 4]
// a=1, b=2, rest=[3, 4]
const f = (x, y = x * 2) => x + y
f(1)                 // 3
`1+1=${1 + 1}`       // '1+1=2'
function* nat() { let i = 0; while (true) yield i++ }
const [p, q] = nat() // p=0, q=1
```

- 이터러블은 코드 포인트 단위로 순회하므로 `'a😀'.length`는 3이지만 `[...'a😀'].length`는 2입니다.
- 기본값은 인수가 `undefined`일 때만 적용됩니다. `null`과 `0`은 그대로 전달됩니다.
- `class`는 선언 전에 쓰면 TDZ 오류입니다. 함수 선언처럼 끌어올려지지 않습니다.

## ES2016–2017

### ES2016

ES2016은 변경이 두 가지뿐인 작은 판입니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `**`, `**=` | 거듭제곱. 오른쪽 결합 | 06편 |
| `Array.prototype.includes` | 요소 포함 여부를 boolean으로 반환 | 28편 |

```js
2 ** 3 ** 2      // 512 (2 ** 9, 오른쪽 결합)
-2 ** 2          // SyntaxError (괄호가 필요)
(-2) ** 2        // 4
[NaN].indexOf(NaN)   // -1
[NaN].includes(NaN)  // true
```

- `includes`는 SameValueZero로 비교합니다. `NaN`을 찾고, `-0`과 `0`을 같다고 봅니다.
- `-2 ** 2`가 오류인 것은 단항 연산자와 `**`의 우선순위가 모호하기 때문입니다.

### ES2017

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `async`/`await` | 프로미스를 동기 코드처럼 쓰는 문법 | 43편 |
| `Object.values`, `Object.entries` | 값 배열, `[키, 값]` 배열 | 18편 |
| `Object.getOwnPropertyDescriptors` | 모든 프로퍼티 디스크립터 | 14편 |
| `padStart`, `padEnd` | 지정 길이까지 채우기 | 33편 |
| 후행 쉼표 | 함수 매개변수·인수 목록 끝 쉼표 | 11편 |
| `SharedArrayBuffer`, `Atomics` | 스레드 간 공유 메모리 | 48편 |

```js
Object.entries({ a: 1, b: 2 })  // [['a', 1], ['b', 2]]
'5'.padStart(3, '0')            // '005'
'ab'.padEnd(4, '-')             // 'ab--'
async function load() { return 1 }
load()                          // Promise (1로 이행)
```

- `async` 함수는 반환값이 무엇이든 항상 프로미스를 반환합니다.
- `await`는 ES2017에서는 `async` 함수 안에서만 쓸 수 있었습니다. 모듈 최상위는 ES2022부터입니다.
- 나머지 매개변수 뒤의 쉼표(`function f(...r,)`)는 SyntaxError입니다.
- 브라우저는 2018년 Spectre 취약점 대응으로 `SharedArrayBuffer`를 막았고, 교차 출처 격리(COOP·COEP) 환경에서만 다시 허용했습니다.

## ES2018–2019

### ES2018

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 객체 나머지·스프레드 | `{ ...obj }`, `const { a, ...rest } = obj` | 36·37편 |
| 비동기 이터레이션 | `for await...of`, 비동기 제너레이터, `Symbol.asyncIterator` | 42·43편 |
| `Promise.prototype.finally` | 성공·실패와 무관하게 실행 | 41편 |
| 정규식 이름 붙은 캡처 그룹 | `(?<y>\d{4})`, `groups.y` | 32편 |
| 정규식 후방 탐색 | `(?<=…)`, `(?<!…)` | 32편 |
| 정규식 `s` 플래그 | `.`이 줄바꿈도 매칭 | 32편 |
| 정규식 유니코드 속성 이스케이프 | `\p{Script=Hangul}` (`u` 플래그 필요) | 32편 |
| 태그드 템플릿 제한 완화 | 잘못된 이스케이프를 태그 함수에서 허용 | 33편 |

```js
const { a, ...rest } = { a: 1, b: 2, c: 3 }
// a=1, rest={ b: 2, c: 3 }
/(?<y>\d{4})-(?<mo>\d\d)/.exec('2026-10').groups.y // '2026'
'$10 €20'.match(/(?<=\$)\d+/)[0]                   // '10'
/a.b/s.test('a\nb')                                // true
/a.b/.test('a\nb')                                 // false
```

- 객체 스프레드는 자체 열거 가능 프로퍼티만 얕게 복사합니다. `{ ...null }`은 오류 없이 `{}`입니다.
- 태그드 템플릿에서 잘못된 이스케이프(`\unicode`)가 있으면 `strings[0]`은 `undefined`, `raw`는 원문입니다. 태그 없는 템플릿은 여전히 SyntaxError입니다.
- `finally` 콜백의 반환값은 결과를 바꾸지 않습니다. 콜백이 예외를 던지거나 거부된 프로미스를 반환할 때만 바뀝니다.

### ES2019

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Array.prototype.flat`, `flatMap` | 중첩 배열 평탄화 | 28편 |
| `Object.fromEntries` | `[키, 값]` 이터러블을 객체로 | 18편 |
| `trimStart`, `trimEnd` | 한쪽 공백 제거 | 33편 |
| 선택적 catch 바인딩 | `catch { }`처럼 변수 생략 | 44편 |
| `Symbol.prototype.description` | 심벌 설명 읽기 | 34편 |
| `Function.prototype.toString` 개정 | 주석·공백을 포함한 소스 원문 그대로 반환 | 16편 |
| JSON 상위 집합 | 문자열 리터럴에 U+2028·U+2029 허용 | 39편 |
| 올바른 형식의 `JSON.stringify` | 짝 없는 서로게이트를 이스케이프 | 39편 |
| 안정 정렬 | `Array.prototype.sort`가 같은 값의 순서를 보존 | 29편 |

```js
[1, [2, [3]]].flat()            // [1, 2, [3]] (깊이 1)
[1, [2, [3]]].flat(Infinity)    // [1, 2, 3]
[1, 2].flatMap(x => [x, x * 2]) // [1, 2, 2, 4]
Object.fromEntries([['a', 1]])  // { a: 1 }
Symbol('d').description         // 'd'
try { JSON.parse('x') } catch { /* 변수 없이 받음 */ }
```

- `flatMap`은 깊이 1까지만 펼칩니다. `[1,2,3].flatMap(x => [[x]])`는 `[[1], [2], [3]]`입니다.
- `Object.fromEntries`는 `Object.entries`의 역연산이며 `Map`도 받습니다.

## ES2020

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 옵셔널 체이닝 `?.` | `null`·`undefined`면 `undefined`로 중단 | 06편 |
| 널 병합 `??` | `null`·`undefined`일 때만 오른쪽 값 | 08편 |
| `BigInt` | 크기 제한 없는 정수, 리터럴 `10n` | 05편 |
| `Promise.allSettled` | 모든 프로미스의 결과를 상태와 함께 반환 | 41편 |
| `globalThis` | 환경 무관 전역 객체 | 13편 |
| 동적 `import()` | 모듈을 프로미스로 로드 | 45편 |
| `import.meta` | 현재 모듈 메타데이터(`import.meta.url`) | 46편 |
| `String.prototype.matchAll` | 모든 매칭을 이터레이터로 | 32편 |
| `export * as ns from` | 모듈 전체를 이름 붙여 재내보내기 | 45편 |
| `for-in` 순회 순서 | 순회 규칙을 명세에 규정 | 18편 |

```js
const user = { addr: null }
user.addr?.city   // undefined
user.fn?.()       // undefined
null ?? 'd'       // 'd'
0 ?? 'd'          // 0
0 || 'd'          // 'd'
2n ** 64n         // 18446744073709551616n
```

- `?.`는 뒤따르는 체인 전체를 건너뜁니다. `a?.b.c`에서 `a`가 `null`이면 `.c`는 평가되지 않습니다.
- `a?.b = 1`처럼 옵셔널 체인에 대입하면 SyntaxError입니다.
- `??`를 괄호 없이 `||`·`&&`와 섞으면 SyntaxError입니다. `null ?? 1 || 2`는 오류, `(null ?? 1) || 2`는 1입니다.
- `BigInt`와 `Number`는 섞을 수 없습니다. `1n + 1`은 TypeError이고, 나눗셈은 버림이라 `5n / 2n`은 `2n`입니다. `JSON.stringify`도 `BigInt`에서 TypeError입니다.
- `matchAll`에 `g` 플래그 없는 정규식을 넘기면 TypeError입니다.

## ES2021–2022

### ES2021

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `String.prototype.replaceAll` | 모든 일치를 치환 | 33편 |
| `Promise.any` | 가장 먼저 이행한 프로미스, 모두 거부면 `AggregateError` | 41편 |
| 논리 대입 연산자 | `&&=`, `??=`와 `\|\|=` | 06편 |
| 숫자 구분자 | `1_000_000` | 05편 |
| `WeakRef`, `FinalizationRegistry` | 약한 참조와 정리 콜백 | 49편 |

```js
'a-b-c'.replaceAll('-', '+')  // 'a+b+c'
let x = null; x ??= 5         // x = 5
let y = 0; y ||= 7            // y = 7
let z = 1; z &&= 9            // z = 9
1_000_000                     // 1000000
Number('1_000')               // NaN
```

- 논리 대입은 단락 평가합니다. `a ||= b`는 `a || (a = b)`와 같아서 `a`가 참이면 대입이 일어나지 않고 setter도 호출되지 않습니다.
- `replaceAll`에 정규식을 넘기면 `g` 플래그가 필수이며, 없으면 TypeError입니다.
- 모든 프로미스가 거부되면 `Promise.any`는 `AggregateError`로 거부하고 각 이유는 `errors` 배열에 담깁니다.
- `WeakRef`의 `deref()`와 정리 콜백의 실행 시점은 보장되지 않습니다.

### ES2022

| 기능 | 동작 | 자세히 |
|------|------|--------|
| 클래스 필드 | 공개·`#private` 필드, private 메서드·접근자, `static` 필드 | 24편 |
| 클래스 정적 블록 | `static { }` 초기화 코드 | 24편 |
| `#x in obj` | private 필드 존재 확인(brand check) | 24편 |
| 최상위 `await` | 모듈 최상위에서 `await` | 46편 |
| `.at()` | 음수 인덱스 접근(`Array`, `String`, Typed Array) | 28편 |
| `Object.hasOwn` | 안전한 자체 프로퍼티 확인 | 18편 |
| 정규식 `d` 플래그 | 일치 위치 `indices` | 32편 |
| `Error` cause | `new Error(msg, { cause })` | 44편 |

```js
class A {
  #p = 1
  static s = 2
  static { A.t = 4 }
  static has(o) { return #p in o }
}
A.has(new A())                  // true
A.has({})                       // false
[1, 2, 3].at(-1)                // 3
/a(b)/d.exec('xab').indices[1]  // [2, 3]
new Error('m', { cause: 'c' }).cause // 'c'
```

- 최상위 `await`는 모듈에서만 쓸 수 있고, 그 모듈을 import하는 쪽은 `await`가 끝날 때까지 실행을 기다립니다.
- `Object.hasOwn(obj, key)`는 `obj.hasOwnProperty(key)`와 달리 `Object.create(null)` 객체에서도 동작합니다.

## ES2023–2025

### ES2023

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `toSorted`, `toReversed`, `toSpliced`, `with` | 원본을 바꾸지 않는 복사본 반환 | 28편 |
| `findLast`, `findLastIndex` | 뒤에서부터 검색 | 28편 |
| 해시뱅 문법 | 첫 줄 `#!/usr/bin/env node`를 주석으로 허용 | 46편 |
| 심벌을 `WeakMap` 키로 | 등록되지 않은 심벌만 가능 | 38편 |

```js
const arr = [3, 1, 2]
arr.toSorted()      // [1, 2, 3] (arr는 그대로)
arr.toReversed()    // [2, 1, 3]
arr.toSpliced(1, 1) // [3, 2]
arr.with(0, 9)      // [9, 1, 2]
[1, 2, 3].findLast(n => n < 3)   // 2
[1, 2, 3].findLastIndex(n => n > 5) // -1
```

- `with`의 인덱스가 범위를 벗어나면 RangeError입니다.
- Typed Array도 `toSorted`, `toReversed`, `with`를 가집니다. `toSpliced`는 배열만 가집니다.
- `Symbol.for`로 만든 등록 심벌은 `WeakMap` 키로 쓸 수 없습니다(TypeError).
- 해시뱅은 파일 맨 첫 줄에서만 유효합니다.

### ES2024

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Object.groupBy`, `Map.groupBy` | 콜백 반환값으로 그룹화 | 28편 |
| `Promise.withResolvers` | `promise`, `resolve`, `reject`를 한 번에 생성 | 41편 |
| 정규식 `v` 플래그 | 집합 연산, 문자열 속성 | 32편 |
| 크기 조절 `ArrayBuffer` | `maxByteLength`, `resize()` | 48편 |
| `ArrayBuffer.prototype.transfer` | 소유권을 새 버퍼로 이전, 원본은 분리됨 | 48편 |
| 올바른 형식의 유니코드 문자열 | `isWellFormed`, `toWellFormed` | 33편 |
| `Atomics.waitAsync` | 논블로킹 대기 | 48편 |

```js
Object.groupBy([1, 2, 3, 4], n => (n % 2 ? 'odd' : 'even'))
// { odd: [1, 3], even: [2, 4] }
const { promise, resolve } = Promise.withResolvers()
resolve(1)               // promise는 1로 이행
/[\p{L}--[a-z]]/v.test('a')  // false (L에서 a–z 제외)
/[\p{L}--[a-z]]/v.test('A')  // true
/^\p{RGI_Emoji}$/v.test('👍🏽')   // true
'a\ud800'.isWellFormed()  // false
```

- `v` 플래그는 `u`의 상위 호환입니다. 차집합 `--`, 교집합 `&&`, 중첩 클래스, 이모지 시퀀스 같은 문자열 속성(`\p{RGI_Emoji}`)을 지원하며, `u`와 함께 쓸 수 없습니다.
- `Object.groupBy`의 결과는 `Object.create(null)` 객체이므로 `hasOwnProperty` 메서드가 없습니다.
- `transfer()`를 호출하면 원본의 `detached`가 `true`가 되고 `byteLength`가 0이 됩니다.
- 크기 조절은 `new ArrayBuffer(4, { maxByteLength: 8 })`로 만든 버퍼에서만 가능합니다.

### ES2025

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Set` 집합 메서드 | `union`, `intersection`, `difference`, `symmetricDifference`, `isSubsetOf`, `isSupersetOf`, `isDisjointFrom` | 38편 |
| 이터레이터 헬퍼 | `Iterator` 전역, `map` `filter` `take` `drop` `flatMap` `reduce` `toArray` 등 | 35편 |
| `Promise.try` | 동기·비동기 함수를 프로미스로 감싸 실행 | 41편 |
| `RegExp.escape` | 문자열을 정규식 리터럴로 이스케이프 | 32편 |
| 정규식 수정자 | `(?i:…)`처럼 일부에만 플래그 적용 | 32편 |
| 중복 이름 그룹 | 서로 다른 대안(`\|`)에서 같은 그룹 이름 허용 | 32편 |
| import 속성, JSON 모듈 | `with { type: 'json' }` | 45편 |
| `Float16Array` | 16비트 부동소수점 Typed Array, `Math.f16round`, `DataView` getFloat16·setFloat16 | 48편 |
| 전역 eval var 재선언 | `eval`이 전역에 만든 `var`와 같은 이름의 `let`·`const` 허용 | 12편 |

```js
const s = new Set([1, 2, 3])
s.union(new Set([3, 4]))        // Set {1, 2, 3, 4}
s.intersection(new Set([2, 9])) // Set {2}
s.difference(new Set([2]))      // Set {1, 3}
function* nat() { let i = 0; while (true) yield i++ }
nat().drop(2).take(3).toArray()  // [2, 3, 4]
RegExp.escape('.a*')  // '\\.a\\*'
/(?i:a)b/.test('Ab')  // true
/(?i:a)b/.test('AB')  // false
```

```js
import cfg from './cfg.json' with { type: 'json' }
```

- 이터레이터 헬퍼는 지연 평가입니다. 무한 제너레이터에 `drop`·`take`를 이어도 필요한 만큼만 계산하고, `toArray`처럼 소비하는 메서드가 호출될 때 실행됩니다.
- `Set` 메서드의 인수는 `Set`이 아니어도 `size`, `has`, `keys`를 가진 유사 집합이면 됩니다.
- `RegExp.escape`는 문자나 숫자로 시작하면 첫 글자를 16진수로 이스케이프합니다. `RegExp.escape('1+1')`은 `'\\x31\\+1'`입니다.
- import 속성의 이전 문법 `assert`는 `with`로 대체되었습니다.
- 중복 이름 그룹은 같은 대안 안에서는 쓸 수 없습니다. `(?<y>a)(?<y>b)`는 SyntaxError입니다.

ES2026(17판)은 2026년 6월 30일 총회에서 승인되었습니다. TC39 목록 기준으로 일곱 가지 기능이 추가되었습니다.

| 기능 | 동작 | 자세히 |
|------|------|--------|
| `Array.fromAsync` | 비동기 이터러블을 배열로 | 28편 |
| `Error.isError` | 값이 에러 객체인지 판별 | 44편 |
| `Math.sumPrecise` | 부동소수점 오차를 최소화한 합 | 30편 |
| `Uint8Array` Base64·Hex | `toBase64`, `fromBase64`, `toHex`, `fromHex` | 48편 |
| `Iterator.concat` | 여러 이터러블을 순서대로 이어 붙임 | 35편 |
| `JSON.parse` 원문 접근 | reviver의 `context.source`, `JSON.rawJSON` | 39편 |
| `Map`·`WeakMap` upsert | `getOrInsert`, `getOrInsertComputed` | 38편 |

```js
await Array.fromAsync(asyncGen(1, 3))        // [1, 2, 3]
Error.isError(new TypeError())               // true
Error.isError({ name: 'Error', message: '' }) // false
1e20 + 0.1 - 1e20                            // 0
Math.sumPrecise([1e20, 0.1, -1e20])          // 0.1
```

- `Error.isError`는 `instanceof Error`와 달리 다른 realm(iframe 등)에서 만든 에러도 `true`로 판별합니다. 이름이 `'Error'`인 일반 객체는 `false`입니다.
- `Math.sumPrecise`는 중간 합이 아니라 정확한 합을 구한 뒤 한 번만 반올림합니다.

```js
const bytes = new Uint8Array([72, 105])
bytes.toBase64()                  // 'SGk='
bytes.toHex()                     // '4869'
Uint8Array.fromBase64('SGk=')     // Uint8Array [72, 105]
Uint8Array.fromHex('4869')        // Uint8Array [72, 105]
```

- `toBase64`는 옵션 `{ alphabet: 'base64url' }`로 URL 안전 문자 집합을 선택할 수 있습니다.
- 기존 `btoa`·`atob`는 호스트 API이고 문자열 기반이라, 바이너리에는 이 메서드들이 대안입니다.

```js
Iterator.concat([1, 2], [3]).toArray()   // [1, 2, 3]
JSON.parse('999999999999999999',
  (k, v, { source }) => BigInt(source))
// 999999999999999999n
JSON.stringify({ n: JSON.rawJSON('999999999999999999') })
// '{"n":999999999999999999}'
const m = new Map()
m.getOrInsert('k', 0)   // 0 (없으면 넣고 반환)
m.getOrInsertComputed('j', k => [k])
// ['j'] (없을 때만 콜백 실행)
```

- `JSON.parse`의 reviver는 세 번째 인수로 원문 문자열 `source`를 받습니다. 정밀도가 손실되기 전 값을 `BigInt`로 복원할 때 씁니다. `source`는 원시 값에만 주어집니다.
- `getOrInsert`는 키가 있으면 기존 값을 반환하고 값을 덮어쓰지 않습니다. 기본값이 비싸면 콜백을 받는 `getOrInsertComputed`를 씁니다.

### Temporal

Temporal은 `Date`의 문제(0부터 시작하는 월, 가변 객체, 시간대 지원 부족, 밀리초 정밀도)를 해결하려는 전역 네임스페이스입니다(`Date`는 31편).

| 클래스 | 표현하는 것 |
|--------|-------------|
| `Temporal.Instant` | 시간대 없는 정확한 한 시점(나노초) |
| `Temporal.ZonedDateTime` | 날짜+시간+시간대 |
| `Temporal.PlainDateTime` | 시간대 없는 날짜+시간 |
| `Temporal.PlainDate` | 날짜만 |
| `Temporal.PlainTime` | 시간만 |
| `Temporal.PlainYearMonth` | 연·월 |
| `Temporal.PlainMonthDay` | 월·일 |
| `Temporal.Duration` | 기간 |
| `Temporal.Now` | 현재 시각 조회 |

```js
const d = Temporal.PlainDate.from('2025-01-15')
d.add({ months: 3 }).toString() // '2025-04-15'
d.toString()                    // '2025-01-15' (불변)
d.month                         // 1 (1부터 시작)
```

- 모든 Temporal 객체는 불변이고, 연산은 새 객체를 반환합니다.
- 월이 1부터 시작해서 `Date`의 `getMonth()`(0부터)와 다릅니다.
- 달력 체계(그레고리력 외)를 지원합니다.
- 엔진 지원 범위가 제한적일 수 있어 폴리필(`@js-temporal/polyfill`)을 쓰는 경우가 많습니다.

### 명시적 자원 관리

블록을 벗어날 때 자원의 정리 메서드를 자동 호출하는 문법입니다. 파일 핸들, 락, 스트림 정리에 씁니다.

```js
{
  using file = openFile()  // 종료 시 file[Symbol.dispose]()
  using lock = acquire()   // 역순 정리: lock, file 순
}
{
  await using conn = await connect()
  // 종료 시 await conn[Symbol.asyncDispose]()
}
```

- 객체에 `Symbol.dispose`(동기) 또는 `Symbol.asyncDispose`(비동기) 메서드가 있어야 합니다.
- 여러 자원은 선언의 역순으로 정리합니다. 정리 중 에러가 겹치면 `SuppressedError`로 묶습니다.
- `DisposableStack`, `AsyncDisposableStack`은 여러 자원을 코드로 모아 한꺼번에 정리하는 컨테이너입니다.

### 이터레이터 확장과 기타

```js
Iterator.zip([[0, 1, 2], [3, 4, 5]]).toArray()
// [[0, 3], [1, 4], [2, 5]]
Iterator.zipKeyed({ a: [0, 1], b: [3, 4] }).toArray()
// [{ a: 0, b: 3 }, { a: 1, b: 4 }]
[0, 1, 2, 3, 4].values().chunks(2).toArray()
// [[0, 1], [2, 3], [4]]
[0, 1, 2, 3].values().windows(2).toArray()
// [[0, 1], [1, 2], [2, 3]]
[1, 2, 3].values().join('-')     // '1-2-3'
[1, 3].values().includes(3)      // true
```

- `zip`은 `mode` 옵션(`'shortest'`, `'longest'`, `'strict'`)으로 길이가 다른 입력을 처리하고, `'longest'`에서는 `padding`으로 채웁니다.
- `chunks`는 겹치지 않는 묶음이고 마지막 묶음이 짧을 수 있습니다. `windows`는 한 칸씩 밀리는 겹치는 묶음입니다.
- `Atomics.pause()`는 락 획득 재시도 사이에 CPU에 짧은 대기를 알리는 용도입니다(스핀 루프, 48편).

## Stage 제안

4단계 아래에 있는 제안은 문법과 동작이 바뀔 수 있습니다. 단계의 정의와 절차는 01편에서 다룹니다. 아래는 2026년 10월 확인한 TC39 제안 목록입니다.

### 3단계

엔진 구현을 권장하는 단계입니다.

| 제안 | 내용 |
|------|------|
| Source Phase Imports | `import source x from './m.wasm'`처럼 모듈을 실행하지 않고 소스 객체로 가져옴 |
| Deferring Module Evaluation | `import defer * as ns from 'y'`처럼 로드만 하고 평가는 첫 접근까지 미룸 |
| Import Text | `import t from './a.txt' with { type: 'text' }` |
| Await Dictionary | `Promise.allKeyed`, `Promise.allSettledKeyed`로 객체의 프로미스 값을 병렬 대기 |
| RegExp Buffer Boundaries | `u` 모드에서 `\A`, `\z`, `\Z`로 입력 전체의 시작·끝 지정 |
| Non-extensible Applies to Private | 확장 불가 객체에 private 필드 추가를 TypeError로 |
| Error Stack Accessor | `Error`의 `stack`을 접근자로 표준화 |
| Legacy RegExp features | `RegExp.$1` 같은 정적 프로퍼티와 `compile` 표준화 |
| Dynamic Code Brand Checks | `eval`·`Function`에 호스트 보안 검사(Trusted Types) 연동 |
| Curtailing the power of Thenables | thenable 처리 범위 축소 |

```js
const { shape, color } = await Promise.allKeyed({
  shape: getShape(),
  color: getColor(),
}) // 두 요청이 병렬로 진행
```

### 2.7단계

설계가 사실상 확정되어 테스트 작성을 기다리는 단계입니다.

- Decorators: `@defineElement('x') class C {}`, `@reactive accessor clicked = false` 같은 클래스 요소 장식.
- Decorator Metadata, ShadowRealm(`new ShadowRealm().evaluate('2 + 2')`로 격리된 전역 환경 실행).
- Immutable ArrayBuffers: `transferToImmutable`, `sliceToImmutable`, `immutable`.
- Import Bytes: `import b from './a.png' with { type: 'bytes' }`로 `Uint8Array` 획득.
- ESM Phase Imports, JSON.parse options, export all from, Deferred Re-exports.

### 2단계의 주요 제안

| 제안 | 내용 |
|------|------|
| Pipeline Operator | Hack 스타일 `x \|> f(%)` |
| `throw` expressions | 표현식 자리에서 `throw` |
| `String.dedent` | 템플릿 리터럴의 들여쓰기 제거 태그 |
| `Iterator.range` | 숫자 범위 이터레이터 |
| `Math.clamp` | 값을 범위 안으로 제한 |
| Async Context | 비동기 호출 사이로 컨텍스트 전달 |

그 밖에 Module Expressions, Module Declarations, Structs, Extractors, Async Iterator helpers, SeededPRNG가 2단계입니다.

- 3단계 이하 기능은 Babel·TypeScript가 지원하더라도 최종 문법이 달라질 수 있습니다. 운영 코드에서는 4단계 이후에 쓰는 것이 안전합니다.
- 제안 기능을 먼저 쓰면 버전 업그레이드 때 코드를 다시 고쳐야 합니다.

## 지원 여부 확인 방법

기능이 표준이 되었다고 해서 대상 환경에서 동작하는 것은 아닙니다. 판 번호, 엔진 지원, 대상 환경 세 가지를 따로 확인합니다.

| 확인 대상 | 도구 |
|-----------|------|
| 브라우저·엔진별 지원 | MDN의 Browser compatibility 표, Can I use |
| 표준 상태·판 | TC39 finished-proposals |
| Node.js 버전별 지원 | node.green, Node.js 문서의 버전 표기 |
| 종합 지원표 | compat-table(ES2016 이후 항목) |
| 안정성 판단 | Baseline (Widely available = 모든 주요 브라우저에서 30개월 이상) |

- Baseline의 Newly available은 주요 브라우저 최신 버전에서 모두 지원되기 시작한 상태이고, Widely available은 거기서 30개월이 지난 상태입니다.
- iOS에서는 모든 브라우저가 Safari 엔진을 쓰므로 Safari 지원 여부를 따로 봅니다(01편).

존재만 확인하므로 일부만 구현된 경우를 걸러내지는 못합니다. 옵션 지원 여부는 실제로 호출해서 확인합니다.

### 문법 검사

문법은 `typeof`로 확인할 수 없습니다. 지원하지 않는 문법은 실행 전 파싱 단계에서 SyntaxError로 파일 전체를 막기 때문입니다. `Function` 생성자에 코드를 문자열로 넘기면 해당 코드만 별도로 파싱해 검사할 수 있습니다.

```js
function supportsSyntax(code) {
  try { new Function(code); return true }
  catch { return false }
}
supportsSyntax('a?.b')   // 지원 시 true
supportsSyntax('a ??= 1') // 지원 시 true
```

- 콘텐츠 보안 정책(CSP)이 `unsafe-eval`을 막으면 `new Function`이 항상 실패합니다.
- 모듈 문법은 `<script type="module">`·`nomodule` 조합으로 분기하는 방식이 쓰입니다.

### 구형 환경 대응

| 종류 | 대상 | 도구 |
|------|------|------|
| 트랜스파일 | 새 문법을 옛 문법으로 변환 | Babel, TypeScript `target`, esbuild·SWC |
| 폴리필 | 없는 내장 객체·메서드를 코드로 보충 | core-js |

- 문법은 폴리필할 수 없고, 메서드는 변환할 수 없습니다. 각각 다른 도구가 필요합니다(자세히는 51편).
- 대상 환경은 `browserslist`에 적어 도구들이 같은 기준을 쓰게 합니다.
- TypeScript의 `target`은 문법 변환 수준을, `lib`는 타입 선언에 포함할 내장 API를 정합니다. 둘은 별개 설정입니다.
- 폴리필이 있어도 `Temporal`처럼 큰 기능은 번들 크기가 커집니다.

## 핵심 정리

- ES5(2009)는 strict mode, JSON, 배열 반복 메서드, `Object.defineProperty`를 추가했고, ES2015는 `let`·`const`, 화살표 함수, 클래스, 모듈, 프로미스, 이터러블 등 언어의 뼈대를 만들었습니다.
- ES2016–2022는 `**`·`includes`, `async`/`await`, 객체 스프레드, `?.`·`??`, `BigInt`, `replaceAll`, 클래스 필드, 최상위 `await`로 이어집니다.
- ES2023–2025는 복사본 반환 배열 메서드, `groupBy`, `withResolvers`, `Set` 집합 메서드, 이터레이터 헬퍼, `Promise.try`, `RegExp.escape`를 추가했습니다.
- ES2026은 `Array.fromAsync`, `Error.isError`, `Math.sumPrecise`, `Uint8Array` Base64·Hex, `Iterator.concat`, `JSON.parse` 원문 접근, `getOrInsert`를 추가했고, Temporal과 `using`은 ES2027 예정입니다.
- 3단계 이하 제안은 바뀔 수 있으므로 지원 여부는 MDN·Baseline으로, 메서드는 기능 검사로, 문법은 `new Function` 파싱으로 확인하고, 구형 대상은 트랜스파일러와 폴리필로 대응합니다.
