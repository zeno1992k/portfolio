## 일급 객체의 조건

일급 객체(first-class object)는 다른 값과 똑같이 다룰 수 있는 값입니다. 아래 네 가지를 모두 할 수 있으면 일급 객체이고, JavaScript의 함수는 모두 해당합니다.

| 조건 | 함수에서의 의미 |
|------|-----------------|
| 런타임에 생성 | 실행 중에 함수 리터럴을 평가해 새 함수 객체를 만든다 |
| 변수·자료구조에 저장 | 변수, 객체 프로퍼티, 배열 요소에 담는다 |
| 인수로 전달 | 다른 함수의 인수로 넘긴다 |
| 반환값으로 사용 | 함수가 함수를 반환한다 |

```js
const inc = function (n) { return n + 1 } // 변수에 저장
const ops = { inc, dbl: (n) => n * 2 }    // 프로퍼티로 저장
const list = [inc, Math.abs]              // 배열 요소로 저장
const apply = (f, v) => f(v)              // 인수로 받음
const make = (k) => (n) => n * k          // 함수를 반환

apply(inc, 1)       // 2
make(3)(5)          // 15
make(2) === make(2) // false
```

마지막 줄이 `false`인 이유는 `make`를 호출할 때마다 새 함수 객체가 만들어지기 때문입니다.

- 함수는 객체입니다. `typeof`가 `'function'`을 반환할 뿐 ECMAScript 타입은 Object이고, 일반 객체와 다른 점은 `[[Call]]` 내부 메서드를 가져서 호출할 수 있다는 것입니다(자세히는 15편).
- 일반 객체의 기능을 그대로 씁니다. 프로퍼티를 추가·삭제하고, `===`로 참조를 비교하고, `Map`의 키로 쓸 수 있습니다(참조 비교는 10편).
- 함수를 인수로 받거나 반환하는 함수를 고차 함수라고 하고, 인수로 넘겨져 나중에 호출되는 함수를 콜백 함수라고 합니다(자세히는 11편, 29편). 반환된 함수가 바깥 함수의 변수를 기억하는 구조는 클로저입니다(자세히는 23편).

**흔한 실수:** 함수 값을 넘겨야 할 자리에 호출 결과를 넘기는 경우입니다. 함수 이름 뒤에 `()`를 붙이면 그 자리에서 실행되고, 반환값이 전달됩니다.

```js
const log = (v) => console.log(v)
const nums = [1, 2]

nums.forEach(log)   // ✅ 1, 2 출력
nums.forEach(log()) // ❌ undefined 출력 후 TypeError
```

## 함수 객체의 프로퍼티

함수 객체는 일반 객체의 프로퍼티에 더해, 함수가 만들어질 때 붙는 own 프로퍼티와 `Function.prototype`에서 상속하는 메서드를 가집니다. own 프로퍼티는 `Object.getOwnPropertyNames`로 확인합니다.

```js
function square(n) { return n * n }

Object.getOwnPropertyNames(square)
// ['length', 'name', 'arguments', 'caller', 'prototype']
```

결과는 V8 기준입니다.

| 프로퍼티 | 값 | writable / enumerable / configurable | 있는 함수 |
|----------|----|----------------------------------------|-----------|
| `length` | 선언한 매개변수 수 | false / false / true | 모든 함수 |
| `name` | 함수 이름 | false / false / true | 모든 함수 |
| `prototype` | 인스턴스의 프로토타입이 될 객체 | true / false / false | constructor 함수, 제너레이터 함수 (클래스는 writable이 false) |
| `arguments`, `caller` | `null` | false / false / false | 비엄격 일반 함수 (비표준, V8) |

- `length`와 `name`은 모든 함수에 있고, `prototype`은 constructor 함수와 제너레이터 함수에만 있습니다. 화살표 함수, 메서드, async 함수, 대부분의 빌트인 함수, 바운드 함수에는 없습니다(자세히는 15편).
- `arguments`와 `caller`는 명세가 정한 own 프로퍼티가 아니라 엔진의 비표준 확장입니다(자세히는 아래 `caller`·`callee` 절).
- own 프로퍼티는 모두 enumerable이 `false`라서 `Object.keys(square)`는 `[]`입니다. 어트리뷰트 확인은 `Object.getOwnPropertyDescriptors`를 씁니다(자세히는 14편).
- `__proto__`는 함수의 own 프로퍼티가 아니라 모든 객체가 `Object.prototype`에서 상속하는 접근자입니다.
- 상속하는 메서드는 `call`, `apply`, `bind`(자세히는 21편), `toString`(아래 절), `Symbol.hasInstance`입니다.

함수에 직접 추가한 프로퍼티는 enumerable이 `true`인 일반 프로퍼티입니다.

```js
function counter() { return ++counter.count }
counter.count = 0

counter()            // 1
counter()            // 2
Object.keys(counter) // ['count']
```

함수 안에서 자기 프로퍼티를 함수 이름으로 참조하면, 그 이름이 다른 값으로 재할당될 때 깨집니다. 호출 사이에 유지할 상태는 클로저로 보관하는 편이 안전합니다(자세히는 23편).

## `arguments` 객체

`arguments` 객체는 함수가 호출될 때 전달된 인수 전체를 담는 유사 배열 객체이고, 함수 본문에서 `arguments`라는 식별자로 쓸 수 있습니다. 유사 배열 객체는 `length`와 0부터 시작하는 인덱스 프로퍼티를 가졌지만 배열이 아닌 객체입니다. 화살표 함수를 제외한 모든 함수에 생깁니다.

```js
function sum() {
  let total = 0
  for (const n of arguments) total += n
  return total
}

sum(1, 2, 3) // 6
```

| 프로퍼티 | 내용 |
|----------|------|
| `0`, `1`, … | 전달된 인수. enumerable |
| `length` | 전달된 인수의 개수. 쓰기 가능, enumerable 아님 |
| `Symbol.iterator` | `Array.prototype.values`와 같은 함수. `for...of`와 스프레드에 쓸 수 있다(자세히는 35편, 36편) |
| `callee` | 비엄격 모드에서만 호출 중인 함수 자신(아래 `caller`·`callee` 절) |

**배열이 아닙니다.** 프로토타입이 `Object.prototype`이라 `map`, `forEach` 같은 배열 메서드가 없고 `Array.isArray(arguments)`는 `false`입니다. `Object.prototype.toString.call(arguments)`는 `'[object Arguments]'`입니다. 배열 메서드가 필요하면 먼저 변환합니다.

```js
function f() {
  const a = Array.from(arguments)
  const b = [...arguments]
  const c = Array.prototype.slice.call(arguments)
  return [a, b, c]
}

f(10, 20) // [[10, 20], [10, 20], [10, 20]]
```

**`length`는 전달한 인수의 개수입니다.** 선언한 매개변수 수와 무관하며, 초과해서 넘긴 인수는 `arguments`로만 접근할 수 있습니다.

```js
function g(a, b) { return arguments.length }

g()        // 0
g(1, 2, 3) // 3
g.length   // 2
```

- 매개변수 기본값은 `arguments`에 반영되지 않습니다. 인수를 넘기지 않았으면 기본값이 채워져도 `arguments`는 비어 있습니다.

  ```js
  function h(x = 5) {
    return [arguments.length, arguments[0]]
  }
  h() // [0, undefined]
  ```

- `arguments`의 `length`와 인덱스는 배열처럼 서로 연동되지 않습니다. `arguments[5] = 1`을 해도 `length`는 그대로이고, `arguments.length = 1`을 해도 `arguments[1]`은 남습니다.
- `arguments`는 예약어가 아니라 일반 식별자입니다. 비엄격 모드에서 `arguments`라는 이름의 매개변수를 선언하면 `arguments` 객체는 만들어지지 않고 그 매개변수가 쓰입니다. 엄격 모드에서는 `arguments`를 바인딩 이름으로 쓰면 SyntaxError입니다(자세히는 19편).
- 화살표 함수에는 자기 `arguments`가 없고 스코프 체인으로 바깥 함수의 `arguments`를 참조합니다(자세히는 27편).
- 함수 바깥의 최상위에서 `arguments`를 읽으면 ReferenceError입니다. Node.js의 CommonJS 모듈은 파일 전체가 래퍼 함수 안에서 실행되므로 그 래퍼의 `arguments`가 보입니다.

나머지 매개변수(ES2015)가 `arguments`의 용도를 대체하므로 새 코드에서는 나머지 매개변수를 씁니다(자세히는 27편).

| 구분 | `arguments` | 나머지 매개변수 `...args` |
|------|-------------|---------------------------|
| 타입 | 유사 배열 객체 | 배열 |
| 배열 메서드 | 변환한 뒤 사용 | 바로 사용 |
| 화살표 함수 | 자기 것이 없다 | 사용할 수 있다 |
| 담기는 범위 | 전달된 모든 인수 | 선언된 매개변수 뒤의 인수 |

**흔한 실수:** `arguments`를 배열로 착각하고 배열 메서드를 호출하는 경우입니다.

```js
function bad() { return arguments.map((v) => v) }
bad(1) // ❌ TypeError: arguments.map is not a function

const ok = (...args) => args.map((v) => v) // ✅
ok(1)  // [1]
```

## `length`와 `name`

### length

`length`는 함수를 정의할 때 선언한 매개변수의 수입니다. 호출할 때 전달한 인수의 수와는 무관합니다.

기본값이 있는 매개변수와 나머지 매개변수는 세지 않고, 그 앞까지만 셉니다.

| 매개변수 목록 | length | 이유 |
|---------------|--------|------|
| `(a, b)` | 2 | 모두 센다 |
| `(a, b = 1, c)` | 1 | 첫 기본값 앞까지만 센다 |
| `(a = 1, b)` | 0 | 첫 매개변수부터 기본값이다 |
| `(a, ...rest)` | 1 | 나머지 매개변수는 세지 않는다 |
| `({ x }, [y])` | 2 | 구조 분해 패턴 하나가 매개변수 하나다 |

`f.length`와 `arguments.length`는 이름만 같습니다.

| 구분 | `f.length` | `arguments.length` |
|------|------------|--------------------|
| 의미 | 선언한 매개변수 수 | 호출 때 전달한 인수 수 |
| 정해지는 시점 | 함수를 정의할 때 | 호출할 때마다 |
| 읽을 수 있는 곳 | 함수를 참조할 수 있는 곳 어디서나 | 그 함수의 본문 안 |

- `length`는 writable이 `false`라서 대입이 비엄격 모드에서는 조용히 무시되고 엄격 모드에서는 TypeError입니다. configurable은 `true`라서 `Object.defineProperty`로는 바꿀 수 있습니다.

  ```js
  function f(a, b, c) {}

  f.length = 10 // 비엄격: 무시, 엄격: TypeError
  f.length      // 3
  Object.defineProperty(f, 'length', { value: 10 })
  f.length      // 10
  ```

- 바운드 함수의 `length`는 `max(0, 원본의 length - 바인딩한 인수 수)`입니다. `f.bind(null, 1).length`는 `2`, `f.bind(null, 1, 2, 3, 4).length`는 `0`입니다.
- 빌트인 함수의 `length`는 명세가 정한 값입니다. `Math.max.length`는 `2`(여러 개를 받지만 명세가 2로 정함), `Array.prototype.push.length`는 `1`, `Function.length`는 `1`입니다.
- `length`는 함수가 기대하는 인수의 수를 읽는 코드에 쓰입니다(커리링은 50편). 기본값이나 나머지 매개변수가 있으면 실제 매개변수 수보다 작으므로 주의합니다.

### name

`name`은 함수를 가리키는 문자열이며 스택 트레이스와 에러 메시지에 표시됩니다. 명세는 `name`에 의미적 효과가 없다고 정의하고, ES2015에서 표준이 되었습니다. 값은 함수를 만든 문법이 결정합니다.

| 함수를 만든 형태 | name |
|------------------|------|
| 함수 선언문 `function foo() {}` | `'foo'` |
| 기명 함수 표현식 `const a = function b() {}` | `'b'` (변수 이름 `a`가 아님) |
| 익명 함수·화살표 함수를 변수에 대입 `const f = () => {}` | `'f'` |
| 객체 리터럴의 프로퍼티·메서드 `{ p: function () {}, m() {} }` | `'p'`, `'m'` |
| getter·setter | `'get x'`, `'set x'` |
| 심벌 키 메서드 `[Symbol.iterator]() {}` | `'[Symbol.iterator]'` |
| 클래스 | 클래스 이름 |
| `bind`로 만든 함수 | `'bound '` + 원본 이름 |
| `new Function()`으로 만든 함수 | `'anonymous'` |
| 모듈의 `export default function () {}` | `'default'` |
| 이름을 얻지 못한 익명 함수 | `''` |

```js
function foo() {}
const bar = function () {}
const baz = function qux() {}

foo.name // 'foo'
bar.name // 'bar'
baz.name // 'qux'
```

- 이름 추론은 익명 함수 정의가 식별자에 대입되거나, 프로퍼티 정의의 값이거나, 구조 분해·매개변수 기본값에 쓰일 때만 일어납니다(자세히는 11편). 멤버 대입이나 표현식 결과로는 추론하지 않아 빈 문자열입니다.

  ```js
  const o = {}
  o.f = function () {}
  o.f.name   // '' — 멤버 대입에는 추론이 없다
  const g = function () {}
  const h = g
  h.name     // 'g' — 복사해도 생성 때 정해진 이름
  ```

- getter의 이름은 접근자 프로퍼티가 아니라 getter 함수 객체에서 확인합니다. `Object.getOwnPropertyDescriptor(o, 'x').get.name`이 `'get x'`입니다.
- `bind`를 거듭하면 접두사가 쌓입니다. `decl.bind(null).bind(null).name`은 `'bound bound decl'`입니다.
- 클래스에 `static name`을 정의하면 클래스의 `name` 프로퍼티를 덮어씁니다. `class S { static name = 'custom' }`의 `S.name`은 `'custom'`입니다.
- `length`처럼 writable이 `false`이고 configurable이 `true`입니다. 대입은 막히고 `Object.defineProperty`로는 바꿀 수 있습니다.
- 기명 함수 표현식의 이름(`b`)은 함수 안에서만 식별자로 보입니다(자세히는 11편).
- 코드 압축(minify)은 함수 이름을 짧게 바꾸므로 `name` 값으로 로직을 분기하면 빌드 후에 깨집니다(자세히는 51편).

## `__proto__`와 `prototype`

`__proto__`는 모든 객체가 상속하는 접근자 프로퍼티로, 그 객체의 프로토타입(내부 슬롯 `[[Prototype]]`)을 읽고 씁니다. `prototype`은 constructor 함수만 가지는 프로퍼티로, 그 함수를 `new`로 호출해 만든 인스턴스의 프로토타입이 될 객체를 가리킵니다.

| 구분 | `__proto__` | `prototype` |
|------|-------------|-------------|
| 있는 곳 | 모든 객체(`Object.prototype`에서 상속) | constructor 함수의 own 프로퍼티 |
| 종류 | 접근자 프로퍼티(get·set) | 데이터 프로퍼티 |
| 가리키는 것 | 그 객체의 프로토타입 | 인스턴스의 프로토타입이 될 객체 |
| 함수 객체에서의 값 | `Function.prototype` | 함수가 만들어질 때 함께 만들어진 객체 |

```js
function Person() {}
const p = new Person()

p.__proto__ === Person.prototype        // true
Person.__proto__ === Function.prototype // true
Person.prototype.constructor === Person // true
Person.hasOwnProperty('prototype')      // true
p.hasOwnProperty('__proto__')           // false
```

- `Person.prototype`의 초기값은 enumerable이 아닌 `constructor` 프로퍼티 하나만 가진 객체입니다. `Object.keys(Person.prototype)`는 `[]`, `Object.getOwnPropertyNames(Person.prototype)`는 `['constructor']`입니다.
- 함수 객체의 프로토타입은 일반 함수, 화살표 함수, 메서드가 `Function.prototype`입니다. `extends`가 있는 클래스는 부모 클래스(`class B extends A {}`에서 `B.__proto__ === A`)이고, async 함수와 제너레이터 함수는 각자의 전용 프로토타입입니다.
- `Function.prototype` 자체가 함수입니다. 인수를 무시하고 `undefined`를 반환하며, `name`은 `''`, `length`는 `0`입니다. ES2015 이전 코드와의 호환 때문에 함수 객체로 정의되었습니다.

  ```js
  Function.prototype.__proto__ === Object.prototype // true
  Object.prototype.__proto__ // null
  typeof Function.prototype  // 'function'
  ```

- `prototype` 프로퍼티가 없는 함수(화살표 함수, 메서드 등)의 `prototype`은 `undefined`입니다.
- 명세는 `__proto__`를 레거시 기능으로 분류하며 웹 호환을 위해 둡니다. 새 코드에서는 `Object.getPrototypeOf`와 `Object.setPrototypeOf`를 씁니다(자세히는 17편).
- `Object.create(null)`로 만든 객체는 `Object.prototype`을 상속하지 않으므로 `__proto__` 접근자가 없습니다(자세히는 17편).

**흔한 실수:** 인스턴스에서 `prototype`을 찾거나, 함수의 `__proto__`를 `prototype`으로 착각하는 경우입니다.

```js
p.prototype      // undefined (인스턴스에는 없다)
Person.__proto__ // Function.prototype (prototype 아님)
```

## `arguments`와 매개변수의 연동(비엄격)

비엄격 모드 함수에서 매개변수 목록이 단순하면, `arguments` 객체의 인덱스 프로퍼티와 대응하는 매개변수가 같은 값을 공유합니다. 한쪽을 바꾸면 다른 쪽도 바뀝니다. 이런 `arguments` 객체를 매핑된(mapped) 객체라고 합니다.

```js
function f(a, b) {
  arguments[0] = 'X' // 인수 쪽을 바꾸면 매개변수가 바뀐다
  b = 'Y'            // 매개변수를 바꾸면 인수 쪽이 바뀐다
  return [a, arguments[1]]
}

f(1, 2) // ['X', 'Y']
```

연동 여부는 함수가 호출되는 모드와 매개변수 목록이 결정합니다.

| 조건 | 연동 |
|------|------|
| 비엄격 모드 + 단순 매개변수 목록 | 연동됨 |
| 엄격 모드 | 연동되지 않음. 호출 시점 값의 사본 |
| 기본값·나머지·구조 분해 매개변수가 하나라도 있음(비엄격이라도) | 연동되지 않음 |

```js
function s(a) {
  'use strict'
  arguments[0] = 99
  return a
}
s(1) // 1

function d(a = 0) { arguments[0] = 99; return a }
d(1) // 1 — 기본값 매개변수가 있어 연동되지 않는다
```

- 연동되는 위치는 인덱스가 매개변수 개수보다 작고, 호출 때 실제로 전달된 인수에 해당하는 곳뿐입니다. 전달하지 않은 매개변수는 연동 대상이 아닙니다.

  ```js
  function g(a, b) {
    b = 'Y'
    return [arguments.length, arguments[1]]
  }
  g(1) // [1, undefined] — 전달되지 않은 b는 연동되지 않는다
  ```

- 연동은 인덱스 단위로 끊어집니다. `delete arguments[i]`로 지우거나, 그 인덱스를 접근자 프로퍼티로 바꾸거나, `writable: false`로 재정의하면 그 위치의 연동이 사라집니다.
- `Array.from(arguments)`나 `[...arguments]`가 만든 배열은 사본이라 연동되지 않습니다.
- 엄격 모드, 클래스 본문, ES 모듈에서는 항상 연동이 없습니다(자세히는 19편).

**흔한 실수:** 비엄격 함수에서 매개변수를 재할당한 뒤 `arguments`로 원본 인수를 읽는 경우입니다. 재할당한 값이 `arguments`에도 보입니다.

```js
function parse(n) {
  n = Number(n)
  return arguments[0]
}
parse('5') // 5 — 변환된 숫자 (엄격 모드면 '5')
```

매개변수와 `arguments`를 함께 수정하지 않습니다. 원본 인수가 필요하면 나머지 매개변수나 엄격 모드를 씁니다.

## `caller`·`callee` 금지

`arguments.callee`와 `Function.prototype.caller`는 코드가 실행 중인 함수와 호출 스택을 들여다보는 기능입니다. 엄격 모드에서 금지되었고 새 코드에서 쓰지 않습니다.

### `arguments.callee`

`arguments.callee`는 비엄격 모드의 `arguments` 객체에서 현재 실행 중인 함수 자신을 가리키는 프로퍼티입니다. 이름 없는 함수가 스스로를 재귀 호출할 때 쓰였습니다.

```js
const f1 = function (n) {
  return n <= 1 ? 1 : n * arguments.callee(n - 1) // ❌
}
const f2 = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1)             // ✅
}

f1(5) // 120 (비엄격). 엄격 모드면 TypeError
f2(5) // 120
```

- ES5 엄격 모드부터 `callee`를 읽으면 TypeError입니다. 엄격 모드 `arguments` 객체의 `callee`는 getter와 setter가 모두 TypeError를 던지는 접근자이고 configurable이 `false`입니다.
- 비엄격 함수라도 기본값·나머지·구조 분해 매개변수가 있으면 `arguments`가 매핑되지 않는 객체여서 `callee`는 TypeError입니다.
- 금지된 이유는 두 가지입니다. 함수가 자기 자신을 참조할 수 있으면 엔진이 인라인과 꼬리 재귀 최적화를 하기 어렵고, 호출 스택 정보가 코드로 새어 나갑니다.
- `arguments.callee(...)`로 호출하면 `this`가 바깥 값이 아니라 `arguments` 객체가 됩니다.
- 대체 방법은 기명 함수 표현식이나 함수 선언문입니다(자세히는 11편).

### `caller`와 `arguments` 프로퍼티

`f.caller`는 `f`를 호출한 함수를 가리키는 비표준 프로퍼티입니다. 최상위 코드에서 호출했으면 `null`입니다(Node.js의 CommonJS 모듈에서는 모듈 래퍼 함수가 나옵니다).

```js
function who() { return who.caller }
function a() { return who() }

a() === a // true — who를 호출한 함수는 a
```

`f.arguments`도 같은 비표준 확장입니다. 실행 중에는 현재 호출의 `arguments` 객체를, 실행 중이 아닐 때는 `null`을 돌려줍니다.

| 접근 | 비엄격 함수 | 엄격 함수 등 |
|------|-------------|--------------|
| `arguments.callee` | 함수 자신 | TypeError |
| `f.caller` | 호출한 함수(엔진 확장) | TypeError |
| `f.arguments` | 현재 호출의 `arguments`(엔진 확장) | TypeError |

- 명세가 정의하는 것은 `Function.prototype`의 `caller`와 `arguments` 접근자이고, 읽기·쓰기 모두 TypeError를 던집니다. 비엄격 함수에서 값을 돌려주는 동작은 엔진 확장이며, 구현 방식도 엔진마다 다릅니다(Chrome은 own 데이터 프로퍼티, Firefox와 Safari는 접근자에 특수 처리).
- 명세의 금지 확장 규칙은 엄격 함수, 화살표 함수, 메서드, 클래스, 제너레이터 함수, async 함수, 빌트인 함수, 바운드 함수에 own `caller`·`arguments` 프로퍼티를 만들지 못하게 합니다. 이런 함수에서 읽으면 상속한 접근자가 TypeError를 던집니다.
- 엄격 모드 함수에서 `caller`를 읽는 예입니다.

  ```js
  function s() { 'use strict'; return s.caller }
  s() // TypeError
  ```

- 클래스 본문과 ES 모듈은 자동으로 엄격 모드이므로 이 기능을 쓸 수 없습니다(자세히는 19편).

## `Function.prototype.toString`

`Function.prototype.toString`은 함수의 소스 코드를 문자열로 반환합니다. `String(fn)`, 템플릿 리터럴 `${fn}`, `fn + ''`도 이 메서드를 거칩니다.

```js
function add(a, b) {
  // 합
  return a + b
}

add.toString()
// 'function add(a, b) {\n  // 합\n  return a + b\n}'
```

반환값은 함수의 종류에 따라 다릅니다.

| 대상 | 반환값 |
|------|--------|
| 사용자 정의 함수(선언문, 표현식, 화살표 함수, 메서드, 클래스) | 소스 텍스트 그대로. 공백과 주석 포함 |
| 빌트인 함수 | `function max() { [native code] }` |
| 바운드 함수, 호출 가능한 Proxy | 엔진이 정한 NativeFunction 형식. V8은 `function () { [native code] }` |
| `new Function(...)`으로 만든 함수 | 명세가 정한 합성 형식 `function anonymous(a,b\n) {\n본문\n}` |

```js
const o = { m(x) { return x } }
class K { static s() {} }

o.m.toString() // 'm(x) { return x }'
K.s.toString() // 's() {}' — static 키워드는 빠진다
K.toString()   // 'class K { static s() {} }'
```

- 소스 텍스트는 함수를 정의한 문법 조각을 그대로 잘라 낸 값입니다. 메서드는 이름부터 본문까지(`m(x) { return x }`), getter는 `get` 키워드부터(`get g() {}`), 클래스는 `class` 키워드부터 닫는 중괄호까지 전체입니다.
- 빌트인 함수는 소스를 얻을 수 없으므로 `[native code]` 형식을 반환합니다. 이 형식은 명세가 NativeFunction 문법으로 정했고, 이름 부분은 함수의 초기 이름과 같아야 합니다. getter는 `function get size() { [native code] }`처럼 `get`이 붙습니다.
- ES2019 전에는 사용자 정의 함수의 표현 형식도 엔진이 정할 수 있었습니다. ES2019부터 소스 텍스트를 그대로 반환하도록 명세가 고정했습니다.
- `new Function('a', 'b', 'return a + b')`는 이름이 `anonymous`이고 매개변수 목록과 본문을 줄바꿈으로 구분한 코드를 반환합니다(`Function` 생성자는 11편).
- `this`가 함수가 아니면 TypeError입니다. `Function.prototype.toString.call({})`과 `.call(1)`이 해당합니다.
- `Object.prototype.toString.call(fn)`은 별개의 메서드이며 소스가 아니라 `'[object Function]'`을 반환합니다.
- 압축·변환 같은 빌드 도구가 코드를 바꾸면 `toString` 결과도 달라집니다. 소스 텍스트를 파싱해 동작을 결정하는 코드는 빌드 후에 깨집니다(자세히는 51편).

## 핵심 정리

- 함수는 일급 객체입니다. 런타임에 생성하고, 변수·자료구조에 저장하고, 인수로 전달하고, 반환할 수 있으며, 일반 객체의 기능에 더해 호출할 수 있습니다.
- 함수의 표준 own 프로퍼티는 `length`, `name`, `prototype`(constructor 함수와 제너레이터 함수만)이고, 모두 enumerable이 아닙니다. `length`와 `name`은 읽기 전용입니다.
- `arguments`는 전달된 모든 인수를 담는 유사 배열 객체입니다. 화살표 함수에는 없고, 새 코드에서는 나머지 매개변수를 씁니다. 비엄격 모드이면서 매개변수가 단순할 때만 매개변수와 값을 공유합니다.
- `__proto__`는 객체의 프로토타입에 접근하는 접근자이고, `prototype`은 constructor 함수가 인스턴스의 프로토타입으로 쓸 객체를 담는 프로퍼티입니다.
- `arguments.callee`, `f.caller`, `f.arguments`는 엄격 모드에서 TypeError입니다. `toString`은 소스 텍스트를 반환하고 빌트인 함수는 `[native code]`를 반환합니다.
