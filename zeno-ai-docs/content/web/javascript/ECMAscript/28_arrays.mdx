## 핵심 먼저 보기

- 배열은 `length`와 인덱스 프로퍼티가 연동되는 객체이며, 대입하면 참조가 복사됩니다. `length`를 줄이면 요소가 잘리고, 늘리면 빈 슬롯이 생깁니다.
- 빈 슬롯은 `undefined` 값이 아니라 프로퍼티가 없는 칸입니다. `forEach`·`map`·`filter` 등은 건너뛰고 `find`·`includes`·스프레드는 `undefined`로 읽으므로 희소 배열을 만들지 않습니다.
- 원본을 바꾸는 메서드는 `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`, `copyWithin` 9개이고 반환값이 제각각입니다. 원본이 필요하면 `toSorted`, `toReversed`, `toSpliced`, `with`나 `slice`·`concat`을 씁니다.
- `indexOf`는 `===`로 비교해 `NaN`을 못 찾고, `includes`는 SameValueZero라서 찾습니다. `splice(indexOf(x), 1)`은 `-1`일 때 마지막 요소를 지웁니다.
- `fill`은 같은 참조를 모든 칸에 넣으므로 객체 칸에는 `Array.from`의 `mapFn`을 씁니다. 배열 판별은 `Array.isArray`, 유사 배열 객체의 변환은 `Array.from`입니다.

## 배열·요소·인덱스

배열(array)은 값을 순서대로 담는 객체입니다. 담긴 값을 요소(element), 요소의 순번을 인덱스(index)라고 하며 인덱스는 0부터 시작합니다.

```js
const fruits = ['apple', 'banana', 'cherry']
fruits[0]      // 'apple'
fruits[2]      // 'cherry'
fruits[3]      // undefined (에러가 아니다)
fruits.length  // 3
```

- 마지막 요소의 인덱스는 `length - 1`입니다.
- 없는 인덱스를 읽으면 에러 없이 `undefined`가 나옵니다. 요소 값이 `undefined`인 경우와 구분하려면 `in` 연산자를 씁니다(아래 length와 희소 배열).
- 요소의 타입은 섞여도 되고, 배열도 요소가 될 수 있습니다. 배열 안의 배열을 중첩 배열이라고 하며, 2차원 배열은 중첩 배열로 표현합니다.

## JavaScript 배열의 특징

JavaScript의 배열은 `Array.prototype`을 상속하는 특수한 객체입니다. 인덱스 프로퍼티와 `length`가 서로 연동되는 것이 일반 객체와의 차이이고, 명세는 이런 객체를 Array exotic object라고 부릅니다.

| 항목 | C·Java의 배열 | JavaScript 배열 |
|------|---------------|-----------------|
| 크기 | 생성할 때 고정 | 언제든 변한다 |
| 요소 타입 | 하나로 통일 | 섞을 수 있다 |
| 빈 칸 | 모든 칸에 값이 있다 | 값이 없는 빈 슬롯을 가질 수 있다 |
| 메모리 | 연속된 공간 | 명세가 규정하지 않는다 |

```js
const arr = [1, 2, 3]
arr.note = 'extra'
arr.length        // 3
arr.map(x => x)   // [1, 2, 3]
Object.keys(arr)  // ['0', '1', '2', 'note']
```

## length와 희소 배열

`length`는 배열의 가장 큰 인덱스 + 1입니다. 읽고 쓸 수 있지만 열거와 삭제는 되지 않는 프로퍼티입니다(자세히는 14편). 희소 배열에서는 요소 개수와 다를 수 있습니다.

## 배열 생성(리터럴·Array·of·from)

`[]`는 요소를 직접 적습니다. `Array(3)`은 길이 3의 빈 슬롯 배열이고 `Array.of(3)`은 요소 하나가 3인 배열입니다. `Array.from`은 이터러블·유사 배열을 실제 배열로 바꿉니다.

## Array.fromAsync (ES2026)

`Array.fromAsync(items, mapFn, thisArg)`는 비동기 이터러블을 포함한 입력을 배열로 모으고, 그 배열로 이행하는 프로미스를 반환합니다(프로미스는 41편, `await`는 43편).

| 비교 | `Array.fromAsync` | `Promise.all` |
|------|-------------------|---------------|
| 입력 | 비동기·동기 이터러블, 유사 배열 | 동기 이터러블 |
| 처리 | 하나씩 순서대로 | 전부 동시에 기다림 |
| 변환 함수 | `mapFn` 인수 | 없음 (`map`으로 미리 변환) |

## 요소 참조·추가·갱신·삭제

| 동작 | 방법 | 비고 |
|------|------|------|
| 참조 | `arr[i]` | 범위 밖이면 `undefined` |
| 끝에 추가 | `arr.push(v)`, `arr[arr.length] = v` | |
| 앞·중간에 추가 | `unshift`, `splice` | |
| 갱신 | `arr[i] = v` | |
| 삭제 | `pop`, `shift`, `splice`, `length` 줄이기 | `delete`는 빈 슬롯만 남긴다 |

음수 인덱스는 뒤에서 세는 것이 아닙니다. `-1`은 그냥 문자열 키 `'-1'`이므로, 읽으면 `undefined`이고 쓰면 `length`는 그대로인 일반 프로퍼티가 생깁니다. 뒤에서 읽으려면 `at`을 씁니다(아래 at).

## 원본 변경 메서드와 새 배열 반환 메서드

배열 메서드는 호출한 배열 자체를 바꾸는 것과 원본을 두고 새 값을 만드는 것으로 나뉩니다. 원본을 바꾸는 메서드는 9개입니다.

| 메서드 | 반환값 |
|--------|--------|
| `push`, `unshift` | 바뀐 뒤의 새 `length` |
| `pop`, `shift` | 제거한 요소 |
| `splice` | 제거한 요소들의 배열 |
| `sort`, `reverse`, `fill`, `copyWithin` | 원본 배열 자체 |

## Array.isArray

`Array.isArray(value)`(ES5)는 값이 배열이면 `true`를 반환합니다.

## indexOf·includes

`indexOf(value, fromIndex)`는 처음 일치하는 인덱스를, `includes(value, fromIndex)`는 존재 여부를 반환합니다.

| 항목 | `indexOf` | `includes` |
|------|-----------|------------|
| 반환값 | 인덱스, 없으면 `-1` | `true` 또는 `false` |
| 비교 방식 | 엄격한 동등(`===`) | SameValueZero |
| `NaN` | 찾지 못한다 | 찾는다 |
| 빈 슬롯 | 건너뛴다 | `undefined`로 취급한다 |
| 도입 | ES5 | ES2016 |

## lastIndexOf

`lastIndexOf(value, fromIndex)`는 `indexOf`와 같은 비교 방식으로 뒤에서 앞으로 검색해 마지막으로 일치하는 인덱스를 반환합니다. 없으면 `-1`입니다.

## push·pop·unshift·shift

끝과 앞에서 요소를 추가하고 제거하는 메서드입니다. 모두 원본을 바꿉니다.

| 메서드 | 위치 | 동작 | 반환값 |
|--------|------|------|--------|
| `push(...items)` | 끝 | 추가 | 새 `length` |
| `pop()` | 끝 | 제거 | 제거한 요소 |
| `unshift(...items)` | 앞 | 추가 | 새 `length` |
| `shift()` | 앞 | 제거 | 제거한 요소 |

## concat

`concat(...values)`는 원본 뒤에 인수를 이어 붙인 새 배열을 반환합니다. 원본은 바뀌지 않습니다.

## splice·slice

두 메서드는 이름이 비슷하지만 성격이 다릅니다.

| 항목 | `slice(start, end)` | `splice(start, deleteCount, ...items)` |
|------|---------------------|-----------------------------------------|
| 원본 | 바꾸지 않는다 | 바꾼다 |
| 반환값 | 선택한 구간의 새 배열 | 제거한 요소들의 배열 |
| 두 번째 인수 | 끝 인덱스(미포함) | 제거할 개수 |
| 용도 | 일부를 복사 | 삭제·삽입·교체 |

## join·reverse·fill

`join(separator)`는 요소를 문자열로 바꿔 구분자로 이은 문자열을 반환합니다. 구분자를 생략하면 쉼표입니다.

## fill의 참조 공유

`Array(3).fill({})`는 같은 객체를 세 번 넣습니다. 한 요소의 객체를 바꾸면 나머지도 바뀐 것처럼 보입니다. 요소별 객체가 필요하면 `Array.from({ length: 3 }, () => ({}))`로 각각 만듭니다.

## copyWithin

`copyWithin(target, start, end)`(ES2015)는 배열 안의 `start` 이상 `end` 미만 구간을 같은 배열의 `target` 위치로 복사해 덮어씁니다. 원본을 바꾸고 원본 배열 자체를 반환합니다.

## flat

`flat(depth)`(ES2019)는 중첩 배열을 `depth` 단계까지 펼친 새 배열을 반환합니다. `depth`의 기본값은 1입니다.

## at

`at(index)`(ES2022)는 인덱스의 요소를 반환하되 음수 인덱스를 뒤에서부터 셉니다. 범위를 벗어나면 `undefined`입니다.

## toSorted·toReversed·toSpliced·with

ES2023에서 추가된 네 메서드는 원본을 바꾸는 `sort`, `reverse`, `splice`, 인덱스 대입에 각각 대응하며 원본은 두고 바뀐 새 배열을 반환합니다.

| 원본 변경 | 복사본 반환 |
|-----------|-------------|
| `sort(compareFn)` | `toSorted(compareFn)` |
| `reverse()` | `toReversed()` |
| `splice(start, deleteCount, ...items)` | `toSpliced(start, deleteCount, ...items)` |
| `arr[i] = value` | `with(i, value)` |

## keys·values·entries

`keys()`, `values()`, `entries()`는 배열을 순회하는 이터레이터(Array Iterator 객체)를 반환합니다(ES2015). 배열이 아니라 `for...of`나 스프레드로 소비하는 이터레이터입니다(자세히는 35편).

| 메서드 | 순회하는 값 |
|--------|-------------|
| `keys()` | 인덱스 |
| `values()` | 요소 |
| `entries()` | `[인덱스, 요소]` 쌍 |

## 유사 배열 객체

유사 배열 객체(array-like object)는 `length` 프로퍼티와 0부터 시작하는 인덱스 프로퍼티를 가졌지만 `Array.prototype`을 상속하지 않는 객체입니다. `arguments`, DOM의 `NodeList`·`HTMLCollection`, 문자열의 인덱스 접근이 대표적입니다.

## 메서드별 빈 요소 처리

같은 희소 배열이라도 메서드마다 빈 슬롯을 다르게 처리합니다. 처리 방식은 다음 여덟 가지로 나뉩니다.

| 처리 방식 | 메서드 |
|-----------|--------|
| 건너뜀 (콜백·비교를 하지 않음) | `forEach`, `map`, `filter`, `some`, `every`, `reduce`, `reduceRight`, `flatMap`, `indexOf`, `lastIndexOf` |
| `undefined`로 방문 | `find`, `findIndex`, `findLast`, `findLastIndex`, `includes`, `keys`·`values`·`entries`, `Array.from`, 스프레드, `for...of` |
| 빈 슬롯 그대로 유지 | `concat`, `slice`, `splice`(옮겨지는 요소), `reverse`, `copyWithin`, `map`의 결과 |
| 제거 | `flat` |
| 맨 끝으로 모음 | `sort`: `undefined` 뒤에 빈 슬롯, 비교 함수는 호출하지 않는다 |
| `undefined` 요소로 채워 반환 | `toSorted`, `toReversed`, `toSpliced`, `with` |
| 빈 문자열 | `join` |
| 값으로 채움 | `fill` |

## 배열 메서드 전체 분류표

원본을 바꾸는 메서드입니다.

| 메서드 | 반환값 | 도입 | 다루는 곳 |
|--------|--------|------|-----------|
| `push` | 새 `length` | ES5 이전 | 이 편 |
| `pop` | 제거한 요소 | ES5 이전 | 이 편 |
| `unshift` | 새 `length` | ES5 이전 | 이 편 |
| `shift` | 제거한 요소 | ES5 이전 | 이 편 |
| `splice` | 제거한 요소의 배열 | ES5 이전 | 이 편 |
| `reverse` | 원본 배열 | ES5 이전 | 이 편 |
| `fill` | 원본 배열 | ES2015 | 이 편 |
| `copyWithin` | 원본 배열 | ES2015 | 이 편 |
| `sort` | 원본 배열 | ES5 이전 | 29편 |
