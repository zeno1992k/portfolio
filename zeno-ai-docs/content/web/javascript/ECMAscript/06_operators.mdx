## 핵심 먼저 보기

- `+`는 한쪽이라도 문자열이면 연결이고, 그 밖의 산술 연산자는 피연산자를 항상 숫자(BigInt)로 바꿉니다. BigInt와 Number를 섞으면 TypeError입니다.
- `===`는 변환 없이 비교하고 `==`는 규칙 표에 따라 변환합니다. `Object.is`는 `NaN`과 `-0`에서만 `===`와 다릅니다.
- 문자열끼리의 대소 비교는 코드 단위 순서이고 다른 값은 숫자 변환의 영향을 받습니다. `null >= 0`은 참이지만 `null == 0`은 거짓입니다. `NaN`이 있으면 대소 비교는 모두 거짓입니다.
- `&&`·`||`·`??`는 피연산자 중 하나를 돌려주며 오른쪽을 건너뛸 수 있고, `??`는 `||`·`&&`와 괄호 없이 섞을 수 없습니다.
- 피연산자는 항상 왼쪽부터 평가되고 우선순위는 묶는 방식만 정합니다. 섞이는 곳은 괄호로 의도를 적습니다.
- `%`의 부호는 왼쪽 값을 따르고, `**`는 오른쪽 결합이며 단항 연산자 바로 뒤에서는 SyntaxError이고, `typeof null`은 `'object'`입니다.

## 산술 연산자

산술 연산자는 피연산자(operand, 연산 대상 값) 두 개를 계산해 숫자를 돌려주는 이항(binary) 연산자입니다.

| 연산자 | 이름 | 예 | 결과 |
|--------|------|----|------|
| `+` | 덧셈 | `7 + 2` | `9` |
| `-` | 뺄셈 | `7 - 2` | `5` |
| `*` | 곱셈 | `7 * 2` | `14` |
| `/` | 나눗셈 | `7 / 2` | `3.5` |
| `%` | 나머지 | `7 % 2` | `1` |

```js
1 / 0                // Infinity
-1 / 0               // -Infinity
0 / 0                // NaN
Infinity - Infinity  // NaN
Infinity * 0         // NaN
```

## 단항 + 와 -

단항(unary) 연산자는 피연산자가 하나인 연산자입니다. 피연산자가 둘이면 이항, 셋이면 삼항이며 삼항 연산자는 `?:` 하나뿐입니다.

```js
+'42'        // 42
+''          // 0
+'12px'      // NaN
+true        // 1
+null        // 0
+undefined   // NaN
+[]          // 0
+new Date()  // 현재 시각(밀리초 타임스탬프)
```

## 증가·감소 연산자

`++`와 `--`는 피연산자를 숫자로 바꿔 1을 더하거나 뺀 값을 같은 변수에 저장하는 연산자입니다. 피연산자는 변수나 프로퍼티처럼 값을 저장할 수 있는 대상이어야 합니다.

| 형태 | 이름 | 식의 값 | 변수의 새 값 |
|------|------|---------|--------------|
| `++x` | 전위 | 증가한 새 값 | `x + 1` |
| `x++` | 후위 | 증가하기 전 값 | `x + 1` |

## 문자열 연결

`+`는 피연산자 중 하나라도 문자열이면 덧셈이 아니라 문자열 연결을 합니다. 다른 산술 연산자는 연결 기능이 없습니다.

## 할당 연산자

`=`는 오른쪽 값을 왼쪽 대상에 저장하며, 식 전체의 값은 저장한 값입니다. 오른쪽 결합이라 연쇄 대입이 가능합니다.

## 동등 비교와 일치 비교

일치 비교(`===`, `!==`)는 타입 변환 없이 타입과 값이 모두 같은지 비교합니다. 동등 비교(`==`, `!=`)는 타입이 다르면 규칙에 따라 변환한 뒤 비교합니다. `!==`와 `!=`는 각각의 부정입니다.

| 타입 | 같다고 보는 조건 |
|------|------------------|
| Number | 수학적으로 같은 값. `NaN`은 자기 자신과도 다르고, `+0`과 `-0`은 같음 |
| String | 코드 단위 열이 완전히 같음 |
| BigInt | 같은 정수 |
| Boolean | 같은 값 |
| `undefined`, `null` | 같은 타입이면 항상 같음 |
| Symbol, 객체 | 같은 참조 |

## Object.is

`Object.is`는 `NaN`끼리는 같게, `+0`과 `-0`은 다르게 봅니다. `===`는 반대로 `NaN`끼리는 다르고 두 0은 같다고 봅니다. 객체는 두 방식 모두 같은 참조인지 비교합니다.

## 대소 비교 연산자

문자열끼리는 UTF-16 코드 유닛 순서로 비교하고, 다른 일반 값은 숫자 변환의 영향을 받습니다. `NaN`과의 대소 비교는 모두 `false`입니다. 숫자 문자열을 비교할 때는 명시적으로 숫자로 바꿉니다.

## 삼항 조건 연산자

`조건 ? 값1 : 값2`는 조건이 참이면 `값1`, 거짓이면 `값2`를 평가한 결과를 돌려주는 연산자입니다. 자바스크립트의 유일한 삼항 연산자이며, 조건은 불리언으로 변환됩니다(자세히는 08편). 선택되지 않은 쪽은 평가되지 않습니다.

## 논리 연산자

`&&`(AND), `||`(OR), `??`(널 병합, ES2020)는 불리언이 아니라 **피연산자 중 하나를 그대로** 돌려줍니다. `!`(NOT)만 항상 불리언을 돌려줍니다.

## 지수 연산자

`a ** b`(ES2016)는 `a`의 `b`제곱입니다. 숫자에서는 `Math.pow(a, b)`와 결과가 같습니다.

## 비트 연산자

Number 비트 연산은 보통 값을 32비트 정수로 바꿉니다. `| 0`을 일반적인 반올림이나 큰 정수 처리에 쓰면 값이 손실됩니다. BigInt 비트 연산은 BigInt끼리 해야 하고 `>>>`는 지원하지 않습니다.

## typeof와 주의점

`typeof 피연산자`는 피연산자의 타입을 나타내는 문자열을 돌려주는 단항 연산자입니다. `typeof(x)`의 괄호는 함수 호출이 아니라 그룹 연산자입니다. 결과는 항상 문자열이라 `typeof typeof 1`은 `'string'`입니다.

| 값 | 결과 |
|----|------|
| `undefined` | `'undefined'` |
| `null` | `'object'` |
| `true`, `false` | `'boolean'` |
| 숫자 (`NaN`, `Infinity` 포함) | `'number'` |
| BigInt | `'bigint'` |
| 문자열 | `'string'` |
| 심볼 | `'symbol'` |
| 호출할 수 있는 객체 (함수, 클래스, 화살표·async·제너레이터 함수, bind 결과) | `'function'` |
| 그 밖의 모든 객체 (배열, Date, RegExp, Map, Set, Promise, Error, 래퍼 객체, `Math`, `JSON`) | `'object'` |

## in 연산자

`키 in 객체`는 객체 자신이나 프로토타입 체인에 그 키가 있으면 `true`를 돌려줍니다. 왼쪽은 프로퍼티 키(문자열 또는 심볼로 변환), 오른쪽은 객체여야 하며 원시값·`null`·`undefined`이면 TypeError입니다.

## instanceof 연산자

`객체 instanceof 생성자`는 생성자의 `prototype` 객체가 왼쪽 객체의 프로토타입 체인에 있으면 `true`를 돌려줍니다(자세히는 17편).

## 쉼표·그룹·void·delete

`a, b`는 `a`를 평가해 값을 버리고 `b`를 평가한 값을 돌려주는 연산자입니다. 우선순위가 모든 연산자 중 가장 낮습니다.

## 부수 효과

부수 효과(side effect)는 식이 값을 계산하는 것 외에 프로그램의 다른 상태를 바꾸거나 바깥에 영향을 주는 동작입니다. 값만 만들고 아무것도 바꾸지 않는 식은 순수한 식입니다.

| 부수 효과를 일으키는 것 | 바뀌는 것 |
|-------------------------|-----------|
| `=`, 복합 할당 | 변수·프로퍼티 값 |
| `++`, `--` | 피연산자 값 |
| `delete` | 프로퍼티 존재 여부 |
| 함수·메서드 호출, `new` | 함수 본문이 하는 모든 일(출력, 변경, 예외) |
| `await`, `yield` | 실행의 중단과 재개 |

## 우선순위와 결합 순서

우선순위(precedence)는 여러 연산자가 섞인 식에서 어느 연산자가 피연산자를 먼저 묶는지의 순서입니다. 결합 순서(associativity)는 우선순위가 같은 연산자가 이어질 때 묶는 방향입니다. 왼쪽 결합이면 `a - b - c`가 `(a - b) - c`, 오른쪽 결합이면 `a = b = c`가 `a = (b = c)`입니다.
