## 핵심 먼저 보기

- 심벌은 호출마다 고유한 원시 값입니다. `Symbol()`은 `new` 없이 호출하고, 설명이 같아도 서로 다릅니다. `Symbol.for(key)`만 key가 같으면 같은 심벌을 모든 realm에서 공유합니다.
- 심벌 키는 대괄호로만 접근합니다. `for...in`, `Object.keys`, `JSON.stringify`에서는 빠지지만 `Object.getOwnPropertySymbols`와 `Reflect.ownKeys`로 드러나므로 진짜 private이 아닙니다.
- 심벌 키로 빌트인 객체를 확장하면 이름 충돌과 `for...in` 노출이 없습니다. 전역 상태를 바꾼다는 점은 그대로입니다.
- Well-known Symbol 13개는 `for...of`, `instanceof`, 형 변환, 문자열 메서드 등 언어 동작을 객체가 바꾸는 훅입니다. `Symbol.dispose` 계열은 ES2027 예정입니다.
- 심벌은 문자열·숫자로 암묵 변환되지 않습니다. `+ ''`, 템플릿 삽입, 산술은 TypeError이고 `String(sym)`, `description`, 불리언 변환, `==` 비교만 에러 없이 동작합니다.

## 심벌의 개념

심벌(Symbol)은 ES2015에서 추가된 원시 타입으로, 만들 때마다 다른 값이 되는 고유한 값입니다. 프로퍼티 키로 쓸 수 있는 값은 문자열과 심벌 두 가지뿐입니다(자세히는 09편).

```js
const a = Symbol('id')
const b = Symbol('id')
a === b      // false
typeof a     // 'symbol'
```

| 종류 | 만드는 법 | 같은 값이 되는 조건 |
|------|-----------|---------------------|
| 일반 심벌 | `Symbol(desc)` | 같은 심벌을 참조할 때뿐 |
| 등록 심벌 | `Symbol.for(key)` | key가 같을 때 |
| Well-known Symbol | `Symbol.iterator` 등 | 어느 realm에서나 항상 같은 값 |

## Symbol 함수와 값 생성

`Symbol([description])`은 호출할 때마다 새 심벌을 반환하는 함수입니다.

```js
const s1 = Symbol()
const s2 = Symbol('login')
console.log(s2)   // Symbol(login)
new Symbol()      // TypeError
```

| 멤버 | 반환값 |
|------|--------|
| `toString()` | `'Symbol(설명)'` 문자열 |
| `valueOf()` | 심벌 자신 |
| `description` (getter) | 설명 문자열 또는 `undefined` |
| `[Symbol.toPrimitive]()` | 심벌 자신 (힌트와 무관) |
| `[Symbol.toStringTag]` | `'Symbol'` |

## description과 toString

`description`은 심벌을 만들 때 준 설명을 읽는 접근자 프로퍼티입니다(ES2019).

## Symbol.for와 Symbol.keyFor

`Symbol.for(key)`는 전역 심벌 레지스트리에서 key에 해당하는 심벌을 찾아 반환하고, 없으면 만들어 등록한 뒤 반환합니다. `Symbol.keyFor(sym)`은 등록 심벌의 key를 돌려줍니다.

| 구분 | `Symbol()` | `Symbol.for()` |
|------|------------|----------------|
| 새 값이 만들어지는 때 | 호출할 때마다 | key마다 처음 한 번 |
| 같은 설명 | 서로 다른 값 | 같은 값 |
| realm 사이 | 서로 다른 값 | 같은 값 |
| WeakMap 키·WeakRef 대상 | 가능 | TypeError |

## 심벌과 상수

값이 서로 겹치면 안 되는 상수(열거형 값)에 심벌을 쓸 수 있습니다. 심벌 상수는 상수 객체를 거쳐야만 얻을 수 있고, 다른 상수와 값이 우연히 같아질 수 없습니다.

## 심벌과 프로퍼티 키

심벌 키 프로퍼티는 계산된 이름(`[sym]`)이나 대괄호 표기법으로 만들고 읽습니다.

| API | 심벌 키 |
|-----|---------|
| `Object.keys`, `values`, `entries`, `for...in`, `getOwnPropertyNames` | 포함하지 않음 |
| `Object.getOwnPropertySymbols` | 심벌 키만 반환 (열거 불가 포함) |
| `Reflect.ownKeys`, `Object.getOwnPropertyDescriptors` | 포함 (열거 불가 포함) |
| `Object.assign`, 객체 스프레드 | 열거 가능한 것만 복사 |
| `JSON.stringify` | 무시 |

## 프로퍼티 은닉

심벌 키는 `Object.keys`·`for...in`에 나오지 않지만 `Reflect.ownKeys`·`Object.getOwnPropertySymbols`로 찾을 수 있습니다. 충돌을 줄이는 도구이며 보안상 비밀이나 private 필드의 대체물이 아닙니다.

## 표준 빌트인 객체 확장

내장 프로토타입을 수정하면 다른 라이브러리와 충돌하거나 표준 기능을 덮어쓸 수 있습니다. 심벌 키는 이름 충돌을 줄여도 전역 영향은 없애지 못합니다. 별도 함수나 래퍼를 우선 사용합니다.

## Well-known Symbol

Well-known Symbol은 명세가 미리 만들어 `Symbol`의 정적 프로퍼티로 제공하는 심벌입니다. 엔진의 내부 알고리즘이 객체의 동작을 확인할 때 이 심벌을 키로 프로퍼티를 찾습니다. 객체에 그 키로 메서드를 정의하면 `for...of`, `instanceof`, 형 변환 같은 언어 기능의 동작을 바꿀 수 있습니다.

## toPrimitive

`Symbol.toPrimitive`는 객체를 원시 값으로 바꾸는 방법을 직접 정하는 메서드의 키입니다. 엔진은 객체가 문자열이나 숫자 자리에 쓰이면 이 메서드를 힌트(hint)와 함께 호출합니다.

| 힌트 | 발생하는 문맥 |
|------|---------------|
| `'number'` | 단항 `+`·`-`, `*` 같은 산술, 대소 비교, `Number()`, `Math.max()` |
| `'string'` | 템플릿 리터럴 삽입, `String()`, 계산된 프로퍼티 키, `join`, `parseInt` |
| `'default'` | 이항 `+`, `==`, `new Date(obj)` |

## toStringTag

`Symbol.toStringTag`는 `Object.prototype.toString()`이 만드는 `'[object 태그]'` 문자열에서 태그를 정하는 프로퍼티의 키입니다.

## 심벌의 형 변환 제약

심벌은 문자열이나 숫자로 암묵적 변환되지 않습니다. 명시적 변환도 일부만 허용됩니다. 전체 변환 규칙은 08편이고 여기서는 심벌 기준으로 모았습니다.

| 연산 | 결과 |
|------|------|
| `String(sym)`, `sym.toString()` | `'Symbol(설명)'` |
| `sym.description` | 설명 문자열 또는 `undefined` |
| `Boolean(sym)`, `!sym`, `if (sym)` | `true` (심벌은 항상 truthy) |
| `sym + ''`, 템플릿 리터럴에 삽입 | TypeError |
| `Number(sym)`, `+sym`, `sym * 2` | TypeError |
| `[sym].join()`, `parseInt(sym)` | TypeError |
| `sym == 'a'`, `sym === 'a'` | `false` (에러 아님) |

## JSON·for...in에서 제외

`JSON.stringify`와 `for...in`은 문자열 키만 다룹니다. 심벌 키 프로퍼티는 열거 가능이어도 둘 다에서 빠집니다(자세히는 39편, 18편).

| API | 문자열 키 | 심벌 키 |
|-----|-----------|---------|
| `for...in` | 열거 가능 (상속 포함) | 제외 |
| `Object.keys` / `values` / `entries` | 열거 가능 | 제외 |
| `JSON.stringify` | 열거 가능 | 제외 |
| `Object.assign` / 객체 스프레드 | 열거 가능 | 열거 가능한 것만 복사 |
| `getOwnPropertyNames` | 전부 | 제외 |
| `getOwnPropertySymbols` | 제외 | 전부 |
| `Reflect.ownKeys` | 전부 | 전부 |
