## 핵심 먼저 보기

- 값은 표현식의 평가 결과이고, 리터럴은 값을 소스에 직접 적는 표기입니다. `undefined`, `NaN`, `Infinity`는 리터럴이 아닌 식별자입니다.
- 표현식은 값이 오는 자리에 쓸 수 있고, 문은 쓸 수 없습니다. 선언과 제어문은 표현식이 아닙니다.
- 문 맨 앞의 `{`, `function`, `class`는 블록·선언으로 해석되므로 표현식으로 쓰려면 괄호로 감쌉니다.
- ASI는 문법 오류가 났을 때만 세미콜론을 삽입합니다. `return` 뒤 줄바꿈은 `return;`이 됩니다.
- 줄이 `(`, `[`, 백틱, `+`·`-`, `/`로 시작하면 앞 줄과 합쳐집니다. 세미콜론을 쓰거나 그 줄 앞에 `;`를 둡니다.
- 완료 값은 `eval()`과 콘솔 출력으로만 보이며, 선언은 값이 없고 `if`·반복문은 undefined로 덮어씁니다.

## 값

값(value)은 표현식이 평가되어 만들어지는 데이터입니다. 평가(evaluation)는 코드를 계산해 하나의 값으로 확정하는 일입니다.

```js
10 + 20         // 평가 결과: 30
'a' + 'b'       // 평가 결과: 'ab'
10 > 5          // 평가 결과: true
```

## 리터럴

리터럴(literal)은 소스 코드에 값을 직접 적는 표기법입니다. 엔진은 리터럴을 평가해 그 표기가 뜻하는 값을 만듭니다.

<details>
<summary>전체 비교표 펼치기</summary>

| 종류 | 예 | 평가 결과 |
|------|----|-----------|
| 숫자 | `42` `3.14` | Number |
| BigInt | `42n` | BigInt |
| 문자열 | `'a'` `"a"` | String |
| 템플릿 | `` `a${x}` `` | String |
| 불리언 | `true` `false` | Boolean |
| null | `null` | Null |
| 정규 표현식 | `/ab+/g` | RegExp 객체(32편) |
| 객체 | `{ a: 1 }` | 객체(09편) |
| 배열 | `[1, 2]` | 배열 객체(28편) |
| 함수 | `function () {}` `() => {}` | 함수 객체(11편) |

</details>

```js
1_000_000    // ✅ 1000000
1e1_0        // ✅ 10000000000
100_         // ❌ SyntaxError: 맨 끝
1__0         // ❌ SyntaxError: 연속
0_1          // ❌ SyntaxError: 0 바로 뒤
1_.5         // ❌ SyntaxError: 소수점 옆
0x_1         // ❌ SyntaxError: 접두사 바로 뒤
```

## 표현식

표현식(expression)은 평가되어 값이 되는 코드 조각입니다. 값을 만들 수 있는 문법 단위는 모두 표현식입니다.

<details>
<summary>전체 비교표 펼치기</summary>

| 종류 | 예 | 평가 결과 |
|------|----|-----------|
| 리터럴 | `10` | 그 값 |
| 식별자 | `count` | 저장된 값. 선언되지 않았으면 ReferenceError |
| 산술·비교·논리 | `1 + 2` `a > b` `a && b` | 연산 결과 |
| 삼항 | `ok ? 'a' : 'b'` | 선택된 쪽의 값 |
| 멤버 접근 | `user.name` `list[0]` | 프로퍼티 값 |
| 함수 호출 | `add(1, 2)` | 반환값 |
| 생성 | `new Date()` | 새 객체 |
| 할당 | `x = 5` | 할당한 값 5 |
| 증감 | `i++` | 증가 전 값(`++i`는 증가 후 값) |
| 함수·클래스 | `function () {}` `class {}` | 함수 객체 / 클래스 |
| 그룹 | `(a + b)` | 안쪽 표현식의 값 |
| 쉼표 | `(a, b)` | 마지막 값 b |
| 템플릿 | `` `x${a}` `` | 문자열 |
| await·yield | `await p` | 프로미스 결과(43편) / 재개 값(42편) |

</details>

## 문과 토큰

문(statement)은 프로그램을 이루는 실행 단위로, 엔진에 내리는 명령 하나입니다. 스크립트는 문의 나열이며 엔진은 위에서 아래로 순서대로 실행합니다. 제어문이 이 흐름을 바꿉니다.

<details>
<summary>전체 비교표 펼치기</summary>

| 종류 | 예 | 자세히 |
|------|----|--------|
| 변수 선언 | `let a = 1` `const b = 2` | 03편 |
| 함수·클래스 선언 | `function f() {}` `class A {}` | 11편, 24편 |
| 표현식 문 | `a = 1;` `f();` | 아래 절 |
| 블록 | `{ ... }` | 07편 |
| 조건문 | `if` `switch` | 07편 |
| 반복문 | `for` `while` `do...while` `for...of` | 07편 |
| 점프문 | `break` `continue` `return` `throw` | 07편, 11편, 44편 |
| 예외 처리 | `try...catch...finally` | 44편 |
| 빈 문 | `;` | 아래 절 |
| 모듈 | `import` `export` | 45편 |
| 기타 | `debugger` `with` | |

</details>

## 표현식인 문과 표현식이 아닌 문

표현식인 문은 값으로 평가되는 문이고, 표현식이 아닌 문은 값으로 평가되지 않는 문입니다. 표현식 뒤에 `;`를 붙이면 표현식 문(expression statement)이 되어 값은 버려지고 부수 효과만 남습니다.

| 문 | 표현식인가 | 이유 |
|----|-----------|------|
| `x = 5;` | 예 | 할당 표현식 |
| `f();` `i++;` | 예 | 호출·증감 표현식 |
| `1 + 2;` | 예 | 값을 버리는 표현식 문 |
| `var` `let` `const` 선언 | 아니오 | 선언문. `var x = 5`의 `= 5`는 할당 표현식이 아니라 초기화 |
| 함수·클래스 선언 | 아니오 | 선언문 |
| `if` `for` `while` `switch` `try` | 아니오 | 제어문 |
| `return` `break` `continue` `throw` | 아니오 | 점프문 |
| `{ }` 블록 | 아니오 | 문의 묶음 |

## 세미콜론과 ASI

세미콜론(`;`)은 문의 끝을 나타냅니다. 줄 끝의 세미콜론은 생략할 수 있고, 생략하면 엔진이 자동 세미콜론 삽입(ASI, Automatic Semicolon Insertion)으로 채웁니다. ASI는 줄 끝마다 세미콜론을 붙이는 기능이 아니라, 파서가 문법 오류를 만났을 때 쓰는 보정 규칙입니다.

| 위치 | 줄바꿈이 있으면 |
|------|-----------------|
| `return` 뒤 | `return;` — undefined 반환 |
| `break` `continue`와 레이블 사이 | 레이블 없는 `break;` `continue;` |
| `throw` 뒤 | SyntaxError (표현식이 없어 문이 불완전) |
| `yield` 뒤 | `yield;` — undefined를 내보냄 |
| 후위 `++` `--` 앞 | 다음 줄의 `++`가 전위 연산자로 읽힘 |
| `=>` 앞 | SyntaxError |
| `async` 뒤 | `async`가 식별자로 읽힘(async 함수가 아님) |

## ASI가 실패하는 5가지 시작 문자

앞 문장에 세미콜론이 없고 다음 줄이 `(`·`[`·백틱·`+`·`-`로 시작하면 앞 표현식의 연속으로 해석될 수 있습니다. `return` 바로 뒤 줄바꿈은 반대로 반환문을 끝냅니다. 줄바꿈만으로 문장의 경계를 판단하지 않습니다.

## 주석

주석(comment)은 엔진이 실행에서 무시하는 설명 텍스트입니다.

| 종류 | 문법 | 범위 |
|------|------|------|
| 한 줄 | `// 내용` | 줄바꿈 문자 직전까지 |
| 여러 줄 | `/* 내용 */` | 처음 만나는 `*/`까지. 중첩 불가 |
| 해시뱅 | `#!/usr/bin/env node` | 파일 맨 앞 두 글자일 때만. 한 줄. ES2023 |
| HTML 스타일 | `<!--` `-->` | 스크립트에서만. 모듈은 SyntaxError |

## 완료 값

완료 값(completion value)은 문 하나를 실행한 결과로 명세가 정하는 값입니다. 문은 값 자리에 쓸 수 없으므로 이 값은 프로그램 안에서 쓰이지 않습니다. 직접 볼 수 있는 곳은 `eval()`의 반환값과, 브라우저 개발자 도구와 Node.js REPL이 입력 줄 아래에 출력하는 값입니다.

| 종류 | 발생 | 의미 |
|------|------|------|
| normal | 문이 끝까지 실행됨 | 다음 문으로 진행 |
| break | `break` | 가장 가까운 반복문·`switch`·레이블을 벗어남 |
| continue | `continue` | 반복문의 다음 반복으로 |
| return | `return` | 함수 실행을 끝내고 값을 돌려줌 |
| throw | `throw` | 예외를 던져 `catch`를 찾음 |
