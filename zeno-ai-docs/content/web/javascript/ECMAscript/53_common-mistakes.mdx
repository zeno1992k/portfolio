## 핵심 먼저 보기

- `==`는 변환 규칙이 복잡해 `===`를 기본으로 쓰고, `NaN`은 `Number.isNaN`·`Object.is`로, `null`은 `=== null`로 검사합니다. 소수는 정수 단위나 허용 오차로 비교합니다.
- `this`는 호출 방식으로 결정되므로 메서드를 꺼내 넘기면 잃습니다. `bind`·화살표 래퍼로 고정하고, 객체 메서드를 화살표로 만들지 않습니다. `var`는 반복 콜백이 같은 변수를 공유하므로 `let`을 씁니다.
- 대입·`fill`·스프레드·`slice`는 객체를 공유합니다. 깊은 복사가 필요하면 `structuredClone`을 쓰고, `JSON` 복사는 `undefined`·함수·`Date`·`Map`을 잃습니다. `const`는 재대입만 막습니다.
- `sort()`는 문자열 순서이므로 비교 함수가 필요하고 원본을 바꿉니다. `map(parseInt)`는 인덱스가 진법이 되며, 빈 요소는 메서드마다 다르게 처리됩니다. `Date`의 월은 0부터입니다.
- `forEach`는 `async` 콜백을 기다리지 않고, `try/catch`는 `await`하지 않은 프로미스를 잡지 못합니다. `.then` 콜백은 `return`해야 체인이 이어집니다. 줄이 `(`·`[`로 시작하면 ASI가 삽입되지 않습니다.

## == 비교 함정

`==`(느슨한 동등)은 두 값의 타입이 다르면 변환한 뒤 비교합니다. `===`(엄격한 동등)은 변환하지 않고 타입과 값이 모두 같아야 `true`입니다(자세히는 06편, 08편).

```js
0 == ''           // true   ('' → 0)
0 == '0'          // true   ('0' → 0)
'' == '0'         // false  (둘 다 문자열, 변환 없음)
false == '0'      // true   (false → 0, '0' → 0)
null == undefined // true
null == 0         // false
[] == false       // true   ([] → '' → 0, false → 0)
[] == ![]         // true   (![] 는 false)
```

| 식 | 결과 | 비고 |
|----|------|------|
| `NaN === NaN` | `false` | 어떤 비교 연산자로도 `NaN`을 찾을 수 없다 |
| `Object.is(NaN, NaN)` | `true` | 같은 값으로 취급 |
| `0 === -0` | `true` | |
| `Object.is(0, -0)` | `false` | 부호까지 구분 |
| `[NaN].indexOf(NaN)` | `-1` | `indexOf`는 `===` 방식 |
| `[NaN].includes(NaN)` | `true` | `includes`는 같은 값 방식 |

## typeof null

`typeof null`은 `'object'`입니다. 1995년 초기 구현의 오류가 표준이 된 것이고, 기존 웹이 깨지므로 고치지 않습니다.

```js
typeof null       // 'object'
typeof []         // 'object'
typeof NaN        // 'number'
typeof function(){} // 'function'
typeof 10n        // 'bigint'
typeof undeclared // 'undefined' (에러 아님)
```

## 부동소수점 비교

JavaScript의 `number`는 64비트 이진 부동소수점(IEEE 754 double)입니다. 0.1처럼 이진수로 딱 떨어지지 않는 소수는 근삿값으로 저장되어 연산 결과에 오차가 남습니다.

## this 손실

메서드를 호출할 때 점 앞의 객체가 `this`가 됩니다. 메서드를 변수에 꺼내거나 콜백으로 넘기면 점이 사라져 `this`가 달라집니다(자세히는 21편).

| 방법 | 코드 |
|------|------|
| 바인딩 | `setTimeout(user.hello.bind(user), 0)` |
| 화살표 함수로 감싸기 | `setTimeout(() => user.hello(), 0)` |
| 클래스 필드 화살표 | `hello = () => this.name` |
| thisArg 전달 | `arr.forEach(user.hello, user)` |

## 클로저와 반복문

`var`는 함수당 바인딩이 하나입니다. 반복문 안에서 만든 콜백이 나중에 실행되면 모두 반복이 끝난 뒤의 같은 변수를 읽습니다(자세히는 23편).

## 참조 공유 버그

객체와 배열은 변수에 참조가 담깁니다. 대입이나 인수 전달은 객체를 복사하지 않고 참조만 복사하므로, 한쪽을 바꾸면 다른 쪽도 바뀝니다(자세히는 10편).

## sort 기본 동작

`Array.prototype.sort()`는 비교 함수가 없으면 각 요소를 문자열로 바꿔 UTF-16 코드 단위 순서로 정렬합니다. 숫자 크기 순이 아닙니다(자세히는 28편).

- 비교 함수는 음수, 0, 양수 중 하나를 반환해야 합니다. `(a, b) => a > b`는 `true`·`false`를 반환하는데 음수가 없으므로 결과가 보장되지 않습니다.
- `sort`는 원본 배열을 바꾸고 같은 배열을 반환합니다. `const sorted = arr.sort()`는 복사본이 아닙니다. 원본을 유지하려면 `[...arr].sort()` 또는 `arr.toSorted()`(ES2023)를 씁니다.
- `undefined`는 비교 함수를 거치지 않고 항상 맨 뒤로 가고, 빈 요소는 그 뒤에 놓입니다.
- 정렬은 안정 정렬입니다(ES2019부터 명세가 요구). 비교 결과가 같은 요소끼리는 원래 순서를 유지합니다.
- 문자열을 언어 규칙으로 정렬할 때는 `a.localeCompare(b)`나 `Intl.Collator`를 씁니다. 기본 정렬은 코드 단위 순서라 `'é'`가 `'z'` 뒤에 옵니다(자세히는 31편).

## forEach와 await

`forEach`는 콜백이 반환하는 값을 사용하지 않습니다. 콜백이 `async` 함수여도 반환된 프로미스를 기다리지 않고 다음 요소로 넘어가며, `forEach` 자체는 즉시 끝납니다(자세히는 29편, 43편).

| 원하는 동작 | 방법 | 실행 방식 |
|-------------|------|-----------|
| 하나씩 차례로 | `for (const n of arr) { await task(n) }` | 순차 |
| 전부 동시에 | `await Promise.all(arr.map(task))` | 병렬 |
| 결과 모으기 | `const rs = await Promise.all(arr.map(...))` | 병렬 |

## 비동기 에러 누락

`try/catch`는 try 블록이 실행되는 동안 던져진 에러만 잡습니다. 나중에 실행되는 코드의 에러와 `await`하지 않은 프로미스의 거부는 잡지 못합니다(자세히는 44편).

## ASI

자동 세미콜론 삽입(ASI, Automatic Semicolon Insertion)은 파서가 줄바꿈을 보고 세미콜론을 보충하는 규칙입니다. 다음 줄이 앞 줄과 문법적으로 이어질 수 있으면 삽입하지 않습니다(자세히는 04편).

- 줄이 `(`, `[`, `` ` ``(템플릿), `+`, `-`, `/`로 시작하면 앞 줄에 이어붙을 위험이 있습니다. 세미콜론을 쓰지 않는 스타일에서는 이런 줄 앞에 `;`를 붙입니다.
- `return` 뒤 줄바꿈은 반환문을 끝내며, `throw` 뒤 줄바꿈은 구문 오류입니다. 화살표 함수의 `=>` 앞에도 줄바꿈을 넣을 수 없습니다.

## parseInt와 map

`['1', '2', '3'].map(parseInt)`는 `[1, 2, 3]`이 아니라 `[1, NaN, NaN]`입니다. `map`은 콜백에 `(요소, 인덱스, 배열)` 세 인수를 넘기는데, `parseInt(문자열, 진법)`의 둘째 인수가 진법이라서 인덱스가 진법으로 들어갑니다.

| 호출 | 결과 | 이유 |
|------|------|------|
| `parseInt('1', 0)` | `1` | 진법 0은 지정하지 않은 것으로 보고 10진법 |
| `parseInt('2', 1)` | `NaN` | 진법은 2에서 36까지만 유효 |
| `parseInt('3', 2)` | `NaN` | 2진법에 `3`은 없는 숫자 |

## 배열 빈 요소

빈 요소(empty slot)가 있는 배열을 희소 배열이라고 합니다. 빈 요소는 값이 `undefined`인 요소와 다릅니다. 해당 인덱스에 프로퍼티 자체가 없습니다(자세히는 28편).

| 방식 | 빈 요소 처리 |
|------|--------------|
| `forEach`, `map`, `filter`, `reduce`, `some`, `every` | 건너뜀 (`map`은 빈 요소를 유지) |
| `for...of`, 스프레드, `Array.from`, `find`, `includes`, `join` | `undefined`로 취급 |
| `indexOf` | 건너뜀 (`[,1].indexOf(undefined)`는 `-1`) |
| `Object.keys`, `in` | 존재하지 않는 인덱스로 처리 |
| `JSON.stringify` | `null` |

## Date의 월

`Date` 생성자와 `getMonth`·`setMonth`의 월은 0부터 11입니다. 1월이 0, 12월이 11입니다. 일(`getDate`)은 1부터 31이지만, 요일(`getDay`)은 일요일이 0입니다(자세히는 31편).

| 문자열 | 해석 기준 |
|--------|-----------|
| `'2026-01-01'` (날짜만) | UTC 자정 |
| `'2026-01-01T00:00:00'` (시간 있고 오프셋 없음) | 로컬 시간 |
| `'2026-1-5'` 같은 비표준 형식 | 엔진마다 다름 |

## const 객체 변경

`const`는 변수에 다시 대입하는 것을 막을 뿐, 변수가 가리키는 객체의 내용을 막지 않습니다(자세히는 03편).

## JSON 복사의 손실

`JSON.parse(JSON.stringify(obj))`는 JSON으로 표현할 수 있는 값만 남기므로 복사 과정에서 값이 바뀌거나 사라집니다(자세히는 39편).

| 원본 값 | 복사 결과 |
|---------|-----------|
| `undefined`, 함수, Symbol | 객체 프로퍼티는 사라짐, 배열 요소는 `null` |
| `NaN`, `Infinity` | `null` |
| `-0` | `0` |
| `Date` | ISO 문자열 (Date 객체가 아님) |
| `Map`, `Set`, `RegExp` | `{}` |
| 클래스 인스턴스 | 프로토타입이 사라진 일반 객체 (메서드·getter 소실) |
| 순환 참조 | `TypeError` |
| `BigInt` | `TypeError` |

## 화살표 함수 메서드

화살표 함수는 자기 `this`가 없고 정의된 자리의 `this`를 그대로 씁니다. 객체 리터럴의 메서드를 화살표 함수로 만들면 `this`가 객체가 아니라 바깥 스코프의 `this`입니다(자세히는 27편, 21편).

| 환경 | 최상위 `this` | `inc()` 결과 |
|------|---------------|--------------|
| Node.js CommonJS | `module.exports` | 에러 없이 엉뚱한 객체의 `count`가 `NaN`이 됨 |
| ES 모듈 | `undefined` | `TypeError` |
| 브라우저 일반 스크립트 | `window` | `window.count`가 `NaN`이 됨 |

## 얕은 복사

얕은 복사는 최상위 한 단계만 새로 만들고, 그 안의 객체는 참조를 그대로 가져옵니다(자세히는 10편, 36편).

| 방법 | 특징 |
|------|------|
| `structuredClone(obj)` | 전체 깊은 복사 (함수 불가) |
| 변경 경로만 새로 만들기 | `{ ...s, n: { ...s.n, x: 2 } }` — 바꾸는 가지만 복사하고 나머지는 공유 |
| 라이브러리 | 불변 업데이트 도구 등 |

## 프로미스 반환 누락

`.then` 콜백이 값이나 프로미스를 반환해야 다음 `.then`이 그 결과를 받습니다. 반환하지 않으면 다음 단계는 기다리지 않고 `undefined`를 받습니다(자세히는 41편).

- 화살표 함수에서 본문을 중괄호로 감싸면 `return`을 직접 써야 합니다. 중괄호 없이 식만 쓰면 그 값이 자동으로 반환됩니다.
- 반환하지 않은 프로미스가 거부되면 체인의 `.catch()`가 잡지 못하고 처리되지 않은 거부가 됩니다. 체인이 끊어지기 때문입니다.
