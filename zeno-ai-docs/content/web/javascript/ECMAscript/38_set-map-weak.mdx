## 핵심 먼저 보기

- Set과 Map은 SameValueZero로 같은 값을 판단합니다. `NaN`은 `NaN`과 같고, `-0`은 `+0`으로 바뀌어 저장됩니다.
- Set은 중복 없는 값을, Map은 키가 어떤 값이든 가능한 쌍을 삽입 순서대로 보관합니다. 배열 중복 제거는 `[...new Set(arr)]`입니다.
- ES2025의 `union`·`intersection`·`difference`·`symmetricDifference`·`isSubsetOf`·`isSupersetOf`·`isDisjointFrom`은 원본을 바꾸지 않고, 인수로 set-like 객체(배열 제외)를 받습니다.
- 키가 동적이거나 객체이거나 순서가 중요하면 Map, 고정 필드의 레코드이거나 JSON이 필요하면 객체를 씁니다. `Map.groupBy`는 키 변환 없이 묶고, ES2026 `getOrInsert`·`getOrInsertComputed`는 없을 때만 삽입합니다.
- WeakMap·WeakSet은 키·값을 약하게 참조하고 `size`·순회가 없습니다. 객체에 붙이는 메타데이터와 객체 인수 캐시에 씁니다.
- WeakRef와 FinalizationRegistry는 회수 시점과 호출 여부가 보장되지 않으므로 정확성이 그 동작에 의존하면 안 됩니다.

## SameValueZero와 키 비교

Set의 값과 Map의 키가 같은지 판단하는 알고리즘은 SameValueZero입니다. `===`와 결과가 같되 `NaN`을 `NaN`과 같다고 봅니다.

| 알고리즘 | NaN과 NaN | +0과 -0 | 쓰이는 곳 |
|----------|-----------|---------|-----------|
| `===` (엄격 동등) | 다름 | 같음 | 일반 비교, `indexOf` |
| SameValue | 같음 | 다름 | `Object.is` |
| SameValueZero | 같음 | 같음 | Set, Map, `includes` |

```js
const nums = [NaN]
nums.includes(NaN)         // true
nums.indexOf(NaN)          // -1
new Set([NaN, NaN]).size   // 1
new Set([1, '1']).size     // 2
new Set([{}, {}]).size     // 2
```

## Set의 개념과 생성

Set은 중복 없는 값을 삽입 순서대로 보관하는 컬렉션입니다(ES2015). 같은 값(SameValueZero)은 하나만 저장되고, 인덱스와 `length`는 없습니다.

```js
new Set()              // Set {}
new Set([1, 2, 2, 3])  // Set {1, 2, 3}
new Set('hello')       // Set {'h', 'e', 'l', 'o'}
new Set(null)          // Set {}
```

- `new`가 필수입니다. `Set()`처럼 호출하면 `TypeError`입니다.
- 인수는 이터러블(자세히는 35편)이거나 `null`·`undefined`입니다. 이터러블이 아니면 `TypeError`입니다.
- 이터러블의 요소가 순서대로 추가되고, 중복은 처음 나온 값만 남습니다.
- `new Set(other)`는 얕은 복사입니다.
- 값의 타입에는 제한이 없습니다. 객체, 함수, `undefined`, `NaN`도 넣을 수 있습니다.

## Set 메서드

| 메서드 | 반환 | 동작 |
|--------|------|------|
| `add(value)` | Set 자신 | 값을 추가한다. 이미 있으면 아무 변화가 없다 |
| `has(value)` | boolean | 값이 있는지 확인한다 |
| `delete(value)` | boolean | 삭제했으면 `true`, 없던 값이면 `false` |
| `clear()` | `undefined` | 모든 값을 삭제한다 |
| `size` | 숫자 | 값의 개수. 읽기 전용 접근자 |

흔한 실수는 내용이 같은 객체로 조회하는 것입니다.

## Set 순회

Set은 이터러블이라 `for...of`, 스프레드, `Array.from`으로 값을 삽입 순서대로 순회합니다.

| 방법 | 순회 내용 |
|------|-----------|
| `for...of`, `[...set]`, `Array.from(set)` | 값 |
| `values()` | 값의 이터레이터 |
| `keys()` | `values()`와 같은 함수 |
| `entries()` | `[값, 값]` 쌍의 이터레이터 |
| `forEach(cb)` | `cb(값, 값, set)` 호출 |

## 중복 제거

배열의 중복은 Set에 넣었다가 다시 배열로 펼쳐 제거합니다. 처음 나온 순서가 유지됩니다.

- SameValueZero 규칙이 그대로 적용됩니다. `[0, -0, NaN, NaN]`은 `[0, NaN]`이 되고, `'a'`와 `'A'`는 다른 값입니다.
- 문자열은 코드 포인트 단위로 쪼개집니다. `'😀😀a'`는 3글자이고 중복 제거 후 2개입니다.
- 객체는 참조로 비교하므로 내용이 같아도 제거되지 않습니다.

## 집합 연산과 Set 메서드 7종

ES2025가 Set.prototype에 집합 연산 메서드 7종을 추가했습니다(Baseline 2024). 이전에는 스프레드와 `filter`로 직접 만들었습니다. 모든 메서드가 원본을 바꾸지 않습니다.

| 메서드 | 결과 | 수학 표기 |
|--------|------|-----------|
| `a.union(b)` | a 또는 b에 있는 값 | 합집합 |
| `a.intersection(b)` | 둘 다에 있는 값 | 교집합 |
| `a.difference(b)` | a에만 있는 값 | 차집합 |
| `a.symmetricDifference(b)` | 한쪽에만 있는 값 | 대칭차집합 |

## Map의 개념과 생성

Map은 키와 값의 쌍을 삽입 순서대로 보관하는 컬렉션입니다(ES2015). 키는 어떤 값이든 쓸 수 있고, SameValueZero로 유일합니다.

- `new`가 필수입니다. `Map()`은 `TypeError`입니다.
- 인수는 `[키, 값]` 쌍을 내놓는 이터러블이거나 `null`·`undefined`입니다.
- 항목이 객체가 아니면 `TypeError`입니다. `new Map([1, 2])`가 해당합니다.
- 일반 객체를 그대로 넘기면 이터러블이 아니므로 `TypeError`입니다. `Object.entries(obj)`로 바꿔서 넘깁니다.
- 쌍의 길이가 1이면 값은 `undefined`입니다. `new Map([[1]])`은 키 `1`이 있고 값은 `undefined`입니다.
- 같은 키가 반복되면 뒤의 값이 앞의 값을 덮어쓰고, 위치는 처음 나온 곳에 남습니다.
- `new Map(other)`는 얕은 복사입니다.

## Map 메서드

| 메서드 | 반환 | 동작 |
|--------|------|------|
| `set(key, value)` | Map 자신 | 키가 있으면 값을 갱신하고, 없으면 끝에 추가한다 |
| `get(key)` | 값 또는 `undefined` | 키에 대응하는 값을 반환한다 |
| `has(key)` | boolean | 키가 있는지 확인한다 |
| `delete(key)` | boolean | 삭제했으면 `true` |
| `clear()` | `undefined` | 모든 항목을 삭제한다 |
| `size` | 숫자 | 항목 수. 읽기 전용 접근자 |

흔한 실수는 세 가지입니다.

## Map 순회

Map은 이터러블이며 기본 순회는 `[키, 값]` 쌍입니다.

| 방법 | 순회 내용 |
|------|-----------|
| `for...of`, `[...map]`, `entries()` | `[키, 값]` 쌍 |
| `keys()` | 키의 이터레이터 |
| `values()` | 값의 이터레이터 |
| `forEach(cb)` | `cb(값, 키, map)` 호출 |

## Map.groupBy

`Map.groupBy(items, callback)`는 이터러블의 요소를 콜백이 반환한 키별로 묶어 Map으로 반환합니다(ES2024). 각 값은 해당 키에 속한 요소의 배열입니다. 콜백은 `(요소, 인덱스)`를 받습니다.

| | `Object.groupBy` | `Map.groupBy` |
|---|------------------|---------------|
| 반환 | 프로토타입이 없는 객체 | Map |
| 키 | 문자열·심벌로 변환 | 변환 없이 그대로 |

## getOrInsert와 getOrInsertComputed (ES2026)

`getOrInsert`와 `getOrInsertComputed`는 키가 있으면 그 값을 반환하고, 없으면 값을 삽입한 뒤 그 값을 반환하는 메서드입니다. Map과 WeakMap에 모두 추가됐습니다. 제안 이름은 upsert이고 2026년 1월에 4단계가 되어 ES2026에 들어갔습니다.

| 메서드 | 두 번째 인수 | 값 계산 시점 |
|--------|--------------|--------------|
| `getOrInsert(key, value)` | 삽입할 값 | 호출 전에 항상 계산됨 |
| `getOrInsertComputed(key, callback)` | `callback(key)` | 키가 없을 때만 호출됨 |

## Map과 Object 비교

| 항목 | Map | Object |
|------|-----|--------|
| 키 타입 | 모든 값 | 문자열·심벌. 나머지는 문자열로 변환 |
| 키 비교 | SameValueZero | 문자열 비교 |
| 순서 | 삽입 순서 | 정수 인덱스 형태의 키가 오름차순으로 먼저, 나머지는 삽입 순서 |
| 크기 | `map.size` | `Object.keys(obj).length` |
| 순회 | 바로 `for...of` | `Object.entries()` 등을 거쳐야 함 |
| 기본 키 | 없음 | 프로토타입에서 상속(`toString` 등) |
| JSON | `JSON.stringify` 결과가 `{}` | 그대로 변환됨 |
| 접근 | `get`·`set` 메서드 | 점·대괄호 표기 |

객체의 키 변환과 순서 규칙이 만드는 차이는 다음과 같습니다.

## Map·Object·배열 상호 변환

| 변환 | 코드 | 주의 |
|------|------|------|
| 객체 → Map | `new Map(Object.entries(obj))` | 열거 가능한 문자열 키만 포함 |
| Map → 객체 | `Object.fromEntries(map)` | 키가 문자열로 바뀌어 충돌·유실 |
| Map → 쌍 배열 | `[...map]`, `Array.from(map)` | `[[키, 값], ...]` |
| Map → 키·값 배열 | `[...map.keys()]`, `[...map.values()]` | |
| 쌍 배열 → Map | `new Map(pairs)` | 중복 키는 뒤가 이김 |
| 배열 → 키 기준 Map | `new Map(arr.map(o => [o.id, o]))` | 중복 키는 뒤가 이김 |
| Set ↔ 배열 | `new Set(arr)`, `[...set]` | |
| Map → Set | `new Set(map.keys())`, `new Set(map.values())` | |
| Set → Map | `new Map([...set].map(v => [v, f(v)]))` | |

Map과 Set은 `JSON.stringify`가 내용을 직렬화하지 않고 `{}`로 만듭니다(자세히는 39편). 쌍 배열로 바꿔 저장하고 `new Map`으로 복원합니다.

## WeakMap

WeakMap은 객체 또는 비등록 심벌을 키로 사용하고 키의 생존을 강하게 붙잡지 않습니다. 키 목록·크기·순회 API는 없습니다. 가비지 컬렉션 시점을 관찰하거나 보장할 수 없으므로 필수 자원 해제 수단으로 쓰지 않습니다.

## WeakSet

WeakSet은 값을 약하게 참조하는 Set입니다(ES2015). 값은 객체와 등록되지 않은 심벌만 가능합니다.

## WeakMap 활용 패턴

객체에 프로퍼티를 추가하지 않고 부가 정보를 연결합니다. 프로퍼티 이름이 충돌하지 않고, `Object.keys`에 나타나지 않으며, 동결된 객체에도 붙일 수 있습니다.

## WeakRef

WeakRef는 객체를 약하게 가리키는 참조 객체입니다(ES2021). `new WeakRef(target)`으로 만들고 `ref.deref()`로 대상을 꺼냅니다. 대상이 회수됐으면 `deref()`는 `undefined`를 반환합니다.

## FinalizationRegistry

FinalizationRegistry는 등록한 객체가 회수된 뒤에 콜백을 호출해 달라고 요청하는 객체입니다(ES2021). 회수 뒤의 정리 작업용 안전망입니다.

| 항목 | 규칙 |
|------|------|
| `new FinalizationRegistry(cb)` | 회수 후 호출할 콜백. 함수가 아니면 `TypeError` |
| `register(target, held, token)` | `undefined` 반환. 토큰은 생략 가능 |
| `unregister(token)` | 취소한 등록이 하나라도 있으면 `true`, 없으면 `false` |
