# mini-villageanimation

하늘·구름·사람·낮과 밤의 마을을 CSS 애니메이션으로 표현한 학습 프로젝트입니다.

## 실행

별도 패키지 설치·빌드 없이 이 폴더를 루트로 정적 HTTP 서버를 실행합니다. Vercel에서는 Root Directory를 `mini-villageanimation`, Framework Preset을 Other로 지정하고 빌드 명령 없이 배포합니다.

기존 퍼블리싱 학습 결과물이며 화면 안의 원본 브랜드·예제 표기는 유지합니다. 외부 CDN·아이콘·글꼴을 사용하는 화면은 네트워크 연결과 제공 서비스 상태에 영향을 받습니다.
