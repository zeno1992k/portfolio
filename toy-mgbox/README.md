# Megabox 퍼블리싱

예전에 진행한 메가박스 웹사이트 화면 재현 학습 프로젝트입니다. 기존 HTML에 명시된 [webstoryboy의 megabox2019 튜토리얼](https://github.com/webstoryboy/megabox2019)을 바탕으로 작성한 작업이며, 원본 출처 표기를 유지합니다.

- HTML·CSS·JavaScript, jQuery와 Swiper를 사용합니다.
- 영화·이벤트·신규 개봉작·공지·푸터 영역과 예고편 플레이어를 구성합니다.
- 실제 영화 예매나 회원 인증 서버는 포함하지 않습니다.

## 실행

별도 설치·빌드 없이 이 폴더를 루트로 정적 HTTP 서버를 실행합니다. Vercel에서는 Root Directory를 `toy-mgbox`, Framework Preset을 Other로 지정하고 빌드 명령 없이 배포할 수 있습니다.

브랜드 이미지와 문구는 화면 재현을 위한 학습 자료이며 공식 서비스가 아닙니다. 외부 글꼴·영상 등은 네트워크 연결과 제공 서비스 상태에 영향을 받습니다.

기존 FAQ 링크의 대상인 `custom/faq.html`은 현재 소스에 포함되어 있지 않습니다.
