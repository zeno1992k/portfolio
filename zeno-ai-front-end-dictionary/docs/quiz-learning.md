# JavaScript · React 퀴즈

하단의 **퀴즈** 탭에서 파트와 단계를 고르고 4지선다 문제를 풉니다. 670개 용어 카드와 별도로 JavaScript 210문제, React 210문제, 총 420문제를 제공합니다. 각 파트는 기초·실무·심화 70문제씩입니다. React는 코드가 있는 125문제(기초 44·실무 41·심화 40)와 코드 없이 개념을 묻는 85문제로 구성합니다. 코드 문제 중 빈칸 채우기는 40문제(기초 17·실무 13·심화 10)입니다.

## 학습 흐름

- **5문제 연습 / 전체 문제**로 보기를 전환합니다. 전체 목록은 주제·코드 검색과 파트·난도·개념/실무/코딩테스트·미풀이/맞힌 문제/틀린 문제 필터를 함께 적용합니다.
- 목록에는 주제, 질문 미리보기, 파트·단계·유형, 최근 풀이 상태를 표시하며 정답과 해설은 표시하지 않습니다. 30개씩 더 읽어 전체 문제에 접근할 수 있습니다.
- 목록에서 한 문제를 골라 풀면 진행 중이던 다섯 문제 세트는 유지합니다. 정답을 확인하는 순간 단일 문제의 풀이 기록을 한 번 반영하고, 목록으로 돌아오면 기존 필터·위치를 복구합니다.
- 선택한 파트·단계에서 중복 없이 최대 5문제를 무작위로 뽑습니다. 보기 순서도 세트 생성 시 섞고, 새로고침해도 유지합니다.
- 보기를 선택한 뒤 **정답 확인하기**를 누르면 답이 잠깁니다. 정답, 개념 해설, 선택한 오답의 이유, 네 보기의 설명을 확인합니다.
- 질문은 존댓말로 작성합니다. 별개의 console.log 출력은 첫 번째·두 번째 출력처럼 줄별로 표시하고, 빈 문자열은 `"" (빈 문자열)`로 표시합니다. 코드가 문자열 안에 화살표를 직접 출력하는 경우는 그 실제 값을 유지합니다.
- 목록과 문제 화면에 **빈칸 채우기 / 코드 읽기**를 표시합니다. 빈칸은 문법 강조된 코드 안의 밑줄로 표시하며 보기 네 개 중 들어갈 코드나 코드·설명 조합을 고릅니다. 코드 읽기에는 실행 결과·수정 방법·설계 판단 문제가 포함됩니다.
- 코드에는 기존 라이트·다크 문법 강조를 적용합니다. 관련 용어는 기존 전체 화면 상세로 연결하고, 문항마다 근거 문서를 제공합니다.
- 탭을 이동하거나 새로고침해도 진행 중인 세트를 이어서 풀 수 있습니다. 새 세트를 시작하면 진행 중이던 세트를 교체합니다.
- 세트를 끝내면 기록을 한 번만 반영합니다. 마지막에 틀렸던 문제를 최대 5개씩 다시 풉니다. 정답을 맞히면 오답 목록에서 빠집니다.
- 파트·단계별로 풀어본 문제 수와 누적 정답률, 가장 최근 결과를 표시합니다.
- 오답 표시에는 문항의 최근 답변 시각을 사용합니다. 잠시 멈춘 세트를 나중에 끝내도 그 사이 단일 문제에서 맞힌 결과를 이전 오답으로 되돌리지 않습니다.

JavaScript는 연산자·참조·배열·클로저·비동기 작업과 스택·투 포인터·슬라이딩 윈도·이진 탐색·누적 합·BFS·DP 등의 패턴을 다룹니다. React는 JSX·props·state·Hooks·Effect·요청 경쟁·렌더링·hydration·Suspense 등의 상황을 다룹니다. 난도는 이 앱의 편집 기준이며, 출제 빈도에 대한 통계를 의미하지 않습니다.

## 기록 저장

퀴즈는 이 브라우저의 localStorage에 저장합니다. 게스트와 로그인 계정별로 키를 분리합니다. 로그인 시 게스트 퀴즈를 가져오는 기능과 기기 간 퀴즈 동기화는 구현하지 않았습니다. 기존 용어 학습 기록의 Supabase 동기화는 유지합니다.

다섯 문제 세트는 선택한 보기와 확인한 답까지 새로고침 후 이어서 풀 수 있습니다. 목록에서 연 단일 문제의 확인 전 선택은 임시 화면 상태이며 새로고침으로 초기화됩니다. 확인한 단일 문제 기록은 저장됩니다.

`zeno-quiz:v1:guest` 또는 `zeno-quiz:v1:user:<account-id>`에 진행 중인 세트, 문항별 풀이 횟수·최근 정오답, 최근 10개 세트 결과를 저장합니다. 저장이 막힌 브라우저에서도 현재 화면의 퀴즈는 풀 수 있고 안내를 표시합니다. Supabase 테이블·정책·인증 설정은 변경하지 않습니다.

## 검증

`npm test`는 세트 추출·보기 순서 유지·중복 채점 방지·오답 갱신·계정별 키·손상된 저장 값 처리와 문항 구성을 확인합니다. 예제 코드는 선언한 언어로 파싱하고, 동기 JavaScript 출력 문제는 실제 실행 결과와 비교합니다. 값 표기를 검증할 때 NaN·undefined·-0을 JSON 변환으로 바꾸지 않습니다. 기존 Promise.all·Promise.any와 이벤트 루프 출력도 실행 검사합니다. React 코드 보강 전 배포된 420문항의 ID·정답 선택지가 유지되는지 확인하고, 단계별 코드·빈칸 문제 비중과 빈칸의 접근성 표시를 검사합니다. 기존 일시 정지한 세션을 복원하는 검증도 유지합니다. React 코드 검증은 문법 파싱과 정답 코드의 문법 확인이며 실제 React 앱 실행 검사를 의미하지 않습니다. 자동 검증은 실제 휴대폰에서의 터치·화면 확인을 대신하지 않습니다.

개발 서버에서는 `http://127.0.0.1:4179/?tab=quiz`로 퀴즈 화면, `http://127.0.0.1:4179/?tab=quiz&view=list`로 전체 목록을 바로 열 수 있습니다.
