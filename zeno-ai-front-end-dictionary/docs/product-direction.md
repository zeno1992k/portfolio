# Zeno 학습 앱의 확장 방향

문서로 읽은 개념을 카드로 떠올리고 퀴즈로 확인하는 학습 흐름을 지향합니다. 현재 구현은 프론트엔드 용어 카드 670개, 면접 답변 연습 390개와 JavaScript·React 퀴즈 420개입니다.

## 현재 제품 구조

- 공통 로그인, 북마크와 복습 일정.
- 분야·난도를 선택하는 카드 학습.
- 검색 가능한 용어 사전과 면접 답변 연습.
- 퀴즈 풀이, 해설과 오답 복습.

## 향후 검토 범위

| 방향 | 현재와의 관계 |
| --- | --- |
| 독립 코스 선택 | JavaScript·React 콘텐츠는 있으나 별도 코스 선택 화면은 미구현 |
| 자격증 학습 | 시험 범위 확정과 콘텐츠 제작 필요 |
| 문서와 카드 연결 | 문서의 특정 항목에서 관련 카드로 이동하는 연동 필요 |
| 예약 알림 | 출퇴근 시간 설정과 별도로 권한·구독·발송 기능 구현 필요 |

같은 개념을 여러 코스에서 사용할 때 카드 ID를 재사용해 학습 기록의 중복을 줄이는 방향입니다. 위 내용은 확장 계획이며 완료된 기능은 아닙니다. 현재 콘텐츠와 학습 규칙은 [콘텐츠 구성](learning-catalog.md)을 참고합니다.
