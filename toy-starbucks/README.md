# Starbucks 퍼블리싱

예전에 진행한 스타벅스 웹사이트 화면 재현 학습 프로젝트입니다.

- HTML·CSS·JavaScript, Swiper와 외부 애니메이션 라이브러리를 사용합니다.
- 메인 화면의 메뉴·프로모션·상품·매장 안내와 슬라이더를 구성합니다.
- `signin/index.html`은 로그인 화면 퍼블리싱이며 실제 계정 인증은 연결되지 않았습니다.

## 실행

별도 설치·빌드 없이 이 폴더를 루트로 정적 HTTP 서버를 실행합니다. 메인은 `/`, 로그인 화면은 `/signin/`에서 확인합니다. Vercel에서는 Root Directory를 `toy-starbucks`, Framework Preset을 Other로 지정하고 빌드 명령 없이 배포할 수 있습니다.

브랜드 이미지와 문구는 화면 재현을 위한 학습 자료이며 공식 서비스가 아닙니다. 외부 CDN·글꼴·영상은 네트워크 연결과 제공 서비스 상태에 영향을 받습니다.
